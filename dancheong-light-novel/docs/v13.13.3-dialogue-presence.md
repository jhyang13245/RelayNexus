# v13.13.3 — 대사 중 입상 유지

## 원인과 재현

연출 모델이 대사 비트의 물리적 등장 근거로 서술 대신 대사 원문만 반환할 때, 인용만으로 인물을 등장시키지 않는 검증 규칙이 해당 입상을 제외했습니다. 실제 저장된 연출 결과에서도 같은 문단의 서술에서는 히시리가 보이고 대사에서만 사라진 뒤, 다음 서술에서 다시 보이는 현상을 재현했습니다.

## 수정

- 같은 문단의 바로 이전 비트에서 검증된 인물이 계속 대화하고, 모델도 현재의 물리적 등장으로 확정한 경우에만 직전의 유효한 서술 근거를 재사용합니다.
- 이전 비트에 없던 인물, 퇴장 뒤의 인물, 전화·회상·불확실한 인물을 대사만으로 새로 표시하지 않습니다.
- 입상 유지와 화자 확정을 분리합니다. 연출 모델이 화자 근거를 바꿔 쓰거나 잘못 인용했다면 인물은 유지하되 화자·음성 신원을 임의로 확정하지 않습니다.
- 이후 연출 요청에는 대사 원문만을 등장 근거로 사용하지 말고, 바로 앞의 물리적 등장 서술을 정확히 인용하도록 명시합니다.
- 기존 연출 캐시도 같은 검증으로 보완하므로 이미지 재생성이나 전체 캐시 삭제가 필요하지 않습니다. 다른 작품·문단의 과거 입상을 무조건 남겨 두지는 않습니다.

## 검증

실제 저장된 문제 응답을 로컬에서 재검증하여 `표시 → 미표시 → 표시`가 `표시 → 표시 → 표시`로 바뀌는 것을 확인했습니다. 사용자 데이터는 공개 소스에 넣지 않았습니다.

새 테스트는 연속 대사의 입상 유지, 잘못된 화자 근거 차단, 전화·불확실한 판정 제외, 직전 부재와 퇴장 이후 인물 재등장 방지를 확인합니다. 전체 420개 테스트를 통과했습니다. v13.13.2 적용 후 실제 크롬에서는 세이버 입상 생성과 히시리 대사 시작 시 입상 표시를 확인했습니다.
