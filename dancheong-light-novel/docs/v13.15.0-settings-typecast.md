# v13.15.0 — 설정 탭 정리와 Typecast 캐릭터 보이스

## 설정 탭

설정 탭을 다섯 개로 나눴습니다: **연결 / 연출 / 음성·음악 / 사용량·비용 / 저장 공간**.

- **연결**
  - 본문 모델, 이미지 모델, API 키(OpenAI, OpenCode Go, Gemini)
  - 문체 지침, 본문 표시 속도, 이미지 품질
- **연출**
  - 읽기: 본문 배치, 자동 읽기 간격, 본문 크기와 글꼴, 화면 움직임, 사건 장면, 그림체 지침, 인물 묘사 기준 이미지
  - 추가 연출: 화면 연출, 새 구도 컷, 눈 깜빡임·입 움직임, 얼굴만 합성
- **음성·음악**
  - AI 대사 음성: 켜기/끄기, 음성 모델, Typecast 키와 캐릭터 목록, 음량, 넘길 때 음성 유지 여부, 낭독 목소리, 인물별 목소리·음량
  - 효과음·배경음악: 조작 효과음, 환경음, 배경음악과 음악 크기, 작품 음원과 AI 배경음악 만들기

저장·취소 버튼은 연결·연출·음성·음악 탭에서 함께 쓰며, 한 번 저장하면 세 탭의 변경을 모두 저장합니다. 사용량·비용과 저장 공간 탭에서는 이 버튼을 숨깁니다. 기존 설정 값과 저장 형식은 바꾸지 않았습니다.

## Typecast 캐릭터 보이스

1. **음성·음악** 탭에서 음성 모델을 **Typecast**로 고릅니다.
2. Typecast API 키를 입력하고 **내 Typecast 캐릭터 목록 불러오기**를 누릅니다. 목록은 이 기기에 보관합니다.
   - API 키는 다른 키와 같이 이 기기의 브라우저 저장소에 암호화해 보관합니다.
3. 인물별로 캐릭터를 고르고, **샘플 ▶**로 Typecast가 제공하는 샘플을 들어 봅니다. 샘플 재생에는 크레딧이 들지 않습니다.
   - 자동으로 두면 공개 프로필의 성별·연령대에 맞춰 인물마다 다른 캐릭터를 배정하고, 이 이야기에서는 고정합니다. 애니메이션·게임 용도의 캐릭터를 우선 고릅니다.
   - 낭독자는 오디오북·다큐·뉴스 용도의 캐릭터를 자동으로 고르며, 그 캐릭터는 인물에게 배정하지 않습니다.
4. **저장**을 누르면 적용됩니다.

### 연기 방식

모델은 `ssfm-v30`, 언어는 `kor`입니다.

| 본문 근거 | Typecast 설정 |
|---|---|
| 속삭였다·소곤 | `whisper` 프리셋 |
| 외쳤다·소리쳤다·고함 | `toneup` 1.5 |
| 울먹·흐느낌·떨리는 목소리 | `sad` 1.3 |
| 중얼·혼잣말·한숨 | `tonedown` |
| 표정: 미소 / 홍조 / 분노 / 슬픔 / 놀람 / 걱정 / 눈 감음 | happy / happy 0.7 / angry 1.2 / sad / toneup 1.2 / tonedown / tonedown 0.8 |
| 그 밖의 대사 | `smart`: 같은 턴의 앞 문장(최대 600자)과 공개된 뒤 문장을 전달해 Typecast가 감정을 추론 |

- 핵심 대사로 강조된 줄은 감정 강도를 1.2배로 높입니다(최대 2.0).
- 한 대사는 한 번만 생성해 저장합니다. 다시 듣기, 되돌아가기, 새로고침, 기록의 ▶ 재생에는 크레딧이 들지 않습니다.
- Typecast 음성은 다른 음성 모델과 캐시를 공유하지 않습니다.

### 요청 형식과 과금

- **요청 형식**
  - `POST https://api.typecast.ai/v1/text-to-speech`를 `X-API-KEY` 헤더로 호출합니다.
  - 본문은 `{ voice_id, text, model, language, prompt, output: { audio_format: 'mp3', audio_tempo } }`입니다.
  - 응답 본문은 음성 파일 자체이고, 이를 data URL로 바꿔 기존 음성 캐시에 저장합니다.
  - 캐릭터 목록은 `GET https://api.typecast.ai/v3/voices?model=ssfm-v30`으로 받습니다.
  - 공식 SDK(`neosapience/typecast-sdk`의 typecast-python `models/tts.py`, `client.py`, `models/voices.py`)의 필드 정의를 그대로 따랐습니다.
- **과금**
  - Typecast는 요금제 크레딧을 글자 수 기준으로 차감합니다. 호출별 달러 금액이 공개되어 있지 않아 비용 탭에는 **Typecast 크레딧**으로 호출 횟수만 기록합니다.
  - 크레딧 부족(402), 잘못된 키(401/403), 없는 캐릭터(404), 요청 한도(429)는 각각 안내 문구로 표시합니다.
  - Typecast의 원문 오류는 요청 대사를 되풀이할 수 있어서 화면에 보여 주지 않습니다.

## 검증

- **자동 검사**
  - Node 테스트 전체 통과. Typecast 테스트 7개를 추가했습니다.
  - 목록이 없을 때 음성을 추측하지 않고 쉬는지 확인했습니다.
  - 목소리 배정: 낭독자 분리, 성별·연령 배정, 캐릭터가 겹치지 않음을 확인했습니다.
  - 연기 매핑과 공식 요청 형식(프리셋, smart, v21 제한)을 확인했습니다.
  - 키 전달, 오류 문구, 원문 오류 숨김, 크레딧 집계, 목록 응답 정리(잘못된 ID·http 샘플 제외)를 확인했습니다.
  - tsc와 배포 빌드 모두 이상 없습니다.
- **실제 Chromium (데스크톱·모바일 폭)**
  - 다섯 탭이 각각 맞는 설정만 보여 주고, 저장 버튼은 편집 가능한 탭에서만 표시되는 것을 확인했습니다.
  - Typecast를 고르면 키 입력, 목록 불러오기, 낭독자 자동 선택이 표시됩니다.
  - 페이지 오류는 없었습니다.
- **검증하지 못한 것**
  - `typecast.ai`와 `api.typecast.ai`는 이 개발 환경에서 네트워크가 차단되어, 실제 키로 음성이나 목록을 받아 보지 못했습니다.
  - 실제 사용자 브라우저와 배포 서버에서는 연결됩니다. 첫 사용 시 목록 불러오기와 대사 한 줄로 확인해 주세요.
