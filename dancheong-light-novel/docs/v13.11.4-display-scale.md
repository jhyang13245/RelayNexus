# v13.11.4 — 잘린 입상의 확대 비율 수정

## 원인

v13.11.3의 생성 결과 검사와 별개로, 실제 표시 경로의 `faceFrame`은 하체가 짧은 입상의 아래쪽을 화면 바닥에 붙이려고 출력 프레임 높이를 줄였습니다. CSS가 그 프레임을 화면 높이까지 확대하면서 상반신 입상의 머리가 다른 인물보다 커졌습니다. 얼굴 탐색을 넓힌 변경도 검사 경로에만 적용되어, 짧은 그림은 표시할 때 얼굴 탐색에 실패하고 전체 이미지 높이 기준으로 돌아갈 수 있었습니다.

## 수정

- 머리 윤곽의 측정 너비로 카메라 배율을 정하고 눈높이를 공통 위치에 맞춥니다. 하체 길이·투명 여백·그림 종횡비로 얼굴을 확대하지 않습니다.
- 확대된 얼굴 탐색을 실제 표시 경로에도 적용합니다. Worker와 Canvas 대체 경로가 같은 프레임·그리기 함수를 사용합니다.
- 예전 상반신 입상을 임시로 표시할 때도 확대 비율을 유지합니다. 없는 하체를 확대해서 덮는 대신 잘린 가장자리를 부드럽게 처리하며, 기존 구도 보완 생성 흐름은 유지합니다.
- 신장 설정과 화면 전체의 공통 카메라 연출은 그대로 적용합니다. 화자만 별도로 확대하는 다인 장면 규칙은 추가하지 않습니다.
- 이미지 캐시 키와 생성 버전은 바꾸지 않습니다. 이번 표시 수정 자체는 AI 호출이나 재생성을 추가하지 않습니다.

## 확인

- 자동 검사 314개 통과. 같은 얼굴의 여러 잘림 범위와 투명 여백에서도 머리 크기·눈높이가 같도록 회귀 검사를 추가했습니다. 잘린 그림을 강제로 확대하던 기존 테스트도 수정했습니다.
- 기존 나디아 입상과 그 그림의 상반신 잘림을 브라우저에서 비교: 1280×590 화면에서 머리 너비 각각 126.8px, 눈높이 차이 0.3px.
- 기존 나디아·홍재 입상을 같은 신장 조건으로 비교: 1280×590에서 측정 머리 너비 각각 126.8px, 눈높이 차이 0.2px.
- 390×844 세로 화면 및 Worker/Canvas 경로 확인. 잘림 비교의 머리 너비 각각 126.8px, 눈높이 차이 0.3px.
- 새 유료 이미지를 생성하지 않았습니다. 사용자 모바일에 저장된 백서현·김다윤 입상 파일은 직접 확보하지 못했으므로 그 두 파일의 실측 검증은 포함하지 않습니다.

얼굴 탐색은 기존 픽셀 기반 추정 방식입니다. 얼굴이 가려졌거나 특수한 화풍이라 측정할 수 없는 그림은 기존 전체 영역 기준 대체 처리를 사용하므로 모든 생성물의 배율 일치를 보장하지는 않습니다. 짧은 입상에 없는 하체를 로컬 보정으로 새로 그리지는 않습니다.
