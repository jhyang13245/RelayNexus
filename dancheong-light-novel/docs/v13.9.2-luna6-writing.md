# v13.9.2 — GPT 6 Luna 집필

## 변경

- OpenAI API와 OpenCode Go의 집필 모델 및 설정 화면 이름을 `gpt-6-luna` / GPT 6 Luna로 변경했습니다. 집필 추론은 기존 Low를 명시적으로 유지합니다.
- 기존 `openai` / `go-luna` 제공자 선택과 암호화된 키 저장 위치를 재사용합니다. 새 버전을 불러오면 기존 선택에 GPT 6 Luna가 적용됩니다.
- 단청 v1.23.1에서 검토한 Cortex 원본의 모델 변경 7개 행을 반영했습니다. Go 전송 계층은 개별 요청의 모델을 보존하여 집필 변경이 판정·기억 요청까지 바꾸지 않도록 합니다.
- 판정·기억과 인물 배치 확인의 Luna 요청은 GPT 5.6 Luna를 유지합니다. Muse 선택 및 추론 설정, 이미지 모델 선택, 판정 재시도 경로는 유지합니다.
- GPT 6 Luna의 별도 비용 계산을 추가했습니다. 100만 토큰당 입력 $0.10, 캐시 입력 $0.01, 캐시 쓰기 $0.125, 출력 $0.50입니다. 입력 272,000토큰 초과 시 입력 계열 2배, 출력 1.5배를 적용합니다. 기존 5.6 비용 기록과 Go 구독 사용량 표시는 유지합니다.

## 근거

2026-09-25 확인:

- [OpenAI GPT 6 Luna 모델 문서](https://developers.openai.com/api/docs/models/gpt-6-luna): 모델 ID, Responses·스트리밍 지원, Low 추론, 요금.
- [OpenCode Go 공식 문서](https://opencode.ai/docs/go/): `gpt-6-luna` 모델 및 `/zen/go/v1/responses` 경로.

## 검증

- 전체 자동 검사 215개 통과: 저장된 제공자 설정의 모델 적용, 실제 Cortex 전송 함수의 집필·판정 분리, 두 프록시의 스트리밍·추론·토큰 한도 전달, Go 허용 모델, 캐시·긴 입력 비용 경계값 포함.
- TypeScript 검사 통과.
- 로컬 브라우저에서 두 GPT 6 Luna 선택 항목과 OpenAI·Go 설정 저장 후 `gpt-6-luna` / Low 적용을 확인했습니다.
- 실제 유료 API 호출과 장시간 플레이는 수행하지 않았습니다. 전송 검사는 합성 요청과 응답을 사용했습니다.
