# v13.9.5 — 공통 인물 묘사 기준

## 생성 기준

- 기존의 균일한 선·2단계 셀 채색 제한을 제거하고, 가는 선·눈의 층별 묘사·부드러운 피부 명암·가느다란 머리카락·옷과 금속의 재질 묘사를 모든 입상/표정에 요구한다.
- 기존 나디아 생성 이미지 `public/art/character-quality-nadia-v1.png`를 묘사 수준 참고로 사용한다. 새 기본 입상 요청의 마지막 이미지로만 추가하고, 앞선 이미지와 공개 인물 정보를 해당 인물의 외형 기준으로 구분한다. 참고 인물의 얼굴·연령·성별·머리색·의상·소품을 복사하지 않도록 명시한다.
- 전신을 축소해 넣는 대신 머리부터 허벅지까지 직접 구성하고, 출력 이미지 안에서 머리가 충분한 영역을 차지하도록 요구한다.
- 표정은 새 기본 입상 한 장을 참조하여 얼굴을 새로 그리되 묘사 밀도와 구도를 유지한다. 표정의 세부 근육을 지시하지 않고 공개된 상황과 필요한 감정만 제공한다.
- OpenAI / Nano Banana 2에 동일한 인물 기준을 적용한다. 선택된 모델과 Low/Medium 설정, 해상도, 배경 모델 선택은 바꾸지 않는다. 추가 묘사 참조의 입력 사용량도 기존 비용 기록에 포함된다.

## 기존 이미지와 비용

- 새 입상/표정 캐시는 `vn-character-finish-1`로 구분한다. 현재와 가까운 공개 문단에서 필요한 인물만 한 번 갱신한다. 전체 캐릭터 일괄 생성이나 매 대사 재생성은 하지 않는다.
- 사용자가 기준으로 삼은 Fate/Seoul의 기본 나디아 입상은 기존 이미지를 유지한다(기본 그림체). 나머지 예전 입상/표정은 갱신될 때 유료 이미지 요청이 발생하며 이후 재사용한다.
- 예전 이미지는 삭제하지 않는다. 갱신 대기·실패·오프라인에는 기존 이미지를 표시한다. 실패한 요청은 명시적 재시도 전까지 자동 반복하지 않는다.
- 새 기본 입상이 준비되면 만난 인물 목록도 새 이미지를 가리킨다. 현재 작품의 현장 인물과 이미 만난 인물만 목록에 반영한다.

## 검증 범위

- 자동 테스트: 두 이미지 모델의 참조 순서/품질 설정, 묘사 참고와 인물 정체성 구분, 표정의 새 기본 입상 참조, 갱신 중 기존 입상 유지, 기본 나디아 재사용, 오프라인/재방문/실패 후 요청 억제, 목록 캐시 갱신, 참고 이미지 다운로드 중복 방지.
- Muse에는 별도 비공개 정보 없는 복사본에서 순수 참고 이미지 로더·프롬프트 테스트 8개만 맡겼다. 반환 파일을 주 개발자가 읽고 직접 실행하여 통합했다. 핵심 생성·캐시·화면 코드는 주 개발자가 작성했다.
- 로컬 브라우저의 모의 응답으로 실제 표시 및 설정의 비용 안내를 확인했다. 이 테스트는 그림의 미적 품질을 평가하는 테스트가 아니다. 모든 연령·복장·모델에서 나디아와 완전히 동일한 완성도가 보장되는 것은 아니며 실제 생성 결과에 따라 차이가 날 수 있다.

## 상황에 맞는 복장

- 기존 현장 인물 판정 요청에서 공개된 본문에 맞춰 복장도 판단한다. 추가 모델 호출은 없지만 판정 입력·출력 토큰은 소폭 늘어난다. 판정 정책 V7로 이전 판정은 가까운 공개 문단부터 다시 확인한다.
- 기본 복장이 원칙이다. 실제 물놀이, 취침 준비, 행사 참석 및 명시적인 갈아입기에서 상황별 복장을 사용한다. 바다 옆을 걷거나 여행을 계획하는 것만으로 수영복을 적용하지 않는다. 갑작스러운 전투나 물에 빠짐도 자동 환복 사유가 아니다.
- 각 읽기 위치 이전의 공개된 근거만 허용한다. 회상·가정·인용·미래 문장을 근거로 한 환복은 배제하며, 긴 대화에서는 이전 환복과 이후 일상 복귀 문장을 제한된 길이의 문맥으로 제공한다. 기본 복장으로 돌아오면 기존 이미지를 재사용한다.
- 복장 종류와 명시된 의복 구절로 캐시를 분리한다. 추론한 수영복은 같은 인물·작품에서 같은 종류를 재사용한다. 명시된 별도 디자인은 별도 변형으로 저장한다. 입상과 표정 모두 해당 복장의 키를 사용하므로 기본 복장 표정이 수영복에 섞이지 않는다.
- 새 복장을 만들 때 이미 생성된 기본 입상이 있으면 인물 외형 참조에 함께 사용한다. 표정은 해당 복장의 입상을 참조한다. 연령·신체·얼굴·머리·눈은 유지하고 복장과 활동에 맞지 않는 소품만 변경하도록 요청한다. Gemini 서버의 ‘복장 무조건 유지’ 후처리 지시도 현재 복장 지시를 따르도록 수정했다.
- 복장별 첫 입상과 필요한 표정에는 이미지 비용이 발생한다. 같은 이미지의 재사용, 기본 복장 복귀, 새로고침에는 추가 이미지 요청이 없다. 복장 생성 실패 시 잘못된 기본 복장을 완성된 변형으로 취급하지 않으며 명시적 재시도 전까지 유료 요청을 반복하지 않는다.
- 자동 검증에는 등장 시점·기본 복귀·미래/인용/가정/회상/부정 배제·문맥 유지·미등장 인물 제외·양 모델의 복장별 참조/캐시/동시 요청/새로고침/실패 처리가 포함된다. 복장 의미 해석은 모델 판정에 의존하며 모든 서술 양식을 자동 테스트로 보장하지 않는다. 실제 수영복 유료 생성은 예시가 실제 플레이가 아니므로 실행하지 않았다.
