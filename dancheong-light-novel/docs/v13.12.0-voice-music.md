# v13.12.0 — 음성 연기·한국어 전처리·후처리, 배경음악 반복·전환·음량, AI 배경음악

2026-09-26. v13.11.8 기준.

## 1. AI 음성

### 감정 연결
- 기존에는 `{"speaker","mood","emotion":"smile"}` 같은 JSON만 보내고, 음성 지시문은 "restrained emotional acting"이라 감정이 거의 드러나지 않았다.
- 이제 연기 지시(`actingNotes`)를 문장으로 만든다. 들어가는 정보:
  - 화자의 확정 표정(예: angry → "angry, tense and hard-edged")
  - 장면 분위기(tense·sad·memory 등)
  - 대사에 붙은 서술의 동사. 속삭였다, 외쳤다, 중얼거렸다, 흐느꼈다, 떨리는 목소리, 비웃었다, 한숨 등 15종을 인식한다.
  - 대사 부호("…"로 시작하면 머뭇거림, "…"로 끝나면 말끝 흐림, "!!"는 강조)
  - 연출 판단의 핵심 대사(`emphasis`)는 "무게를 싣고 앞에 짧은 쉼"
- 음성 라우트의 지시문을 "비주얼노벨 성우처럼 분명하지만 과장되지 않게, 연기 지시를 따르라"로 바꿨다.
- **텍스트 호출은 늘지 않는다.** 이미 있는 연출 판단과 본문만 쓴다.

- 괄호 속 지문, 『』「」【】 같은 문장 부호는 읽지 않는다.

### 기기 후처리 (`vn-voice-post.mjs`)
- 앞뒤 무음을 자른다(-45 dBFS, 60ms 여유).
- 모든 대사를 -16 LUFS로 맞춘다(ITU-R BS.1770 측정, 최대 +12 dB, 피크 제한).
- 85Hz 저역 차단과 3.2kHz 명료도 보정을 한다.
- 장소에 맞춰 울림을 준다. 실내는 작은 방, 야외는 거의 없음, 회상은 길고 흐릿하게.
- 해독에 실패하는 브라우저는 기존 `<audio>` 재생을 쓴다.

### 비용과 캐시
- 음성 키는 `vn-voice-2`로 바뀐다. **이미 만든 대사 음성은 예전 키로 찾아 그대로 재생하고 다시 과금하지 않는다.** 새 대사부터 새 연기 지시가 적용된다.
- 음성 제공사는 바꾸지 않았다. 캐릭터 음성 전문 제공사(Typecast, Supertone, ElevenLabs v3) 비교는 실제로 들어 보는 평가가 필요해서 이번 범위에서 뺐다.

## 2. 배경음악 재생 (`vn-work-music.mjs`, `vn-loop.mjs`, `vn-loudness.mjs`)

기존에는 `<audio loop>`로 파일 전체를 반복했다. 그래서 반복할 때마다 끝부분의 페이드아웃과 무음, 인트로가 다시 들렸다. 분위기가 바뀌면 곡이 그 자리에서 잘렸다.

| 항목 | 방식 |
|---|---|
| 음량 통일 | 곡마다 통합 음량(BS.1770)을 재서 -20 LUFS로 맞춘다. 대사 중 낮추는 기존 동작은 유지한다. |
| 템포·마디 | 타격음 세기의 주기성으로 BPM을 찾고, 곡 전체에서 박과 위상을 정밀하게 맞춘다. 두 배·절반 템포 혼동도 보정한다. 생성 곡은 요청 BPM을 힌트로 쓴다. |
| 이음새 없는 반복 | 인트로(평균의 60% 미만)와 페이드아웃(평균의 75% 미만으로 떨어지는 지점)을 제외한다. 그 사이에서 **마디 수가 정수인 구간** 중 끝과 시작이 가장 비슷한 구간을 고른다. 반복할 때 같은 마디 내용끼리 겹쳐 교차 페이드한다(0.5마디 이하). |
| 마디 전환 | 분위기가 바뀌면 지금 곡의 **다음 마디선**에서 교체한다. 마디가 2.5초보다 길면 다음 박에서 바꾼다. 새 곡은 인트로부터 시작한다. |
| 분석 캐시 | 분석 결과를 곡 기록에 저장해서 다음부터는 다시 계산하지 않는다. |
| 대체 경로 | 해독할 수 없는 주소(CORS 미지원 등)는 기존 `<audio loop>` 재생을 쓴다. |

- 기기에 올린 곡, 패키지의 곡 주소, AI로 만든 곡 모두에 적용된다.
- 기존 합성 배경음(무료)은 따로 유지한다.

## 3. AI 배경음악 (`vn-music-ai.mjs`, `/api/gemini/music`)

### 조사와 결정 (2026-09-26)

| 후보 | 판단 |
|---|---|
| **Google Lyria 3.5 / Lyria 3 Clip (Gemini API)** | **채택.** 이용자가 이미 입력한 Gemini 키로 쓸 수 있다. 공식 API이고 44.1kHz 스테레오를 만든다. 반주만 요청할 수 있고 BPM·시간대별 구조를 프롬프트로 지정할 수 있다. 곡당 과금(3.5 $0.08, Clip $0.04, 무료 등급 없음)이다. 모든 곡에 SynthID 워터마크가 들어간다. |
| ElevenLabs Music API | 품질과 상업 이용 조건이 좋다. 그러나 이용자에게 별도 계정과 키가 필요하고, 영화·TV 용도 등은 플랜에 따라 권리가 다르다. 다음 선택지로 남긴다. |
| Suno / Udio | 공식 공개 API가 없어 약관 위험이 있다. 제외했다. |
| 무료 음원 모음(DOVA-SYNDROME 등) | 품질은 좋지만 웹 서비스에 넣어 배포하는 조건이 곡마다 달라 일괄 탑재하지 않았다. 이용자가 직접 올리는 기존 기능을 그대로 쓸 수 있다. |

**요청 형식 검증:** Google 공식 cookbook(`quickstarts/Get_started_Lyria`, generateContent 버전)의 요청 구조를 따랐다. 실제 Google API에 무효 키로 보내서, 요청 본문이 형식 검사를 통과해 키 인증 단계(`API_KEY_INVALID`)까지 가는 것을 `lyria-3.5`와 `lyria-3-clip-preview` 모두에서 확인했다. 모르는 필드를 넣으면 형식 오류가 나는 것도 확인했다. 이 확인은 생성과 과금을 일으키지 않는다.

### 사용 방법
설정 → 이 작품의 음악 → **AI로 이 작품의 배경음악 만들기**
1. 분위기를 고른다(평상시·따뜻함·슬픔·긴장·공포·회상).
2. 모델을 고른다(Lyria 3.5 약 90초, 또는 Clip 30초).
3. 음악 방향을 적는다(선택).
4. 만들기를 누른다. 예상 금액이 버튼에 표시된다(6곡 × $0.08 = $0.48).

- 한 번에 한 곡씩 생성하고 중지할 수 있다. 곡마다 30초~2분 정도 걸린다.
- 만든 곡은 이 기기의 작품별 저장소에 저장되고 미리 듣기가 가능하다. 다시 만들면 직전 곡 1개를 **되돌리기**용으로 보관한다.
- 읽기 설정의 음악을 "작품 음원"으로 선택하면 위의 재생 엔진으로 재생된다. 플레이 중에는 생성하지 않으므로 대기가 없다.
- 비용 탭에 "AI 음악"으로 기록된다(완료된 곡만 곡당 요금).

### 곡 설명 설계
- **작품 공통 정체성:** 작품의 장르·제목·요약에서 악기 구성을 고른다(판타지, 호러, 미스터리, 사극, SF, 현대 판타지, 학원 등). 작품 이름으로 정해진 조성 한 쌍(단조·장조)과 반복되는 주제 동기를 모든 분위기 곡에 똑같이 요청한다. 곡끼리 한 작품처럼 들리게 하려는 설계다.
- **분위기별 BPM:** 평상시 88, 따뜻함 76, 슬픔 66, 긴장 138, 공포 60, 회상 72.
- **반복에 맞는 구조:** 짧은 인트로 → 템포·강도가 일정한 본 구간 → 본 구간으로 돌아가는 연결부. 끝맺음·페이드아웃·템포 변화는 넣지 말라고 지시한다. 보컬·가사는 금지한다.
- 작가의 음악 방향과 작품 정보는 지시가 아닌 데이터로 넣는다.

### 알아 둘 점
- Lyria는 오디오를 참조로 받지 않는다. 그래서 같은 멜로디의 변주를 보장할 수는 없고, 악기·조성·동기를 글로 맞추는 방식이다.
- Google 문서의 모델 페이지는 상업 이용 조건을 따로 밝히지 않는다. 공개·상업 배포 전에 Gemini API 약관을 확인해야 한다.

## 검증
- Node 테스트 375개 통과(신규 18개), `tsc --noEmit`, 변경 파일 eslint, `npm run build` 성공.
- 신규 테스트:
  - BS.1770 기준음(0 dBFS 997Hz → -3.01 LUFS, 채널·표본율)
  - 음량 보정 상한
  - 대사 무음 경계
  - 합성 곡 3종(120·84·140 BPM)의 템포 오차 0.3 BPM 이내, 마디선 반복 구간, 인트로·페이드 제외
  - 마디·박 대기
  - 반복 계획
  - 가짜 AudioContext에서 **다음 마디선 전환**
  - 한국어 전처리 10종, 연기 지시
  - 음성 새 키와 **예전 음성 무과금 재생**
  - 음악 설명의 공통 정체성·분위기별 BPM·반주 전용
  - 되돌리기 1단계
  - Lyria 비용·분류
  - 음악 라우트의 요청 형식·오류 숨김·음원 누락·차단 처리
- **실제 Chromium의 Web Audio에서 확인:**
  - 20초 합성 곡에서 두 번째 반복이 반복 끝 - 교차 페이드 시점(15.266초)에 마디 위치(0.994초)에서 시작했다.
  - 17.73초에 분위기를 바꾸자 다음 마디선인 18.27초에 새 곡이 시작했다.
  - 대사 음성은 0.54초부터 0.92초 길이로 잘려 재생되고 종료 이벤트까지 확인했다.
  - 음악 설정 화면에서 선택 곡 수에 따른 예상 금액, 순차 생성, 미리 듣기, 되돌리기를 확인했다.
- **확인하지 못한 것:** 실제 유료 Lyria·음성 생성은 호출하지 않았다. 생성된 곡이 요청한 BPM·구조를 얼마나 지키는지, 실제 곡에서 반복 이음새가 얼마나 자연스러운지, 새 연기 지시로 음성이 실제로 얼마나 좋아지는지는 실제 키로 들어 보고 판단해야 한다. 반주 없이 패드만 있는 곡처럼 박을 찾기 어려운 곡은 마디 정렬 없이 3초 교차 페이드 반복으로 대체된다.
