# v13.9.7 — 짧은 머리·드러난 이마의 배율과 인물 눈높이

## 원인과 수정

- 기존 측정은 피부가 처음 나타나는 위치를 눈높이로 간주했습니다. 이마가 드러난 오요한은 눈높이를 너무 높게 추정했습니다.
- 얼굴 폭보다 좁은 짧은 머리 윤곽을 버리고 가상의 큰 머리 폭으로 대체하면서, 화면에서 인물이 작고 아래로 내려앉았습니다.
- 짧은 머리 윤곽도 측정에 사용하고, 이마가 드러난 경우 눈높이 추정 구간을 조정합니다. 머리 윤곽을 공통 배율 기준으로 삼아 앞머리·귀·얼굴 각도에 따른 피부 폭 차이가 확대율을 과도하게 바꾸지 않게 합니다.
- 사용자가 지정한 연출 기본값: 작품에 키가 명시되면 그 값을 우선합니다. 공개 외형에 성인 남성임이 명시된 경우 키가 없으면 178cm를 적용합니다. 오요한은 이 기준을 사용하고 홍재는 기존 163cm를 유지합니다. 작품의 원본 설정을 변경하지 않습니다.
- 저장된 이미지 자체를 기기에서 다시 배치합니다. 이미지 API 추가 호출이나 저장 이미지 삭제는 없습니다.

## 검증과 한계

- 실제 플레이 화면에서 내려받은 홍재·나디아·오요한 이미지를 현재 `displaySprite`, `heightScale`, `stagePositions`, `vn-reader.css`로 표시하여 2명·3명 배치를 브라우저에서 확인했습니다.
- 짧은 머리, 드러난 이마, 큰 투명 여백, 갈색 머리 하이라이트, 키 기본값과 명시값 우선순위에 회귀 테스트를 적용했습니다.
- 픽셀 기반 추정이므로 모든 화풍·극단적인 옆얼굴·모자에 대한 정확도를 보장하지는 않습니다. 얼굴을 찾지 못하면 기존 전체 윤곽 배치로 돌아갑니다. 짧은 상반신 이미지에는 존재하지 않는 하체를 만들지 않습니다.
- 추가 유료 이미지 생성과 전체 게임 재진행은 검증 범위에 포함하지 않았습니다. 현재 작성 중인 사용자 탭은 자동으로 새로고침하지 않습니다.
