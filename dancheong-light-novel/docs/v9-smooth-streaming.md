# v9 — 스트리밍과 확정 본문의 타자 효과 통일

2026-09-25. v8의 첫 문장 스트리밍을 유지하면서 확정 전의 끊기는 표시를 수정했다.

## 변경

- 공개된 스트리밍 문장을 즉시 통째로 옮기던 처리를 지속적인 글자 표시 큐로 바꿨다. 확정 전후에 같은 속도와 문장부호 간격을 사용한다.
- 후속 묶음이 도착하거나 턴이 확정돼도 기존 타이머와 표시된 접두부를 유지한다. 클릭으로 현재 문장을 즉시 표시하는 동작과 설정의 즉시 모드도 유지한다.
- 본문의 페이지 구성이 같으면 같은 문단 요소를 사용한다. 데이터 수신마다 문단 요소를 제거하고 다시 만들지 않는다.
- 배포용 Cortex 어댑터에서 기존 타자 효과의 속도만 위임한다. 공개·미디어 게이트는 그대로 거쳐 `displayText`에 전달하며, 원본 Cortex 파일과 저장된 표시 속도 설정은 변경하지 않는다.
- 첫 글자는 추가 버퍼 대기 없이 표시를 시작한다. 응답이 아직 오지 않은 구간의 네트워크 대기 자체를 없애는 변경은 아니다.

## 검증

- 단위·회귀 검사 99개, TypeScript 검사 통과.
- 실제 배포 HTML의 Cortex 타자 함수를 실행해 공개된 허용 접두부만 전달하고 기존 게이트를 유지하는지 검사했다.
- 별도 Muse 작업 사본에서 작성된 13개 타이머 검사를 주 개발자가 직접 검토·실행한 뒤 통합했다.
- 브라우저에서 불규칙한 네 번의 묶음을 수신하는 fixture를 실행했다. 화면 변화당 최대 1글자, 같은 문단 요소 교체 0회, 관측된 글자 간격 중앙값 약 31ms였다.
- 21글자가 표시된 상태에서 턴을 확정한 직후에도 21글자를 유지했고, 남은 글자가 동일한 큐에서 끝까지 표시됐다. 브라우저 오류는 없었다.

브라우저 검증은 합성 응답으로 수행했으며, 이 수정 검증을 위해 사용자의 실제 이야기 턴이나 유료 생성 요청을 추가하지 않았다.
