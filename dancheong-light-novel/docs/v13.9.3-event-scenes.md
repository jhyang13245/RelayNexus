# v13.9.3 — 사건 장면 자동 연출과 표정 재사용

## 원인과 변경

기존 풍경 이미지는 인물·동작 없이 장소만 그리도록 요청했습니다. 사건 CG는 기본 꺼짐이었고, 절정 장면 및 등록 인물의 등장에 한정되어 사물의 공격을 보여주기 어려웠습니다.

- 기존 인물·연출 판단 요청에서 중요한 물리적 사건도 함께 고릅니다. 별도 판단 호출을 추가하지 않습니다. 종이다발이 문틀을 후려치는 동작처럼 사물만 있는 사건도 선택할 수 있습니다.
- 사건에는 현재 문장의 원문 근거, 화면의 중심 동작, 실제로 그려야 하는 인물을 붙입니다. 인용 대사나 미래 문장의 근거는 제외합니다. 평범한 대화·몸짓, 회상·가정·비유·부정된 사건과 이미 끝난 사건의 재설명은 선택하지 않도록 요청합니다.
- 사건 이미지는 배경 전체를 채우며, 행위 주체·대상·충돌·결과를 중심으로 새 구도를 만듭니다. 풍경 참조는 장소의 연속성을, 실제 참여 인물 참조는 외형을 유지합니다. 목격자 나디아에게 종이다발의 공격을 옮기지 않습니다.
- 현재 문단과 다음 두 문단까지, 이미 공개된 본문에 한해 미리 준비합니다. 문단당 최대 한 장이며 이미지 호출의 기존 동시 제한 2개를 유지합니다.
- 사건 문장 이전에는 이미지를 노출하지 않습니다. 사건 문장과 같은 문단의 후속 반응에서는 같은 이미지를 유지하고 입상을 숨깁니다. 일반 장면에서는 풍경·입상으로 돌아갑니다. 전환은 0.24초로 줄였습니다.
- 인물 없는 장면도 연출 판단을 수행합니다. 새 연출 정책을 적용하려고 인물·연출 판단 캐시만 갱신하며, 기존 풍경·입상·표정 캐시 키는 유지합니다.

## 비용과 설정

- 기존 절정 CG 옵션을 대체하는 **사건 장면 연출 → 자동 · 중요한 동작과 사건**이 기본 적용됩니다. 새 옵션을 끄면 이후 접속에도 꺼짐을 유지합니다.
- 사건 이미지는 선택한 인물 이미지 모델을 사용하며, 기존 사용량·비용 계측에 포함됩니다. 생성은 추가 이미지 비용이 발생하므로 설정 설명에 표시합니다.
- 동일 인물·외형·그림체·감정에 맞는 표정은 턴이나 대사가 달라도 저장된 이미지를 재사용합니다. 다른 이미지 제공자로 전환해도 이미 만들어진 적합한 표정을 무조건 다시 생성하지 않습니다.
- 동일 사건으로 돌아오거나 브라우저를 다시 열면 저장된 사건 이미지를 재사용합니다. 예전의 감정 불일치 표정에 대한 v13.9의 교체 정책은 유지합니다.

## 검증과 한계

- 자동 검사 221개 통과. 인물 없는 종이다발 공격, 현장 밖 인물 참조 배제, 현재 문장 근거, 선행 준비·선행 노출 방지, 이미지 중복 요청 방지, 오프라인 사건 복원, 진지함→놀람→진지함의 표정 재사용을 포함합니다.
- TypeScript 검사 통과.
- 로컬 브라우저에서 실제 화면 모듈과 합성 API 응답으로 풍경·입상→사건 장면→기존 입상 흐름, 사건 후 반응 대사, 재접속·이전 문장 복원, 추가 이미지 요청 없음 확인.
- 브라우저 확인은 표시 위치를 구분하는 테스트 이미지로 수행했습니다. 실제 유료 이미지 생성 및 실제 모델의 사건 판단 정확도·그림 품질은 이 검증에 포함하지 않습니다.
