# v13.5 · 본문 상황으로 해석하는 표정

- 표정 이미지에 눈썹·눈·입 모양을 지정하는 감정별 프리셋을 보내지 않습니다. 이전 공개 맥락과 현재 읽기 구간까지의 본문, 대상 인물의 공개 정보를 전달해 이미지 모델이 자연스럽게 해석하도록 합니다.
- 얼굴은 하나의 새 일러스트로 그리며 인물의 정체성·머리·눈 색·장신구·화풍을 유지합니다. 몸 자세·의상·화면 구도는 기존 스프라이트에 맞춥니다.
- 표정 분류는 뚜렷한 감정 변화 감지와 이미지 재사용에만 쓰고 이미지 프롬프트에는 넣지 않습니다. 매 대사나 문단 변경으로 이미지를 다시 만들지 않습니다.
- 현재 읽기 구간 이후의 문장은 표정 생성 맥락에서 제외합니다. 구간 오프셋은 턴 기준이므로 문단 문자열을 단순히 잘라 쓰지 않고 공개 읽기 구간을 순서대로 사용합니다.
- 기존 배경과 기본 인물은 유지합니다. 이전 표정 이미지도 저장해 오프라인·로딩 중 사용할 수 있으며, 필요한 표정만 새 방식으로 한 번 교체합니다. 기기 저장 데이터 삭제나 전체 이미지 재생성은 하지 않습니다.
- `/image-compare`도 동일한 프롬프트 함수를 사용합니다. 기존 얼굴 동작 예시 대신 사용자가 비교할 실제 본문을 입력합니다. 과거 비교 영수증과 결과는 그대로 복원합니다.
- 기존 자산 재사용·감정 유지·현장 인물 판정 테스트와 새 본문 경계/캐시 이전 검증을 실행합니다. 이번 수정 확인을 위해 유료 이미지를 추가 생성하지 않으므로 실제 그림의 선호도 개선은 아직 확인하지 않았습니다.
