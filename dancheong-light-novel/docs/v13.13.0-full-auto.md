# v13.13.0 — 완전 자동

## 사용법

플레이 화면 하단 **완전 자동** 또는 **Shift+A**를 누릅니다. 본문 생성용 API 키와 AI 음성용 OpenAI API 키가 필요합니다. 활성화하면 버튼이 **자동 중지**로 바뀝니다.

1. 현재 문장부터 서술과 대사를 AI 음성으로 읽습니다. 신원이 확인된 화자는 기존 인물별 목소리·캐시를 사용합니다. 서술과 신원 미확인 인용문은 중립적인 낭독 목소리를 사용합니다.
2. 본문 표시와 음성 재생이 모두 끝난 뒤 다음 문장으로 넘어갑니다. 아직 쓰고 있는 문장은 완성될 때까지 기다립니다. 다음 문장이 이미 공개되었다면 전체 턴 완료를 기다리지 않고 읽습니다.
3. 마지막 문장을 읽고 집필·판정·저장이 완료되면 기존 **장면 이어가기** 명령을 실행합니다. 추천 선택지를 무작위로 고르거나 플레이어의 새로운 행동을 만들어 입력하지 않습니다.
4. 새 턴의 첫 공개 문장부터 같은 과정을 반복합니다. 같은 턴에 중복 요청하지 않으며, 실패한 유료 요청을 자동 재시도하지 않습니다.

## 중지와 기존 설정

- **자동 중지**, 수동 앞/뒤 이동, 기록·설정·메뉴·저장 화면, 메인화면 이동, 탭을 벗어나거나 화면을 잠그면 완전 자동을 해제합니다. 재시작은 직접 누릅니다.
- 오류, 음성 재생 차단, 키 누락, 저장 오류, 복구 또는 판정 보완 대기에서는 정지합니다. 이야기 종결 시 마지막 공개 문장까지 읽고 멈춥니다.
- 중지 전에 이미 서버에 보낸 집필·이미지·음성 요청은 끝날 수 있습니다. 중지 후에는 다음 자동 턴을 보내지 않습니다. 음성 재생은 즉시 정지합니다.
- 켜진 상태를 저장하거나 다른 작품·저장 슬롯으로 이어받지 않습니다. 기존 AI 음성 ON/OFF 설정은 덮어쓰지 않고 완전 자동이 켜져 있는 동안만 낭독을 활성화합니다.
- 기존 **자동**은 문장 넘기기 기능으로, 입력 차례에서 멈추는 기존 동작을 유지합니다. **읽은 부분** 건너뛰기도 별도로 유지합니다.

## 사용료와 개인정보

본문·이미지·음성은 기존에 선택한 제공사와 키로 생성하며 기존 비용 기록에 반영됩니다. 완전 자동 중에는 새 본문과 음성 생성에 사용료가 계속 발생합니다. 이미지 재사용 규칙과 음성 캐시는 동일하게 적용합니다. 낭독은 화면에 공개된 본문만 사용합니다. 아직 공개되지 않은 원고·비공개 프로필은 전달하지 않습니다.

## 검증

- 실제 셸의 자동 진행·중지·제출 함수를 가짜 엔진과 타이머로 실행하여 두 턴 연속 진행, 중복 차단, 제출 직전/도중 중지 이후 재개 방지를 검사합니다.
- 음성 완료 대기, 스트리밍 문장 대기, 판정·저장·종결 조건, 입력 보존, 오류 정지, 낭독/인물 음성 구분, 음성 캐시 재사용, 시작 제스처에서 오디오 활성화를 검사합니다.
- 전체 자동 검사와 TypeScript 검사, 로컬 UI 확인 및 배포 빌드를 수행합니다. 실제 유료 API를 호출하는 무제한 플레이 검사는 수행하지 않습니다. 모바일 브라우저의 백그라운드·잠금 상태에서는 자동 진행을 지원하지 않습니다.

원본 Cortex 엔진과 작품·저장 데이터 형식은 변경하지 않습니다.
