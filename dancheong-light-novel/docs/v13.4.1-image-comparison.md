# v13.4.1 · 이미지 모델 비교 화면

- `/image-compare.html`에서 브라우저에 저장된 OpenAI/Gemini 키로 공통 참조 이미지와 표정 요청을 각 모델에 한 번씩 보냅니다. 업로드한 이미지·키·생성 결과는 공개 소스나 서버 저장소에 넣지 않습니다.
- 기존 인물 Low 요청 및 단청의 크로마 제거·스프라이트 정규화를 사용합니다. 원본 결과, 표시용 PNG, 참조 SHA-256, 공통 프롬프트, 응답 사용량, 요청 시간, 화면 준비 시간과 비용 추정을 다운로드할 수 있습니다.
- 비교 결과는 플레이 저장 데이터와 별도의 기기 저장소에 보관하고, API 호출은 기존 비용 장부에도 기록합니다. 새로고침은 생성 요청을 재전송하지 않습니다.
- 비교 호출은 `strictModel: true`로 Flare 모델 대체를 금지합니다. 기존 플레이 호출의 fallback 동작은 유지됩니다. 자동 재시도는 없습니다.
- 비용은 공식 Standard 토큰 단가 기반 추정값입니다. 실제 청구액은 공급사 내역에서 확인해야 합니다. 사용량이 없으면 미확인으로 표시합니다.
- 모델별 단독 실행도 지원하여 다른 모델의 성공 결과를 중복 생성하지 않고 확인할 수 있습니다.
