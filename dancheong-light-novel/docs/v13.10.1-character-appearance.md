# v13.10.1 — 인물 외형과 모바일 배치

## 외형 전달 수정

원작의 `appearance`는 소개 문구인 `publicInfo`와 다른 필드다. 기존 VN은 Cortex의 공개 소개만 이미지 요청에 전달하면서 안경, 머리 형태 등의 작가 설정을 누락했다. 이제 외형도 Cortex 공개 판정을 거쳐 `publicAppearance`로 전달한다. 비공개·정체 공개 전 외형을 그대로 복사하지 않는다.

인물 생성에는 대상 외형과 공개된 다른 인물들의 묘사를 함께 제공해 얼굴을 구별하도록 지시한다. 대상 기준 이미지가 없는 경우 다른 인물의 품질 참조 이미지를 보내지 않고 글로 된 공통 품질 기준을 사용한다. 대상의 공식 기준 이미지가 있으면 계속 우선 사용한다.

이미 저장된 입상은 업데이트만으로 재생성하지 않는다. **메인화면 → 만난 인물 → 외형 설정으로 다시 그리기 · 유료**에서 해당 인물만 교체할 수 있다. 선택한 인물 이미지 모델과 키를 사용하며 비용 탭에 기존 이미지 요청과 동일하게 기록된다. 기존 생성 얼굴을 재생성 참조로 넣지 않는다. 성공한 이미지를 기기에 저장한 뒤에만 교체한다. 실패하면 기존 이미지와 이야기를 유지한다.

교체한 기본 외형은 같은 작품의 해당 인물에만 적용한다. 이전 얼굴의 표정·복장·모션 캐시는 새 얼굴로 섞이지 않으며 필요한 새 변형부터 생성한다. 기존 데이터는 삭제하지 않는다. 공식 원화가 없는 인물의 세부 디자인을 모델이 해석하므로 모든 생성 결과의 시각적 구별을 보장하는 얼굴 인식 검사는 아니다.

## 모바일

- 높이 600px 이하 가로 화면에서 별도 확대율과 아래쪽 기준점 적용.
- 확대 장면의 과도한 확대·아래 이동 제거, 본문 왼쪽 54%와 인물 오른쪽 배치.
- 세로 화면에서는 2명·3명의 공통 표시 높이를 줄여 얼굴이 화면 가장자리로 밀리는 현상 완화.
- 데스크톱의 기존 배치와 작품에 지정된 상대 신장 비율 유지.

검증: 실제 Cortex 공개 판정을 사용한 외형 전달·비공개 차단, 명시적 재생성·실패 유지·재접속·새 표정 기준·다른 작품과 인물 분리 테스트. 실제 UI에서 852×393 가로, 390×844 세로와 1명·3명 배치, 재생성 버튼의 저장 완료 흐름을 로컬 모의 이미지 응답으로 확인했다. 실기기 Safari 및 이번 수정으로 만든 유료 인물 결과의 미적 품질은 검증하지 않았다.

## 음성 후보 조사

이번 버전은 TTS 제공사를 교체하지 않는다. Eleven v3와 Fish Audio S2.1 Pro는 한국어와 감정 지시를 지원하는 API 후보다. 성우 수준 여부는 실제 캐릭터 목소리와 한국어 대사를 사용한 청취 비교가 필요하다.
