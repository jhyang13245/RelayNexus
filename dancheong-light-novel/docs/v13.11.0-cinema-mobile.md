# v13.11.0 — 장면 연출과 모바일 화면

## 추가된 연출

- 기존 인물·연출 판단 호출에 `transition`, `cutin`, `emphasis`를 함께 받습니다. 연출만을 위한 텍스트 호출은 추가하지 않습니다.
- 사선·원형·블라인드·먹 번짐 무늬로 검은 마스크가 닫히고 열립니다. 기존 배경 교차 전환과 함께 사용합니다.
- 확인된 현장 인물의 기존 입상에서 눈·얼굴 띠를 기기 안에서 잘라 보여 줍니다. 추가 이미지 비용이 없습니다. 본문의 근거 문장이 일치해야 하며, 얼굴 측정에 실패하면 생략합니다.
- 클로즈업 레터박스·풍경 흐림, 충격 순간 필름 질감, 공포·살의의 붉은 톤, 넓은 구도의 느린 카메라 이동, 미세한 호흡 움직임을 추가했습니다. 사건/별도 구도 이미지의 얼굴은 배경 흐림으로 흐리지 않습니다.
- 중요한 문장은 원문 그대로 검은 화면 중앙에 표시합니다. 읽기·자동 넘김은 잠시 멈추고 화면을 누르면 즉시 해제됩니다. 새로 읽는 확정 턴의 전환에는 짧은 장소 제목 카드를 표시합니다. 스트리밍 첫 문장을 카드로 막지는 않습니다.
- ‘영화식 화면 연출’을 끌 수 있습니다. 기기 또는 앱의 움직임 최소화 설정에서는 추가 움직임·일시적 컷인·강조/제목 카드를 생략합니다.
- 별도 구도 생성에 상반신 구도를 추가했습니다. 기존 입상을 확대하는 방식과 별도로, 같은 인물·복장·장소를 참조하는 16:9 상반신 컷을 생성합니다. ‘별도 구도 이미지’는 기본 OFF이며, 켠 경우 추가 이미지 비용이 듭니다. 동일 컷은 저장해 재사용합니다.
- 같은 장소의 낮/저녁/밤은 기존 장소 기준 이미지를 편집·참조하는 경로를 유지합니다. 장소 키 또는 작품이 다르면 공유하지 않습니다.

## 눈·입 움직임 — 실험 기능

기존 독립 재생성 프레임을 사용하는 설정값은 OFF로 전환합니다. 새 ‘마스크 편집’ 옵션을 명시적으로 선택해야 동작합니다.

- 현재 연결은 **OpenAI 인물 모델에서만** 사용합니다. Gemini 인물은 정지 입상을 유지하며 이 기능 때문에 다른 모델로 우회하지 않습니다.
- 기존 입상을 768×1024 PNG로 준비하고 눈/입의 작은 투명 알파 마스크를 이미지 편집 API에 보냅니다. 기존 입상 선택·표정 교체 규칙은 유지됩니다.
- 원본과 정렬을 검사합니다. 마스크 밖 얼굴/몸이 움직인 결과는 버리고, 합격한 결과도 마스크 내부 RGB만 원본에 합성합니다. 외부 픽셀과 실루엣 알파는 원본을 보존합니다.
- 거절한 유료 결과는 ‘사용 불가’ 기록을 저장하여 새로고침 후 자동으로 다시 결제하지 않습니다. 현재 기본 입상은 계속 표시됩니다.
- 실제 모델의 눈/입 연기 품질은 이번 배포에서 유료 호출로 검증하지 않았습니다. 생성 품질과 얼굴 측정의 한계가 있어 실험 기능으로 둡니다.

OpenAI 마스크는 엄밀한 픽셀 경계 준수를 보장하지 않으므로 앱에서 정렬 검사와 원본 보존을 수행합니다. [공식 이미지 편집 안내](https://developers.openai.com/api/docs/guides/image-generation).

## 작품별 음악

설정의 ‘이 작품의 음악’에서 평상시·따뜻함·슬픔·긴장/전투·공포·회상별 MP3/OGG/WAV/M4A 파일(최대 20MB) 또는 HTTPS 직접 음원 주소를 등록합니다. 제목·출처·사용 허락을 기록하고 ‘음악: 작품 음원’을 선택합니다.

- 파일은 **현재 기기/브라우저의 작품별 저장소**에 있습니다. 수동 저장 슬롯이나 전체 소스 ZIP에는 들어가지 않습니다.
- 등록된 분위기 음원이 없으면 그 작품의 평상시 음악을 사용합니다. 둘 다 없으면 조용하게 유지합니다.
- 작품 패키지의 `runtime.packageContract.presentation.music`에도 같은 분위기 키로 `{url,title,credit,license}`를 넣을 수 있습니다. 기기에 등록한 곡을 우선합니다. URL은 직접 재생과 CORS를 지원해야 합니다.
- 곡 교체 시 페이드하고 AI 대사 중 볼륨을 낮춥니다. 브라우저 정책상 첫 터치가 필요할 수 있습니다. 작품 이동·탭 숨김 시 재생을 중지합니다.
- 배포에 상용/제3자 음원은 포함하지 않았습니다. 기존 합성 배경음은 별도 선택지로 유지합니다.

## 모바일

- 세로는 화면 높이뿐 아니라 폭으로도 입상 확대를 제한합니다. 1/2/3명에 각각 적용하며 설정된 상대 신장 차이는 유지합니다.
- 짧은 가로 화면은 본문 왼쪽/인물 오른쪽 배치를 유지하고, 컷인도 오른쪽에 제한합니다.
- 세로 조작 버튼은 4열 두 줄로 정리하고, 저장 슬롯 버튼은 별도 넓은 줄에 배치합니다. 안전 영역과 스크롤 가능한 설정/저장 창을 유지합니다.
- 컷인·레터박스·강조 문장에 세로 및 짧은 가로 전용 크기 규칙이 있습니다. 화면 회전은 진행 상태를 다시 불러오지 않습니다.
- 행동·대사 입력, API 키와 설정 입력칸은 터치 화면에서 최소 16px로 표시해 작은 글꼴로 인한 iOS 포커스 자동 확대를 방지합니다. 사용자의 두 손가락 확대 기능은 유지합니다.

## 검증 범위

순수 로직/모의 API 테스트로 원문 근거·현장 인물 제한, 무늬 마스크, 비용 없는 크롭, 편집 마스크 전달/잘못된 요청 거절, 외부 픽셀 보존·정렬 거절·새로고침 후 재결제 방지, 작품별 음악 선택을 확인했습니다. 기존 전체 테스트와 타입 검사를 함께 실행합니다.

기존 인물 자산을 넣은 로컬 검증 화면에서 데스크톱 및 390×844 / 360×640 세로, 844×390 / 667×375 가로의 렌더링·컷인·강조·저장·설정 UI를 검사합니다. 이는 브라우저 화면 크기 검증이며 실제 iOS/Android 기기, 유료 이미지/음성 생성, 사용자가 등록할 개별 음원의 권한·재생 호환성까지 검증했다는 뜻은 아닙니다.

Cortex 원본, 너름/지음 연동, 저장 슬롯 구조는 변경하지 않습니다. 단청 본 사이트 통합은 베타 완성 후 별도 진행합니다.
