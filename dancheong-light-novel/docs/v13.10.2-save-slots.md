# v13.10.2 · 수동 저장·불러오기

## 사용 방법

- 작품 목록, 작품 타이틀, 플레이 하단 도구, 우측 메뉴의 **저장·불러오기**를 엽니다.
- 전체 작품에서 10개 슬롯을 공유합니다. 빈 슬롯에는 저장, 기존 슬롯에는 덮어쓰기와 불러오기가 표시됩니다.
- 작품명, 저장 시각, 장소, 문장 위치, 본문 일부와 준비된 배경 미리보기를 표시합니다.
- 덮어쓰기와 불러오기는 확인 후 진행합니다. 본문·판정·이미지 저장 작업 중에는 완료 후 사용할 수 있습니다.
- 같은 작품을 불러오면 이어하기도 그 시점으로 바뀝니다. 남길 분기는 다른 슬롯에 먼저 저장하세요. 다른 작품의 현재 진행은 그 작품의 이어하기에 보관합니다.

## 저장 범위

- Cortex 전체 백업: 시나리오, 정사 세션, 턴과 선택, 되감기·복구 장부, 패키지 및 엔진 이미지.
- VN 읽던 문장과 읽은 범위, 만난 인물, 선택 화면 상태, 작품별 그림체·고정 입상·교체 입상 선택, 도입 이미지.
- 이미 생성한 VN 배경·입상·표정·구도·음성은 같은 브라우저의 기존 이미지 저장소를 공유합니다. 슬롯마다 전체 그림을 중복 저장하거나 새 그림을 만들지 않습니다. 이후 플레이에서 없는 이미지가 필요하면 기존 생성 규칙을 따릅니다.
- API 키, 제공사 선택, 기기별 읽기·음성 설정, 누적 사용량·비용은 슬롯으로 되돌리지 않습니다. 별도의 클라우드 동기화나 저장 파일 내보내기 기능은 이번 범위에 포함되지 않습니다.

슬롯과 이어하기는 브라우저 IndexedDB에 보관합니다. 다른 기기/브라우저로 자동 이동하지 않으며 브라우저 사이트 데이터를 삭제하면 함께 지워집니다. 소스 ZIP에는 이용자의 슬롯·키·이미지가 포함되지 않습니다.

## 저장 안정성

기존 이어하기 DB와 독립된 `dancheong-vn-manual-slots-v1`을 사용합니다. 무거운 백업과 목록용 요약은 같은 트랜잭션에서 갱신하고 완료 이벤트 이후에만 성공을 표시합니다. 기존 슬롯은 쓰기 실패 때 유지됩니다. 슬롯 revision 비교와 Web Locks를 이용해 다른 탭에서 변경된 슬롯을 조용히 덮어쓰지 않습니다.

불러오기는 Cortex 원본의 미디어 스테이징·원자적 import를 사용합니다. 엔진 import와 별도 VN 저장소 사이에서 탭이 닫히면, 기록한 불러오기 의도와 현재 엔진의 작품·월드·턴 내용을 비교해 다음 부팅에서 화면 저장을 마무리합니다. 엔진을 불러오기 전에 실패한 의도는 현재 작품에 적용하지 않습니다. 불러오기 중에는 렌더/자동 준비를 잠가 다른 작품 정보가 섞이지 않게 합니다.
