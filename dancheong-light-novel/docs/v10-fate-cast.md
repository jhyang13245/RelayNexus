# v10 — 본문에 등장한 인물과 기존 저장 복구

2026-09-25. Fate/Seoul 플레이에서 배경만 표시된다는 피드백에 따른 수정.

## 확인한 원인

- 비주얼노벨 화면은 `scenario.scene.presentCharacterIds`에 있는 인물만 선택했다. Cortex의 산문 중심 진행에서는 이 명단이 도입부 값으로 남아 있을 수 있다.
- Fate/Seoul 출간 패키지에는 `첫 등장 뒤 공개:` 또는 `첫 물리 등장 뒤 공개:` 형태의 인물 공개 조건이 있다. 공개 산문·화자 기록에 따른 외형 공개 계산도 필요하다.
- 한 번 저장된 `vnScene`은 인물 목록이 비어 있어도 다시 계산되지 않았다.

## 변경

- 기존 현장 명단에 Cortex의 공개 본문·화자 기반 인물 근거를 더한다. 실제 엔진의 `imageCharacters`를 사용한다.
- 저장 시점이 화면 갱신보다 빠르더라도 공개된 첫 등장을 인식하도록 별도 런타임 사본에서 `refreshPublicAppearances`를 실행한다. 원본 정사나 공개 조건을 수정하지 않는다.
- 같은 배경의 직전 인물은 유지하고, Cortex가 화면 밖·간접 언급으로 제외한 이름과 참조 금지 인물은 제거한다.
- 장면 메타데이터 버전을 3으로 올려 현재 저장의 최신 확정 턴을 다시 계산한다. 기존 이미지 캐시 키는 유지한다. 과거 모든 턴을 현재 세계 상태로 다시 쓰지는 않는다.

## 검증과 범위

- 112개 단위·회귀 검사 및 TypeScript 검사 통과.
- 실제 Cortex 원본 모듈로 첫 등장 공개, 검증된 화자 이름, 명시적 비밀 정체 유지, 전화 너머 상대 제외를 검사했다.
- 브라우저 fixture에서 `현장 명단=hero`, `기존 장면 버전=2`, `인물=[]`인 저장을 복구했다. 장면 버전 3과 나디아 인물 이미지가 표시됐으며 현장 명단은 원본 그대로였다. 이미지 응답은 합성 자산을 사용했다.
- Muse가 별도 사본에서 작성한 회귀 검사 10개는 주 개발자가 직접 읽고 실행한 뒤 통합했다.
- 사용자가 실제 플레이 중인 Fate/Seoul 장면은 아직 공유되지 않았다. 확인 가능한 브라우저는 기성학원 저장이므로, 이 문서는 사용자의 해당 실전 장면을 직접 확인했다고 주장하지 않는다.
