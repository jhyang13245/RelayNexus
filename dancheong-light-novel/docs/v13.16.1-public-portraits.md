# v13.16.1 · 일반 등록 인물의 첫 입상 누락

## 원인과 변경

등록명과 `preRevealAlias`가 같은 일반 인물도 Cortex가 외형 비공개(`referenceMode: NONE`)로 반환했습니다. 기존 VN 보정은 `publicInfo`에 특정 '첫 등장 뒤 공개:' 문구가 있는 인물만 처리하여, 일반 공개 소개를 가진 인물은 이미지 생성 후보에서 빠졌습니다.

VN 공개 외형 투영에 다음 경우를 추가합니다.

- 공개 소개가 있고 등록명과 공개 전 호칭이 정확히 같음.
- 작품에 `imageOnFirstAppearance: true`가 명시됨.
- 비밀·비공개·명시적 공개 조건 또는 소개문 안의 조건부 공개 지시가 없음.

이 인물은 공개 외형 후보가 되며 실제 화면 출연은 기존 문장별 신원·물리적 현장 검증을 통과해야 합니다. 내장 이미지가 없으면 설정한 인물 이미지 모델로 첫 입상을 만들고 이후 재사용합니다. 해당 이름의 고유한 축약 호칭도 기존 Cortex 이름 규칙으로 제공됩니다. 특정 작품/인물 하드코딩은 없습니다.

별도 공개 전 이미지가 있는 경우에는 그 이미지와 공개 전 외형만 허용합니다. 비공개 이력은 프롬프트에 포함하지 않으며 원본 엔진, 정사, 공개 원장, 기존 유료 이미지 기록은 변경하지 않습니다. 후보가 달라진 장면은 기존 키 규칙에 의해 출연 판정만 갱신합니다.

## 확인

- 현재 Fate/Seoul 저장 파일에서 김서연·정민석의 등록/외형/첫 이미지 허용 값을 확인하고 누락을 재현했습니다. 패치 후 같은 파일에서 두 사람이 `PRIMARY` 후보로 포함됩니다.
- 실제 Cortex 공개 투영을 사용하는 회귀 테스트: 중복 호칭, 짧은 이름, 내장 이미지 없음, 명시적 비공개 차단, 공개 전 이미지 보존, 잘못된 교수 연결 거부.
- 생성 요청 모의 테스트: 각 인물의 외형으로 첫 입상 요청, 대사 시 입상 노출, 반복 호출 시 재사용, 현장 밖 언급 시 제외.
- 테스트는 추가 유료 이미지 호출 없이 요청·검증·캐시 경로를 확인합니다. 새 그림의 실제 품질은 이 변경의 검증 범위에 포함하지 않습니다.
