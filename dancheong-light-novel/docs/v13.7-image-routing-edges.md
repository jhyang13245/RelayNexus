# v13.7 — 배경·인물 모델 분리와 인물 가장자리 보정

## 모델 선택

설정 → 연결·화면 → 이미지 생성 모델에서 배경과 인물·표정을 각각 OpenAI 2.5 Flare 또는 Nano Banana 2로 고릅니다. 사건 CG는 인물 모델을 사용합니다.

- 기존 단일 모델 설정은 두 항목으로 그대로 옮깁니다. 새 선택은 기기에 저장되어 새로고침 후에도 유지됩니다.
- 배경은 `background`, 인물·표정·사건 CG는 `portrait` / `expression` / `scene` 용도에 맞는 모델·엔드포인트·API 키를 사용합니다. 한쪽 키가 없어도 다른 쪽 생성은 진행합니다.
- Gemini 키를 입력해도 이미 선택한 배경/인물 모델을 임의로 바꾸지 않습니다.
- 선택은 새로 생성하는 이미지부터 적용합니다. 이미 만든 배경·인물·표정은 재사용하며, 선택 변경만으로 전부 다시 생성하지 않습니다. 새 표정은 기존 인물 이미지를 참조하여 일관성을 유지합니다.
- 비용 기록은 실제 요청 모델과 용도를 사용하므로 혼합 사용도 기존 비용 탭에서 구분합니다.

## Gemini 가장자리 처리

- 생성 지침에 배경색이 머리카락·의상에 반사되거나 외곽선·광원처럼 그려지지 않도록 명시했습니다.
- 단색 배경 분리 뒤 초록/노랑빛 잔색을 주변 불투명 영역 색과 비교하여 보정합니다. 얇은 머리카락을 잘라 버리는 대신 외곽 픽셀의 투명도를 부드럽게 조절합니다. 얼굴 내부와 깊은 의상 영역에는 보정을 적용하지 않습니다.
- 인물 참조에서 덜 사용되는 매트 색을 고르는 기존 로직을 유지합니다. 초록뿐 아니라 자홍·파랑 매트도 처리합니다.
- `chromaVersion: 3`으로 이전 Gemini 인물·표정 캐시를 불러올 때 한 번 보정하고 저장합니다. 보정을 위해 이미지 API를 재호출하지 않습니다. 이미지 디코딩에 실패하면 기존 이미지를 유지합니다. OpenAI 인물과 배경은 이 보정 대상이 아닙니다.

## 검증과 범위

- 이미지 경로, 네 가지 모델 조합, 키 누락, 표정 참조, 사건 CG, 비용 분류, 이전 설정 이동, 캐시 재사용·오프라인 보정, 스트리밍·연출 회귀 테스트 92개 통과.
- 기존 나디아 이미지의 원본 및 이전 보정본에 새 처리를 적용하고, 어두운·흰·푸른 배경에서 머리카락과 외곽을 확대 확인했습니다. 검증 샘플에서 초록 테두리가 눈에 띄지 않도록 개선했습니다. 임의의 모든 생성 결과에 완벽한 분리를 보장하는 것은 아닙니다.
- 실제 VN 화면에서 배경 OpenAI / 인물 Gemini 설정 저장·새로고침 유지, 각 요청 경로, 인물 표시 및 모델별 비용 기록을 모의 응답으로 확인했습니다. 데스크톱과 390px 모바일 설정 화면도 확인했습니다.
- Muse가 별도 복사본에서 작성한 설정 CSS는 원본 보존과 차이를 검토하고 실제 렌더링을 확인한 후 통합했습니다. 핵심 이미지 처리·모델 연결·저장 로직은 주 개발자가 구현했습니다.
- 이번 확인에서 실제 유료 이미지 API는 호출하지 않았습니다. 모의 비용 기록은 실제 청구가 아닙니다.
