# v13.9.9 — 사건 배경·비용 설정·작품별 인물 기준

## 사건 배경과 인물

- 사건 이미지는 실제 배경 레이어에 표시합니다. 배경에 직접 그려지는 참여 인물의 입상만 숨기며 목격자 입상은 유지합니다.
- 참여 인물 목록은 사건 비트의 검증된 참여자에서 가져옵니다. 같은 사건 배경을 유지하는 다음 반응 비트에도 적용합니다.
- 배경 이미지의 로딩 완료 후 입상을 숨깁니다. 일반 배경으로 복귀할 때에는 사건 배경의 페이드가 끝난 뒤 기존 입상을 다시 표시합니다.
- 참여 인물의 대사는 로딩이 끝난 사건 배경으로 표시 준비를 충족합니다. 목격자의 대사는 기존 입상 준비 규칙을 따릅니다. 사건 이미지가 실패하거나 꺼져 있으면 입상을 숨기지 않습니다.

## 해상도와 유료 기능 설정

- 사건 이미지의 모델·API 키는 계속 **배경** 선택을 따릅니다. 요청 본문 용도는 `scene`으로 보냅니다.
- Nano Banana 2 절약 설정에서 일반 풍경은 0.5K, 인물·표정·사건은 1K입니다. 사건 사용량은 비용 탭의 장면 용도로 집계됩니다.
- `eventScenes`에 명시된 설정을 우선하고, 없으면 기존 `cg`의 켜짐/꺼짐을 이어받습니다. 설정이 없는 새 사용자는 꺼짐입니다.
- 이미 새 형식으로 저장한 `eventScenes: on`은 유지합니다. 이전 버전에서 이 값을 자동 저장했는지 사용자가 선택했는지는 저장 데이터만으로 구분할 수 없습니다. 끄려면 설정의 사건 장면 연출을 변경하세요.
- 이미 생성된 사건 이미지는 재사용합니다. 해상도 변경만을 이유로 기존 이미지를 자동으로 유료 재생성하지 않습니다.

## 작품별 묘사 기준과 입상 고정

- 모든 작품에 나디아 입상을 보내던 동작과 배포 이미지 파일을 제거했습니다. 소스 ZIP에도 그 이미지가 포함되지 않습니다.
- 기본은 글로 된 묘사 기준만 사용합니다. 설정의 **이 작품의 인물 묘사 기준 이미지**에서 그 작품에서 만난 인물의 저장된 기본 입상을 선택하거나 사용 안 함으로 바꿀 수 있습니다.
- 선택은 브라우저의 작품별 설정에 저장됩니다. 다른 작품의 이미지, 표정 이미지, 상황별 복장 이미지는 기준으로 허용하지 않습니다.
- 선택한 기준은 새 기본 입상 요청의 마지막 참조로 전달되며 참조 입력 비용이 추가될 수 있습니다. 기존 이미지를 이 설정 변경만으로 다시 만들지 않습니다. 모델이 선택한 기준의 외형을 잘못 혼합할 가능성 자체를 보장 없이 배제하지는 않습니다.
- 만난 인물 화면에서 **이 기본 입상 고정**을 사용할 수 있습니다. 작품·인물 ID가 일치하는 기본 입상만 고정하며, 같은 작품의 저장본이나 공개 프로필이 바뀌어도 재사용합니다. 상황별 복장과 표정 변화는 별도 처리합니다.
- Fate/Seoul 나디아만 유지하던 코드 예외를 제거했습니다. 모든 작품에서 이미 저장된 기본 입상을 재사용하며, 업데이트 자체로 유료 품질 교체를 하지 않습니다. 새 입상에는 기존의 세밀한 선·눈·머리카락·재질 묘사 지침을 적용합니다.

## 공개 호칭 데이터

- 인물의 `publicAliases`, `source.publicAliases`, 작품 `presentation.publicAliases`, `runtime.packageContract.presentation.publicAliases`를 읽습니다. 작품 단위 대응은 인물 ID를 키로 한 문자열 배열입니다.
- `presentation.roleNames`로 일반 역할명을 실제 이름 공개의 증거에서 제외할 수 있습니다.
- 기존 Fate/Seoul 공개 패키지의 소녀 검사 호칭은 `public/work-presentation.json`의 작품별 호환 데이터로 옮겼습니다. 런타임 코드에 해당 작품·인물 ID를 직접 분기하지 않습니다.
- 기존 Cortex의 정체 공개·비공개 인물 제한은 유지합니다. 이번 변경은 VN의 패키지 읽기 지원과 호환 데이터이며, 외부 지음 편집기 UI를 수정한 것은 아닙니다.

## 키 기본값

- 공개 프로필에 명시된 키가 가장 우선합니다.
- 키가 없는 성인 남성: 178cm. 키가 없는 성인 여성: **162cm**(사용자 선택).
- 성별·성인 여부가 불명확하거나 양쪽 묘사가 혼재하면 기존 중립 배율을 유지합니다. 작품 정사 프로필을 수정하지 않는 화면 배치 기본값입니다.

## 검증

- 기존 검사와 새 회귀 검사: 사건 참여자/목격자, 반응 비트, 사건 로딩·실패, 기존 설정 승계, 배경/인물 모델 조합, Gemini 실제 라우트의 사건 1K 요청, 작품별 참조·입상 고정의 범위, 공개 호칭과 정체 공개 제한, 성별 기본 키.
- 로컬 브라우저에서 실제 `vn.js`·CSS를 사용하는 검증 화면으로 사건 참여 입상 숨김/복귀, 목격자 유지, 기준 이미지 설정 저장/재표시, 입상 고정 버튼 표시/변경을 확인했습니다. 배경·입상 데이터는 로컬 예시로 공급했습니다.
- 실제 유료 모델 생성, 사용자 브라우저의 진행 데이터 변경, 전체 작품 끝까지의 플레이는 수행하지 않았습니다.
