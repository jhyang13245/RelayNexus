# v13.3 · Nano Banana 2 요청 수정

## 원인과 수정

- `/api/gemini/image`가 `generationConfig.responseFormat.image`에 `16:9`, `3:4`, `1K`, `2K`를 보내고 있었습니다. 이 필드는 legacy `imageConfig`와 달리 REST enum 이름을 요구합니다.
- Google의 v1 discovery schema와 실제 API 응답으로 확인했습니다. 기존 요청은 키 인증 이전에 `aspect_ratio` / `image_size`의 `INVALID_ARGUMENT` 오류로 거부되었습니다.
- 배경은 `ASPECT_RATIO_SIXTEEN_BY_NINE`, 인물·표정은 `ASPECT_RATIO_THREE_BY_FOUR`, 해상도는 공식 enum 값으로 전달합니다.
- API 키 무효·만료, API 비활성, 권한, 할당량, 요청 형식 및 모델 없음 오류를 구분합니다. Google의 원본 오류문·메타데이터는 키나 프롬프트를 포함할 수 있으므로 브라우저나 로그로 전달하지 않습니다.
- 오류 자동 재시도는 추가하지 않았습니다. 참조 이미지, 크로마키 제거, 이미지 재사용 및 비용 집계 흐름은 유지합니다.

## 비용·속도와 인물 일관성

- 기본 Low: 배경 0.5K (`IMAGE_SIZE_FIVE_TWELVE`, 16:9 기준 688×384), 기본 인물·표정 1K (3:4 기준 896×1200), 사건 CG 1K (16:9 기준 1376×768). 얼굴과 참조용 기본 인물에는 1K를 유지합니다. 배경은 1K보다 세부 묘사가 줄어들 수 있습니다.
- Medium 선택 시 모든 이미지는 2K입니다. 비용·속도를 위해 두 설정 모두 `thinkingLevel: MINIMAL`, 후보 1개, 이미지 출력만 요청합니다. 추론 자체를 비활성화했다고 간주하지 않으며 반환된 추론 토큰은 비용에 포함합니다.
- 인물 생성은 기존 참조 이미지를 사용하고, 표정은 기본 인물 한 장을 계속 참조합니다. 표현을 여러 번 바꾼 결과를 연쇄 참조하지 않습니다. 캐시 키를 바꾸거나 기존 이미지를 강제로 재생성하지 않습니다.
- 2026-09-25 공식 Standard 이미지 출력 요금: 0.5K 약 $0.045, 1K 약 $0.067, 2K 약 $0.101. 입력·추론 비용은 별도입니다. 실제 비용 기록은 응답의 토큰 사용량을 사용합니다. 속도 개선량과 모든 장면의 외형 일관성은 보장 수치가 아닙니다.

## 검증

- Gemini 라우트 테스트: REST enum 매핑, 인물 참조 입력, 사용량, 입력 제한, 오류 분류, 민감 정보 비노출 및 자동 재시도 없음.
- Google API에 무효 진단용 키로 요청: 기존 payload의 필드 오류를 재현하고, 수정된 payload가 필드 검사를 통과해 `API_KEY_INVALID`까지 도달함을 확인했습니다. 이 검사는 이미지 생성이나 과금을 발생시키지 않습니다.
- 실제 저장된 키를 이용한 생성 성공 여부는 공개 배포 후 별도로 확인합니다.
