# v13.11.2 — 사건 진행상황과 모바일 안내, 입상 구도 통일

## 플레이 화면

- 하단 **진행**, 메뉴 **진행상황**에서 상세 창을 엽니다.
- **현재 사건**: 진행 비트 / 기본 3비트, 최대 2비트 연장, 종결조건별 충족 여부와 저장된 판정 사유, 종결 검토 내용을 표시합니다.
- **비트 기록**: 저장된 확정 비트·판정 보완 대기·실패 기록을 최신순으로 보여줍니다.
- **종결 기록**: 사건별 종결사유, 진행 비트 수, 연장 수, 이월 조건 수와 종결 검토 내용을 보여줍니다.
- 판정 중 큰 안내 상자는 플레이 화면에 띄우지 않습니다. 하단 버튼이 **판정 중**, **판정 재시도**, **저장 오류**로 바뀝니다. 상세 창에 기존 재시도·백업·별도 저장 버튼과 원래 이벤트 핸들러를 유지합니다.

## 데이터 기준

엔진의 `systemicEventState`, `eventMachine`, `requirementVerdicts`, `eventLedger.sealed`, 각 턴의 `metrics.unifiedAdjudication`과 `transition`을 읽습니다. 원본 Cortex는 변경하지 않습니다. 최신 저장·판정 기준이며 과거 문장을 읽는 커서와 다를 수 있습니다.

현재 사건 ID에 맞는 기록만 연결합니다. 미판정은 미충족으로 추정하지 않고, 대체 달성·작가 인정·범위 밖 판정을 직접 충족과 구별합니다. 연속 판정 실패로 넘어간 사건은 비트 예산을 소진해서 종결한 것으로 표시하지 않습니다. 미래 사건·비공개 초안·전체 API 응답을 표시하지 않습니다. 진행상황 확인은 AI 호출이나 엔진 상태 변경을 발생시키지 않습니다.

## 입상 구도

상반신과 허벅지까지 보이는 그림을 같은 높이로 배치하면 실제 신장과 무관하게 비율이 달라집니다. 머리부터 허벅지 중간까지의 공통 구도, 눈·어깨·골반의 위치, 동일한 카메라 높이를 생성 지침에 명시합니다. 상반신 참조의 잘린 하체는 의상에 맞춰 새로 그리도록 요청합니다. 얼굴·머리색·의상·개인별 체형을 참조하고 신장 배치는 기존 공개 설정을 계속 사용합니다.

기존 구도 캐시를 영구 재사용하던 규칙을 이번 사용자 요청에 따라 변경했습니다. 해당 작품의 인물이 실제로 준비되는 시점에 인물·의상별 새 구도 버전을 한 번 생성합니다. 기존 그림을 삭제하지 않고 준비 중·오프라인에는 표시를 유지합니다. 성공한 새 구도는 다시 불러와도 재사용합니다. 새 기본 입상이 준비된 뒤에는 예전 구도의 표정을 섞지 않고, 새 기본 입상을 유지하다 같은 구도의 표정이 준비되면 바꿉니다. 실패는 세션 내 자동 반복 호출하지 않습니다. 수동 다시 그리기도 같은 기준을 적용합니다.

**비용:** 진행상황 UI는 추가 비용이 없습니다. 기존 입상의 구도 보완과 필요한 표정 재생성에는 선택한 이미지 모델의 생성 비용이 발생합니다. 이미지 해상도·Low/Medium 설정은 변경하지 않았습니다. 구도를 맞춘 이미지와 표정은 이후 재사용합니다.

## 검증 범위

- 원본 Cortex의 실제 `requirementDisplay`와 표시 결과 대조, 사건 ID 혼선·레거시 미판정·조기 종결·연속 판정 실패·미공개 데이터 차단 테스트.
- 새 구도 캐시, 기존 그림 보존, 참조 전달, 중복 요청 통합, 새로고침 후 재사용, 고정 입상·복장 변경·사건 이미지 참조 테스트.
- 실제 브라우저의 로컬 UI에서 세 탭, 모바일 가로·세로, 판정 중 표시, 실패 시 재시도 버튼과 저장 복구 버튼 접근 확인. 유료 호출 없는 테스트 데이터 사용.
- 실제 공급자의 새 김다윤·윤설아 생성 결과나 사용자의 저장본은 이 검증에서 재생성하지 않았습니다. 생성 모델이 지침을 따르는 정도는 최종 그림에서 확인해야 합니다. 이미 실행 중인 탭에는 새 코드가 자동 주입되지 않으며, 새 버전을 불러온 뒤 적용됩니다.

CSS의 독립 초안은 Muse 보조 작업으로 작성했으며, 통합·수정·렌더링 확인은 메인 개발자가 수행했습니다.
