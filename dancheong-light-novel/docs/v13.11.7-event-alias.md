# v13.11.7 사건별 익명 인물 외형 연결

## 원인
Fate/Seoul의 뇌전 사용자 대면 장면은 인물의 등록명과 관계를 의도적으로 숨깁니다. 본문의 ‘능선의 남자’에 대응하는 공개 호칭 연결이 없어, 첫 등장 공개 조건을 통과하지 못하고 이미지 생성 후보에서 빠졌습니다. 이미지 모델의 생성 실패가 아니었습니다.

## 변경
- `presentation.eventPublicAliases`에 `{ characterId, eventIds, name, aliases }`를 지원합니다. 작품 패키지의 설정이 우선이며, 기존 공개 패키지는 `work-presentation.json` 호환 데이터를 사용합니다.
- `turn.sourceEventId`에 해당하는 호칭만 활성화합니다. 과거 비트를 재생할 때 최신 사건을 가져오지 않습니다. 공통 코드에 작품·캐릭터 ID 분기를 넣지 않습니다.
- 현재 공개된 본문으로 물리적 등장을 별도로 검증합니다. 사건의 참여자 목록만으로 입상을 띄우지 않으며, 다른 사건의 ‘남자’라는 표현을 신원 근거로 쓰지 않습니다. 같은 호칭을 두 인물에 연결한 충돌 데이터는 적용하지 않습니다.
- 화면과 연출 요청에는 익명 호칭을 쓰고, 등록된 외형·기준 이미지를 사용합니다. 원본 정사·공개 상태를 수정하지 않으며, 명시적인 비공개·정체 공개 조건·공개 전 이미지 제한은 유지합니다.
- 이름을 알게 되거나 사건이 바뀌어도 같은 인물의 기본 이미지 캐시를 재사용합니다. 별도의 모델 호출은 추가하지 않습니다. 후보가 달라진 장면의 연출 판정과 아직 없는 입상만 기존 생성 경로에서 처리합니다.
- Fate/Seoul 호환 데이터는 원문에서 연결을 확인한 뇌전 사용자 대면 사건 05~08에만 적용합니다. 그가 떠난 뒤의 사건 09에는 적용하지 않습니다.

## 검증
실제 저장본을 로컬에서 재현하여 누락되던 후보·대표 기준 이미지·물리적 등장 근거의 연결을 확인했습니다. 해당 저장본은 소스와 배포 파일에 포함하지 않습니다. 회귀 테스트는 익명 표시, 타 사건/과거 재생 격리, 공개 제한 보존, 충돌 거부, 이름 공개 후 캐시 재사용을 포함합니다.

이 기능은 작가가 선언한 연결을 사용합니다. 임의의 ‘남자’나 ‘교수’를 외모·역할 추측만으로 기존 인물에 자동 연결하지 않습니다. 새 작품에서는 같은 형태의 사건별 호칭 데이터를 패키지에 제공해야 합니다.
