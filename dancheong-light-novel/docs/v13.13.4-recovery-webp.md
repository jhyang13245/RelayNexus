# v13.13.4 — 자동 복구와 WebP 저장

## 판정·저장 자동 복구

- 사건 판정의 일시적 HTTP 오류, 시간 초과, 잘못된 응답은 동일 공개 본문으로 최대 3회 요청합니다(최초 요청 포함, 재시도 간격 1.5초/4.5초). 집필을 다시 하지 않습니다.
- 분기·자원 판정 적용은 최종 응답 뒤 한 번만 실행합니다. 각 시도의 결과 코드는 `metrics.adjudicationAttempts.history`에 기록합니다. 기존 API 비용 계측도 요청별로 유지합니다.
- 401/403 등 키·권한·설정 오류는 반복 호출하지 않습니다. 반복 실패하면 기존 엔진의 본문 보존/판정 미확인 정책을 유지하며, 조건을 임의로 충족 처리하지 않습니다.
- 기존에 중단된 `CORTEX_SAME_TURN_RESUME_V1` 비트는 저장 복구를 먼저 마친 뒤 동일 비트를 재개합니다. 엔진 실행 중, 가져오기 중, 오프라인에서는 중복 요청하지 않습니다. 세션이 바뀌면 이전 복구 결과를 새 세션에 적용하지 않습니다.
- 이어하기 저장 실패는 1초 뒤 재저장하고, 실패 시 3초/9초 간격으로 최대 3회 복구합니다. 원래 저장 리비전 검사를 그대로 사용하고 충돌이면 엔진의 별도 저장 분기를 사용합니다. 성공한 실제 저장 결과를 확인한 뒤 입력 잠금을 해제합니다.
- 유료 이미지 저장도 생성 결과 바이트를 최대 3회 저장합니다. 저장 재시도로 이미지 모델을 다시 호출하지 않습니다.
- 완전 자동은 복구 중 대기하고 성공 시 기존 모드로 이어갑니다. 직접 중지한 자동 모드는 복구가 완료돼도 다시 켜지지 않습니다. 상태는 하단 진행 버튼과 진행상황 창에만 표시합니다.
- 물리적 용량 부족, 차단된 저장소, 읽지 못한 기존 저장본은 자동으로 항상 해결할 수 없습니다. 복구 한도를 넘으면 원래 백업/별도 저장 수단을 유지하며, 저장되지 않은 진행을 저장된 것처럼 취급하지 않습니다. 슬롯·이미지·음성 자동 삭제나 정사 되감기는 하지 않습니다.

## 이미지 저장 최적화

- 생성 API의 원래 출력과 요금은 유지합니다. 저장 시에만 기기의 Web Worker에서 WebP로 인코딩합니다. 변환에는 AI API 호출이 없습니다.
- 인물·표정·사건·상세 컷은 품질 0.94, 새 풍경 배경은 0.88. 원본 해상도와 알파 채널을 유지하며, 실제 반환 MIME이 WebP이고 문자열 저장 크기가 3% 이상 줄어들 때만 적용합니다.
- 생성 이미지는 우선 화면에 표시하고 뒤에서 변환·저장합니다. 캐시 키, 인물 연결, 고정 입상 선택, 비용 기록은 유지합니다. 기존 저장 이미지가 다시 생성되지 않습니다.
- 기존 이미지는 **설정 → 저장 공간 관리 → 작품별 ‘이미지 WebP 최적화’**로 변환합니다. 한 장씩 처리하고, 탭 간 미디어 관리 잠금과 원본 URL 비교 후 원자적 교체로 새 이미지나 삭제된 캐시를 덮어쓰지 않습니다. 처리 개수와 절약량을 표시합니다.
- 슬롯에 포함된 패키지 원본이나 과거 백업 복사본은 변경하지 않습니다. 이후 백업 파일에는 현재 WebP 캐시가 포함됩니다.
- 눈·입 마스크 편집 입력은 기존 PNG 변환 경로를 유지합니다. 픽셀 일치가 필요한 실험 애니메이션 프레임은 PNG로 보존합니다. 프레임 측정/누끼 제거는 압축 전에 수행합니다.
- WebP 인코딩 미지원, 디코딩/저장 실패, 크기 증가 시에는 사용 가능한 원본을 유지합니다. 용량 절감률은 그림에 따라 다릅니다. 디코딩 후 GPU 비트맵 크기나 최초 생성 API 응답 크기까지 줄이는 기능은 아닙니다.

## 검증

- 전체 Node 회귀 테스트 435개 통과: 재시도 횟수/간격, 같은 비트·입력 보존, 저장 우선 복구, 실행 잠금, 오프라인 대기, 복구 한도, 잘못된 키, 세션 교체, 실제 생성된 엔진 판정 함수의 요청 3회/분기 적용 1회, 자동 진행 유지.
- 기존 Fate/Seoul 백업의 인물 PNG와 배경 JPEG를 로컬 Chrome에서 실제 Worker로 변환하고 나란히 비교했습니다. 공개 소스·배포물에 이 검증용 이미지나 백업은 포함하지 않습니다.
- 인물 샘플: 768×1024, 882,234 → 105,128 bytes(약 88% 감소), 약 255ms. 배경 샘플: 1088×608, 121,158 → 96,914 bytes(약 20% 감소), 약 99ms. 두 샘플 모두 알파 차이 최댓값 0. 원본 RGB와 완전히 동일한 무손실 압축은 아닙니다.
- 설정 버튼으로 기존 샘플 2개를 실제 IndexedDB에서 변환하여 약 1MB 절약 표시와 저장 후 WebP 재사용을 확인했습니다.
- 유료 실제 API에 장애를 발생시키거나 사용자의 진행을 재집필하지 않았습니다. API 오류는 모의 응답으로, 저장 실패는 모의 엔진 상태로 재현했습니다. 실제 Safari/iOS 검증은 수행하지 않았습니다.
- Cortex 원본 vendor SHA-256은 그대로 유지합니다. 엔진 내부 연결은 생성 빌드의 정확한 문자열 일치 어댑터로 적용됩니다.
