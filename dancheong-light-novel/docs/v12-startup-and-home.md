# v12 — 최초 로딩과 메인화면 복귀

## 원인과 수정

기존 VN CSS는 Cortex의 `.app`을 화면 밖으로 이동시켰다. 하지만 그 안의 `.composer`와 모바일 `.drawer-toggle`은 viewport에 고정된 요소여서 부모의 이동과 별개로 남았다. VN 모듈이 준비될 때까지 이 입력창과 사건·진단 버튼이 노출될 수 있었다.

- 생성되는 HTML의 head 맨 앞에 핵심 표시 규칙을 인라인으로 넣었다. 원본 Cortex 노드와 그 자손은 외부 CSS/모듈 상태에 관계없이 숨겨지고 클릭·키보드 포커스 대상에서도 제외된다.
- 정적 단청 시작 화면을 body의 첫 요소로 둔다. VN 초기화와 스타일 준비가 완료된 뒤에만 실제 작품 화면을 표시한다.
- 모듈/스타일 실패와 초기화 지연은 단청 오류·다시 불러오기 화면으로 안내한다. 예전 UI를 복구 화면으로 사용하지 않는다.
- 원본 vendor 파일, 본문·인물 엔진, 저장 형식은 수정하지 않았다.

## 메인화면 버튼

- 플레이 화면 왼쪽 위에 항상 읽을 수 있는 ‘← 메인화면’ 버튼을 표시한다. 모바일 터치 높이는 44px 이상이다.
- 메인화면으로 돌아갈 때 읽던 위치를 보관하고 자동 읽기와 글자 표시를 멈춘다. 이야기를 생성 중이어도 화면 이동은 가능하다.
- 동일 작품의 이어하기는 현재 엔진과 페이지를 그대로 사용한다. 다시 가져오기나 초기화로 진행 중 작업을 바꾸지 않는다. 다른 작품으로 전환할 때의 기존 동시 작업 보호는 유지한다.

## 전체 소스 배포

- 작품 선택 화면 하단에서 전체 소스 ZIP을 내려받을 수 있다. 원본 Cortex, 프런트엔드, 서버 API 라우트, 빌드 설정, 잠금 파일, 테스트·문서를 포함한다.
- 빌드 시 명시한 소스 디렉터리만 묶고, API 키·환경 파일·로컬 저장·Git 이력·설치 의존성·실행 캐시·기존 ZIP은 제외한다. 소스 ZIP 자체와 파일별 SHA-256 목록을 함께 생성한다.
- 압축을 푼 뒤 `npm ci`, `npm run dev`로 실행할 수 있다. `npm run source:zip`은 Git 이력 없이도 작동한다. 너름과 지음은 기존 공유 서비스에 연결한다.

## 검증

- 기존 128개 + 시작 화면 회귀 테스트 5개, 총 133개 통과. TypeScript 검사 성공.
- ZIP의 152개 소스가 저장소의 전체 소스 목록 및 원본 바이트와 일치함을 검사했다. 압축을 푼 사본에서 Cortex와 ZIP을 다시 생성하여 동일한 결과를 확인했다. 다운로드 링크의 실제 화면도 확인했다.
- 실제 생성된 Cortex HTML에서 VN 진입 모듈을 지연시켜 확인: 시작·시간 초과 화면 모두 `.composer`와 `.drawer-toggle`의 visibility가 hidden, pointer-events가 none. 390×844 모바일 화면에서 직접 확인했다.
- 지연 모듈을 재개하면 새 작품 선택 화면으로 정상 전환된다. 실제 Fate/Seoul 공개 패키지로 플레이 진입, 메인화면 복귀, 같은 문장 이어하기를 확인했다. 정상 경로 브라우저 오류 없음.
- 별도 합성 스트리밍 fixture에서 STREAMING 상태 그대로 메인화면 왕복이 가능하고 인물 배치 호출도 중복되지 않는 것을 확인했다. 이 검증에 실제 API 키는 사용하지 않았다.
- Muse는 별도 사본에서 시작 화면 컨트롤러 테스트만 작성했다. 주 개발자가 내용을 검토하고 직접 실행한 뒤 반영했다. 초기 로딩·복귀 로직과 실제 화면 검증은 주 개발자가 수행했다.
