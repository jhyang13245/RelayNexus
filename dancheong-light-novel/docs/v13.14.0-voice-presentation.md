# v13.14.0 — Gemini 음성, 살아 있는 입상, 상용 비주얼노벨 기능

## 수정한 문제 (v13.12.2~v13.13.4 검토)

1. **연기 지시가 늦게 도착한 대사의 이중 과금**
   - 이제 음성 저장 키에서 연기 지시를 뺍니다. 저장 키는 `vn-voice-3 · 범위 · 화자 · 목소리 · 문장 · 모델 · 위치`로 구성됩니다.
   - 늦게 스트리밍된 "속삭였다" 같은 서술은 첫 요청의 연기에는 반영됩니다. 하지만 같은 대사를 다시 구매하지 않습니다.
   - 다시 듣기, 되돌아가기, 새로고침, 저장 불러오기 때는 저장된 음성을 추가 비용 없이 재생합니다.
   - v13.12~v13.13에 저장한 음성(`vn-voice-2`, `vn-voice-1` 키)도 그대로 무료로 재생합니다.
2. **저장 불러오기·새로 시작 직후 배경음악 공백**
   - 첫 비트가 `keep`이면 앞 페이지들에 기록된 마지막 음악 신호로 시작합니다. 기록이 없으면 무음으로 시작합니다.
   - 아무 곡도 정해지지 않은 상태에서 첫 음악 신호가 오면 24초 유지 조건 없이 바로 들어옵니다.
   - 이후의 곡 교체 규칙(유지 시간, 확인 페이지 수)은 그대로입니다.
3. **덧칠 정보가 없는 작품을 처음 열지 못하던 문제**
   - `currentRevision`이나 `packageSha256`이 없는 카탈로그 항목은 이전처럼 덧칠 번호 없이 엽니다.
   - 새로하기도 같은 규칙을 씁니다.
4. **완전 자동에서 화자 확인 전 대사를 낭독 목소리로 읽던 문제**
   - 대사나 인용문은 화자 확인이 끝날 때까지 기다린 뒤 그 인물의 목소리로 읽습니다.
   - 화자 확인 결과 신원을 알 수 없는 인용문만 낭독 목소리로 읽습니다.
5. **낭독 목소리와 여성 인물 목소리가 겹치던 문제**
   - 낭독자는 인물에게 기본으로 배정하지 않는 목소리를 씁니다(OpenAI `alloy`, Gemini `Schedar`).
   - 설정에서 낭독 목소리를 바꿀 수 있습니다.

## Gemini 3.8 TTS 인물 음성

설정 → 추가 연출의 **음성 모델**에서 고릅니다.

| 모델 | 요금 (2026-12-31까지, 1M 토큰) | 2027-01-01부터 |
|---|---|---|
| `gemini-3.8-flash-tts` | 텍스트 입력 $0.50 · 음성 출력 $9 | $1 · $18 |
| `gemini-3.8-flash-lite-tts` | $0.50 · $6 | $1 · $12 |

음성 1초는 약 25~32 음성 토큰입니다. 비용 탭은 응답의 `usage`(입력·출력 토큰)로 계산하며, 응답에 사용량이 없으면 "금액 미확인"으로 둡니다.

- **요청 방식**
  - `POST https://generativelanguage.googleapis.com/v1beta/interactions`로 보냅니다.
  - 대사는 `text`에 그대로 넣고, 연기 지시는 `annotations[{type:'speech_metadata', style}]`에 넣습니다. 3.8 TTS는 `text`를 글자 그대로 읽기 때문에 지시문을 본문에 섞지 않습니다.
  - `store:false`로 요청합니다.
  - MP3와 `ko-KR`을 먼저 요청하고, 모델이 이 선택 필드를 거부하면(400, 과금 없음) 최소 요청으로 한 번만 다시 시도합니다.
  - raw PCM(`audio/l16`)이 오면 서버에서 WAV 헤더를 붙입니다.
  - 형식 근거: `google-gemini/cookbook`의 `Get_started_TTS.ipynb`, `googleapis/python-genai`의 Interactions 타입 정의(`TextContent.annotations`, `SpeechAnnotation`, `AudioResponseFormat`, `SpeechConfig`, `Interaction.steps[].content[]`, `usage.total_input_tokens/total_output_tokens`).
- **목소리 배정**
  - 30개 기본 목소리 중에서 공개 프로필의 성별·연령대에 맞는 목소리를 인물마다 서로 다르게 자동 배정하고, 이 이야기에 고정해 저장합니다.
  - 설정에서 인물별 목소리와 음량을 바꿀 수 있습니다.
  - 목소리 선택 목록에는 Google의 한 단어 설명(Bright, Firm, Soft 등)을 함께 표시합니다.
- **연기 태그**: 서술에 한숨이나 웃음이 명시된 경우에만 `<sigh>`, `<chuckle>` 태그를 붙입니다.
- **키와 오류 처리**
  - 이미지(Nano Banana 2)·음악(Lyria)과 같은 Gemini API 키를 씁니다.
  - 잘못된 키는 다시 시도하지 않습니다.
  - Google의 원문 오류 메시지는 요청 내용을 되풀이할 수 있으므로 화면에 보여 주지 않습니다.

## 입상 연출 (추가 이미지 비용 없음)

- **입 움직임**
  - 재생 중인 음성의 실제 음량(Web Audio 분석)에 맞춰 입 프레임을 여닫습니다. 음량이 올라가면 열고 내려가면 닫으며, 70ms 이상 유지해 깜빡임처럼 보이지 않게 합니다.
  - 음성 없이 글이 표시되는 동안에는 기존처럼 일정한 간격으로 움직입니다.
  - 입·눈 프레임은 기존 "눈 깜빡임·입 움직임(실험)"을 켠 경우에만 있습니다.
- **눈 깜빡임**: 2.4~6.4초의 불규칙한 간격으로 깜빡이고, 가끔 두 번 연속 깜빡입니다. 인물마다 박자가 다릅니다.
- **숨쉬기**: 모든 입상에 적용하고, 인물마다 위상을 달리해 동시에 숨 쉬지 않게 했습니다. 움직임 최소화 설정을 따릅니다.
- **표정 전환**: 새 표정이 완전히 나타난 뒤 이전 그림을 치웁니다. 전환 중에 인물이 반투명해지지 않습니다.
- **퇴장**: 서 있던 쪽 가장자리로 미끄러지며 사라집니다.
- **얼굴만 합성 (실험, 기본 꺼짐)**
  - 새 표정 그림이 기본 입상과 몸·옷·윤곽이 거의 같을 때만 얼굴 타원을 기본 입상 위에 부드럽게 합칩니다. 표정마다 단추나 주름이 달라지는 것을 막기 위한 기능입니다.
  - 윤곽 겹침이 95% 미만이거나 색 차이가 크면 새 그림을 그대로 보여 줍니다. 합성 경계에 이음새가 보일 것 같을 때도 마찬가지입니다.
  - 기존 구도 코드의 "얼굴을 다른 그림에 붙이지 않는다" 원칙을 존중해 기본값은 끔입니다.

## 글자

- **본문 글꼴 선택**: 기본(NVL 명조 / ADV 고딕), Pretendard, 고운바탕, Noto Serif KR, 기기 글꼴 중에서 고릅니다.
  - 기존 CSS가 지정만 하고 불러오지 않던 글꼴을 Google Fonts·jsDelivr에서 불러옵니다(`font-display: swap`).
  - 고른 글꼴만 불러오며, 글꼴을 받는 동안에는 기기 글꼴로 표시합니다.
- **루비**: `運命(운명)`처럼 한자 뒤에 읽기가 있으면 읽기를 한자 위에 작게 표시합니다. `운명(運命)`이면 한자를 한글 위에 표시합니다.
  - 타자 효과는 보이는 글자만 세며, 읽기는 한자가 다 나온 뒤에 표시합니다.
- **드러냄표**: 본문에 새어 나온 `*강조*`, `**강조**` 표시를 글자 위 점으로 바꿉니다. 음성에서는 별표를 읽지 않습니다.

## 시스템 기능

- **퀵 세이브·퀵 로드**
  - F5로 저장하고 F9로 불러옵니다. 하단 도구의 Q.저장·Q.불러오기 버튼으로도 할 수 있습니다.
  - 퀵 세이브는 10개 슬롯과 별도인 11번 슬롯에 저장하며, 저장·불러오기 창에 Q로 표시됩니다.
  - 불러올 때는 확인을 묻고, 현재 진행은 이어하기에 먼저 보관합니다.
- **기록에서 음성 다시 듣기**
  - 기록의 대사 옆 ▶로 저장된 음성만 재생합니다. 기록 화면에서는 새 음성을 만들지 않습니다.
  - 항목을 누르면 그 문장으로 돌아갑니다.
- **다음 문장으로 넘겨도 음성 유지 (선택)**: 켜면 넘긴 뒤에도 음성을 끝까지 재생합니다. 다음 음성이 나오면 그 음성으로 바뀝니다.
- **음량**: 전체 음성 음량과 인물별 음량을 조절할 수 있습니다.
- **갤러리·음악 감상** (작품 메인화면)
  - 이 기기에 저장된 사건 CG와 구도 그림을 모아 보여 주며, 누르면 크게 보고 좌우로 넘길 수 있습니다.
  - 등록했거나 AI로 생성한 분위기별 배경음악을 들을 수 있습니다.
  - 새로 생성하거나 내려받지 않습니다.
- **아이캐치**: 이야기가 하루의 다른 시간대(새벽·낮·저녁·밤)로 넘어가면 처음 읽을 때 시간과 장소 카드를 약 2초 동안 화면 가득 보여 줍니다. 입력을 막지 않으며, 화면 연출을 끄거나 움직임 최소화를 켜면 생략합니다.

같은 장소의 시간대별 배경은 v13.10.0부터 저장된 장소 기준 배경을 참조해 구조를 유지하고 있어 그대로 둡니다.

## 검증

- **자동 검사**
  - Node 테스트 전체 통과(추가 테스트 13개 포함). tsc와 배포 빌드 모두 이상 없습니다.
  - 음성: 늦은 연기 지시가 이중 과금되지 않음, 다시 듣기·새로고침 무료 재생, 옛 키 호환을 확인했습니다.
  - 완전 자동: 화자 확인 대기와 낭독 목소리 분리를 확인했습니다.
  - 목소리 배정: Gemini 인물별 목소리가 서로 다르고 고정되며, OpenAI 기존 규칙은 그대로임을 확인했습니다.
  - 음악과 덧칠: 음악 시작 상태 복원, 덧칠 정보 없는 작품 열기를 확인했습니다.
  - Gemini 경로: 요청 형식, 400 재시도, PCM→WAV 변환, 잘못된 키 처리, 원문 오류 숨김, 요금 계산을 확인했습니다.
  - 입상·글자·갤러리: 깜빡임 간격, 입 여닫음, 루비·드러냄표, 갤러리 목록 필터, 얼굴 합성 검사(정렬 통과·이동 거부·이음새 거부)를 확인했습니다.
- **실제 Chromium**
  - 빌드한 셸이 오류 없이 시작합니다. 카탈로그 오류는 이 환경의 네트워크 차단 때문이며 예상된 결과입니다.
  - 새 설정 항목(음성 모델, 낭독 목소리, 음성 유지, 글꼴, 얼굴 합성)이 표시됩니다.
  - Web Audio 음성 재생에서 음량 측정값이 소리 구간에 오르고 무음 구간에 0이 되며, 재생이 끝나면 화자가 해제됩니다.
  - 루비와 드러냄표가 실제로 그려지는 것을 확인했습니다.
  - 얼굴 합성은 캔버스 결과에서 옷은 기본 입상 색, 입은 새 표정 색으로 나왔습니다.
  - 갤러리와 음악 감상 창이 동작합니다.
- **실제 Google 엔드포인트**: 로컬 Worker에서 임시 키로 보낸 요청이 실제 Google에 도달해 키 오류를 받았습니다.
- **검증하지 못한 것**
  - 실제 유료 Gemini·OpenAI 음성의 품질과 응답 시간은 이 환경에서 확인하지 못했습니다.
  - 모델명과 요청 스키마는 공개 SDK·쿡북 기준입니다. 실제 키로 첫 음성을 생성해 확인해 주세요.
  - 글꼴 CDN은 이 환경에서 차단되어 대체 글꼴로 표시되었습니다.
