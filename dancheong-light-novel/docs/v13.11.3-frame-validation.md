# v13.11.3 — 모든 입상의 공통 구도 검사

v13.11.2의 진행상황 UI와 공통 생성 구도에 출력 검증을 추가했습니다. 특정 작품이나 인물 이름을 조건으로 사용하지 않습니다. OpenAI·Gemini, 기본 입상·복장 변경·표정·수동 다시 그리기에 같은 검사를 적용합니다.

## 생성 → 검사 → 저장 → 재사용

1. 동일한 머리~허벅지 구도로 생성합니다. 기존 얼굴·머리색·의상 참조와 공개 신장 설정은 유지합니다.
2. 배경 제거 후 기기에서 알파 영역과 얼굴 위치를 측정합니다. 빈 이미지·불투명 배경·머리 크기에 비해 명백히 부족한 하체 범위를 검사합니다. 긴 그림의 여분은 기존 표시 정규화에서 잘라냅니다.
3. 불량 결과는 원본과 실패 사유를 별도로 보존하고 정상 입상 URL로 등록하지 않습니다. 기존 사용 가능한 입상을 유지합니다.
4. 실패 기록도 저장합니다. 페이지 이동·새로고침으로 자동 재청구하지 않고, 이미지 상태의 명시적인 재시도로만 다시 생성합니다.
5. v13.11.2에서 이미 생성한 구도 이미지도 처음 읽을 때 비용 없이 검사합니다. 검사를 마친 정상 캐시는 재사용합니다. 예전 구도 표정이 새 기본 입상 위에 다시 나타나지 않습니다.

검사는 Worker에서 실행되며 지원하지 않는 브라우저는 로컬 Canvas로 처리합니다. AI 판정 호출은 추가되지 않고, 본문 최대 5초 대기 규칙을 변경하지 않습니다.

## 검증과 한계

- 자동 검사: 구도 판정, 확대된 얼굴 탐색, 두 공급자의 불량 결과 격리, 이전 입상 보존, 새로고침 후 반복 청구 방지, 명시적 재시도 및 오프라인 캐시 검사.
- 실제 브라우저: 기존 나디아 기준 이미지, OpenAI 전투 표정, Gemini 전투 표정 세 장에서 정상 구도 판정. 기준 이미지를 상반신으로 자른 테스트는 `SHORT_BODY_CROP`으로 검출했습니다. 샘플은 기존 비교 자료를 사용했으며 새 유료 생성은 없었습니다.
- 얼굴 탐색은 픽셀 기반 휴리스틱입니다. 복잡한 가림·특수한 화풍 등에서 측정이 불확실하면 `unmeasured`로 저장하고 통과했다고 기록하지 않습니다. 해부학·복장 완성도를 의미적으로 판별하는 검사는 아니며, 모든 생성 오류를 보장해서 차단하지는 않습니다. 불확실한 결과는 기존 표시 정규화와 수동 다시 그리기를 사용할 수 있습니다.

처음 구도를 보완하는 이미지 생성에는 선택한 모델의 비용이 들지만, 로컬 검사와 정상 이미지 재사용은 추가 AI 비용이 없습니다.
