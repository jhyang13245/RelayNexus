# v13.9.4 — 사건 배경·공개 호칭·인물 비율

## 변경

- 사건의 동작을 그린 이미지는 기존 배경 레이어에서 교체한다. 별도 CG 레이어와 입상을 숨기던 CSS를 제거했다. 대사 시점의 인물 준비 규칙도 유지한다.
- 사건 배경은 `purpose: background`로 요청해 배경 모델·API 키·해상도·비용 분류를 따른다. 중요한 사건만 가까운 공개 문단에서 준비하며, 기존 사건 이미지도 재사용한다.
- 사용자가 확인한 Fate/Seoul의 ‘소녀 검사’/‘소녀검사’와 등록 인물 홍재를 작품·ID 단위로 연결한다. 일반 단어 ‘검사’나 다른 작품에 확대하지 않는다. 원본 Cortex의 명시적 비공개 제한과 현장 인물 검증을 유지한다.
- 표시 호칭은 본문에 나온 호칭을 사용한다. 외형 프롬프트는 공개 외형만 사용하며, 기존 인물 캐시 식별자는 보존한다. 등록명 공개 후에도 같은 이미지가 재사용된다.
- 인물 이미지는 얼굴의 피부 영역과 연결된 머리 윤곽을 함께 측정해 크기와 눈높이를 맞춘다. 기기 내 캔버스에서 균일 배율과 크롭만 적용한다. 원본 이미지·얼굴 픽셀과 저장 이미지는 변경하지 않으며 이미지 API를 호출하지 않는다.
- 여러 인물 중 초점 인물만 1.3배 확대되던 연출을 제거했다. 단독 인물 클로즈업은 유지한다.

## 검증

- Node 테스트 224개 통과: 공개 호칭/등록명 전환, 원본 시나리오 보존, 비공개 인물 보호, 기존 입상 캐시 키 유지, 사건 배경의 모델 선택 4가지 조합·재시도·오프라인 복원, 다른 원본 구도의 비율 보정 포함.
- 실제 Cortex 공개 참조 함수를 사용해 홍재 공개 호칭을 검증했다. Cortex 원본 엔진 파일은 수정하지 않았다.
- 로컬 브라우저에서 현재 플레이 화면의 홍재 이미지와 기존 나디아 생성 이미지로 2인 배치를 확인했다. 검증용 장면에서 배경 교체 후에도 입상이 표시되는 것을 확인했다.
- 유료 이미지 생성은 실행하지 않았다. 새로운 이미지 모델 출력의 미적 품질 및 모든 캐릭터의 픽셀 추정 정확성은 이 검증의 범위가 아니다. 얼굴을 신뢰성 있게 추정할 수 없거나 불투명한 이미지에는 기존 프레이밍을 사용한다. 상반신만 존재하는 원본은 빈 하단이 생기지 않도록 가능한 크롭 범위로 제한한다.

## 범위

너름·지음 공유 서비스, 본문 생성과 판정 엔진, 저장된 본문·진행 상태는 유지한다. 테스트용 그림·브라우저 데이터·API 키는 배포와 소스 ZIP에 포함하지 않는다.
