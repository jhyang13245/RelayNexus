# v13.4 · Nano Banana 2 인물 가장자리 보정

## 실사용 확인

- 공개사이트의 Fate/Seoul 저장 장면에서 나디아의 웃는 표정을 Nano Banana 2로 생성했습니다. 기존 기본 인물을 참조해 얼굴을 다시 그렸고, 머리·눈 색, 의상, 장신구, 책과 자세가 유지되는 것을 확인했습니다.
- 생성된 인물이 대사와 함께 표시되고 400 오류는 재발하지 않았습니다. 새 표정에서 머리카락과 옷의 초록색 잔테를 발견해 보정합니다.
- 확인 범위는 이 인물의 표정 변형입니다. 모든 인물·표정의 외형 일관성을 보장하는 검증은 아닙니다.

## 수정

- 배경 제거의 혼합 알파 계산에서 초록 성분이 일정량 남던 계산을 수정했습니다.
- 투명한 윤곽 주변에만 선택한 배경색의 잔여 성분을 제거합니다. 알파, 얼굴 형태, 자세와 프레임은 그대로 유지합니다. 인물 내부 색상은 전역적으로 제거하지 않습니다.
- 기존 Gemini 인물 캐시는 로드 시 기기에서 한 번 보정합니다. 이전 캐시에 배경색 정보가 없으면 윤곽의 지배적인 잔색을 확인하며, 판단이 불확실하면 그대로 둡니다.
- OpenAI 인물과 배경은 이 보정 대상이 아닙니다. 기존 유료 이미지를 삭제하거나 자동 재생성하지 않습니다. 디코딩·저장 실패 시 기존 그림을 계속 사용할 수 있습니다.

## 검증

- 실제 생성한 나디아 이미지의 보정 전후 렌더링을 비교했습니다.
- 초록·자홍·파랑 잔테, 낮은 알파 가장자리, 피부·인물 내부 색상 보존, 반복 적용 안정성 테스트를 추가했습니다.
- 오프라인 캐시 보정, 보정 실패 시 원본 유지 및 추가 API 요청 없음 테스트를 추가했습니다.
