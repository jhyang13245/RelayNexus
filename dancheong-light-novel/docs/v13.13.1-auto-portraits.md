# v13.13.1 — 완전 자동의 인물 준비 대기

## 원인

v13.13.0은 본문 표시·낭독 완료만 확인했습니다. 첫 글의 최대 5초 대기가 끝나면 현장 인물 확인이나 입상 생성이 아직 진행 중이어도 다음 문장·턴으로 넘어갈 수 있었습니다.

## 수정

- 첫 글은 기존처럼 턴당 최대 5초 후 표시합니다. 이미지 준비와 글 표시를 병행합니다.
- 완전 자동의 페이지 이동과 장면 이어가기는 별도로 현재 비트의 현장 인물 확인, 확인된 인물 전원의 입상 준비, 실제 화면 표시까지 기다립니다. 말하지 않는 동행자도 포함합니다.
- 준비 중에는 기존 음성 상태 영역에 인물 확인·이미지 준비 상태를 표시합니다. 늦게 준비된 인물이 바로 지나가지 않도록 표시 완료 후 최소 1.5초 간격을 둡니다.
- 기존 입상·표정을 재사용하며 같은 기본 입상의 이전 표정이 표시 중이면 불필요하게 막지 않습니다. 다른 인물·다른 복장의 그림은 준비 완료로 인정하지 않습니다.
- 사건 배경이 실제 표시된 경우 거기에 그려진 참여 인물은 준비 완료로 인정합니다. 목격자 입상은 따로 확인합니다.
- 현재 비트의 인물만 확인합니다. 다음 문단의 미리 생성 중인 입상, 배경, 선택적 구도·눈·입 이미지 때문에 기다리지 않습니다. 사람이 없는 것으로 확인된 장면에는 입상을 요구하지 않습니다.
- 현장 인물 확인 실패, 필요한 기본 입상 생성 실패, 키 누락·이미지 생성 일시 중지, 표시 오류는 완전 자동을 멈추고 안내합니다. 실패한 유료 요청을 자동 반복하지 않습니다.
- 이미지 준비와 표시 사이에 실행 예약이 생겼더라도 이동 직전 다시 확인합니다. 새 대기가 생기면 이전 예약을 취소합니다.

수동 진행, 일반 자동 읽기, 인물 신원 검증 기준, 원본 Cortex 엔진, 저장 데이터 형식은 유지합니다.

## 검증

기존 테스트와 함께 실제 자동 진행 함수·가짜 엔진 및 지연된 이미지 응답으로 다음을 확인합니다: 첫 글 대기 만료 이후 인물 생성 대기, 말하지 않는 인물 대기, 생성 후 화면 표시 대기, 이미지 오류·키 누락 시 정지, 중복 생성 방지와 캐시 재사용, 사건 참여자와 목격자 구분, 미래 이미지 작업과 현재 인물 대기의 분리, 이동 예약 후 새 인물 발견 시 취소.

실제 유료 이미지 API를 호출하거나 사용자의 공개사이트 저장 내용을 변경하는 테스트는 수행하지 않습니다.
