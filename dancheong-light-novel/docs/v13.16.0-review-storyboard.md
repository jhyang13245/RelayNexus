# v13.16.0 — 업로드 검토와 장면 연출

## 검토 기준

공개본 v13.13.4와 업로드된 v13.15.0을 비교했다. Cortex 원본 SHA-256 `e0b43be5f6eee30cf6908cea694545457c0cee48adbe43ac49348c5fd743b394` 및 의존성은 유지했다. 업로드의 설정 탭, Typecast/Gemini 음성, 퀵 저장, 글꼴·루비, 갤러리, 표정 합성 선택 기능을 통합했다. 이 문서는 유료 음성 모델의 청감 품질을 보증하지 않는다.

## 발견하고 수정한 문제

- Gemini Interactions 음성 요청의 `input`을 공식 REST 형식인 `user_input.content`로 감쌌다. 본문과 연기 지시를 분리한다.
- 뒤늦게 붙는 한숨·웃음 태그가 음성 캐시 키를 바꾸지 않도록 했다. 이전 태그 포함 키와 OpenAI 기본 낭독(marin) 녹음도 재사용한다. 명시적으로 목소리를 바꾸면 새 선택을 우선한다.
- 기록에서 저장 음성을 듣는 동안 현재 장면의 재렌더가 재생을 가로채거나 새 음성을 요청하지 않도록 했다. 기록 조회는 진행 중인 유료 요청에 합류하거나 그 요청의 추적 상태를 지우지 않는다.
- Typecast의 적합한 목소리가 하나만 있어도 성별·연령에 맞는 후보를 우선한다. 목록을 불러오기 전 완전 자동은 설정 안내를 한다.
- 새 TTS의 WAV/OGG 등 지원 음성과 Typecast 크레딧 기록을 슬롯 파일로 내보내고 다시 가져올 수 있게 했다. 크레딧은 0달러로 표시하지 않는다.
- 음악 복구 시 떨어져 있는 동일 분위기를 연속된 분위기로 오인하지 않도록 했다.
- 갤러리를 닫은 뒤 비동기 로딩 결과가 이미지·음원을 계속 붙잡지 않도록 취소 번호와 정리를 추가했다.
- 얼굴 합성 캐시의 키를 길이·파일 끝부분 대신 두 원본 전체 URL로 구분한다. 얼굴 합성은 선택 기능이며 기본 꺼짐을 유지한다.

장소·시간이 그대로인 다음 턴에는 장면 카드를 반복하지 않는다. 선택적 컷·효과의 진입 허용은 읽기 시작 후 최대 1.2초 및 14글자까지이며, 실제로 읽는 도중 들어온 구도 지시가 화면을 비우지 않도록 고정한다. 첫 문장의 인물 준비 유예 5초는 별도다. 인물 입상은 준비되는 대로 나타나며, 이 제한은 선택적 사건·구도 그림을 대상으로 한다. 읽기 시작에 늦은 그림은 캐시에 남고 되돌아가 읽을 때 사용할 수 있다.

새 구도 항목은 기존 현장 인물 확인 응답에 포함한다. 기존 판정 캐시는 유효하며, 연출만을 위해 다시 호출하지 않는다. 저장 슬롯·API 키·기존 이미지의 키는 유지한다. 새 유료 생성, AI 음성, 사건 CG, 표정 합성 등의 기존 ON/OFF 값을 강제로 바꾸지 않는다.

## 검증과 한계

- 업로드 그대로의 기존 검사 455개 통과 후, 새 회귀 검사를 포함한 전체 464개 통과. TypeScript 검사 통과. 배포용 빌드는 공개 배포 전에 별도 실행한다.
- 회귀: Gemini 요청 형식, 늦은 연기 지시의 캐시 재사용, 기록 조회/생성 경쟁, 구도 시점·범위·재방문, 완전 자동의 의도적 빈 화면, 새 음성·비용 백업 왕복.
- 로컬 Chrome에서 실제 작품 목록·Fate/Seoul 시작·설정 탭·본문 표시 확인. 별도 로컬 연출 검증 화면에서 실제 모듈과 기존 캐시 그림으로 독백·얼굴 분할 컷, 데스크톱 및 390×844/844×390 배치 확인. 스틸 레이아웃 검증 시에만 검증 화면의 컷 유지 시간을 연장했다. 이 검증 화면·개인 미디어는 배포물에 포함하지 않는다.
- 실제 유료 음성 호출·성우 수준의 연기·지연 측정은 이번 검증에 포함하지 않았다. 제공사 응답은 모의 응답으로 검사했고 실제 계정의 권한·할당량에 따라 결과가 달라진다. 모바일은 Chrome 뷰포트 검증이며 실제 iOS Safari 기기 검증은 하지 않았다.
- 손·발의 전용 원화나 모든 장면의 새 카메라 각도를 만들지는 않는다. 기존 그림의 얼굴 컷과 배경 구역 재사용이다. 새 사건 원화는 기존 설정과 인물 참조 조건을 따른다.
