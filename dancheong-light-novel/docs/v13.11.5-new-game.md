# v13.11.5 — 작품 메인화면 새로하기

- 작품 타이틀 화면의 이어하기 옆에 새로하기를 추가했습니다.
- 확인창에서 현재 이어하기가 새 진행으로 바뀐다는 점을 안내하고, 취소 또는 저장·불러오기를 먼저 열 수 있습니다.
- 현재 공개된 작품 패키지의 초기 상태를 검사한 뒤 적용합니다. 턴·사건 진행·읽은 위치·만난 인물은 첫 시작 상태로 돌아갑니다.
- 10개 수동 저장 슬롯, API 키, 모델·읽기 설정, 비용 기록, 작품의 그림체·입상 고정 설정과 생성 이미지 캐시는 지우지 않습니다.
- 패키지 다운로드·검사 실패 시 기존 진행을 바꾸지 않습니다. 엔진의 원자적 가져오기와 기존 저장 활성화 저널을 사용하여, 저장 중 탭이 닫히면 다음 실행에서 남은 화면 저장을 마무리합니다. 저널 형식을 공유하되 번호가 있는 슬롯에 새 진행을 쓰지 않습니다.
- 본문·판정·이미지 저장 중에는 기존 저장·불러오기와 같은 기준으로 작업 완료 후 실행하도록 안내합니다.
- 모바일 가로 화면의 작품 메뉴를 두 열로 배치하고, 제목 영역이 화면을 넘으면 스크롤할 수 있게 했습니다.

## 검증

자동 검사 317개 및 TypeScript 검사 통과. 초기 상태 구성, 자격증명 제외, 네트워크/검사 실패, 슬롯을 쓰지 않는 활성화와 중단 복구를 확인했습니다.

실제 크로노스 코어 패키지와 Cortex 엔진을 사용하는 별도 로컬 환경에서 첫 문장 복귀, 만난 인물 초기화, 1번·10번 슬롯 보존, 이전 슬롯 불러오기를 확인했습니다. 844×390과 390×844에서 확인창과 메뉴를 시각 검사했습니다. 공개사이트의 실제 플레이 데이터는 테스트로 초기화하지 않았으며, 모델 API는 호출하지 않았습니다.
