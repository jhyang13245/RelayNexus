# v13.9.6 — 인물 확대율 보정 실패 수정

- 확인한 Fate/Seoul 작품 외형 자료에는 홍재의 키가 163cm이며 나디아의 키 수치는 없다. 실제 브라우저 DOM에 적용된 신장 배율은 각각 0.9775, 1이었다. 1은 키가 명시되지 않았을 때의 표시 기본값이지 나디아의 설정 키가 아니다.
- 실제 표시 이미지에서 홍재의 갈색 머리 하이라이트가 피부색 후보로 먼저 잡혔다. 이 영역은 얼굴 측정에 실패해 전신 높이로 배치하는 예외 경로로 돌아갔고, 그 결과 나디아보다 얼굴이 지나치게 작아졌다.
- 서로 떨어진 피부색 행들을 하나의 얼굴로 합산하지 않는다. 첫 영역의 얼굴 측정이 실패하면 머리 위쪽에서 충분한 면적과 밀도를 가진 연결된 피부 영역을 찾아 얼굴 크기를 다시 계산한다. 얇은 하이라이트·귀걸이·아래쪽 가슴 영역은 후보에서 제외한다. 기존 정상 측정과 저신뢰도 이미지 예외 처리는 유지한다.
- 실제 홍재 표시 이미지의 얼굴 측정은 실패에서 성공(폭 131px, 머리 폭 218px)으로 바뀌었다. 나디아의 기존 측정(얼굴 폭 160px, 머리 폭 239px)은 유지됐다. 화면에서는 공통 얼굴/머리 크기 목표에 맞춰 전체 이미지를 동일 배율로 배치·크롭한다.
- 공개 프로필에 따른 신장 보정, 원본 이미지, 이미지 캐시, 생성 모델 및 비용 집계는 변경하지 않는다. 캐릭터별 강제 배율이나 홍재에만 적용하는 특례가 없으며 이미지 API 요청도 없다.

## 검증

- 갈색 머리 하이라이트, 피부 영역 사이의 빈 행, 옆으로 치우친 얼굴, 어두운 피부색, 얼굴 없는 이미지, 명시된 키의 독립적 보정을 회귀 테스트로 검증했다.
- 실제 크롬 플레이의 두 표시 이미지를 내려받아 로컬 브라우저에서 수정 전후 렌더링을 직접 비교했다. 원본 작품과 플레이 데이터는 수정하지 않았다.
- 범용 얼굴 인식 모델이 아닌 픽셀 기반 추정이므로 모든 그림체와 포즈의 정확한 크기를 보장하지는 않는다. 근거가 부족한 그림은 기존 배치로 안전하게 돌아간다.
