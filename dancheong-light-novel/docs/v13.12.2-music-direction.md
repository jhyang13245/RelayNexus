# v13.12.2 — 음악 유지·무음 연출과 이미지 없는 인물

## 배경음악

원인은 화면 색감에 쓰던 비트별 `mood`를 음악 재생기에 그대로 넘긴 것이었습니다. 평상시·슬픔이 번갈아 나오면 매번 음악 교체를 요청했습니다.

- 음악 전용 `music.cue`(`keep`, `silence`, 분위기 이름)와 본문 근거를 기존 연출 판단에 함께 받습니다. 별도 텍스트 API 호출은 추가하지 않습니다.
- 기본은 현재 곡 유지입니다. 짧은 슬픈 단어, 웃음, 화자 변경만으로 곡을 바꾸지 않습니다. 음악이 필요 없는 도입, 여운, 긴장 속 정적 등에는 `silence`를 선택할 수 있습니다.
- 보통 전환은 현재 곡 24초 유지, 전환 근거 6초 유지, 서로 다른 2페이지를 요구합니다. 뒤의 `keep`은 앞에서 정한 음악 진입을 이어받습니다. 명시적인 무음과 강한 충격 효과가 있는 긴장·공포 전환은 최소 8초로 짧게 반응합니다.
- 음악 지시가 없는 기존 연출 캐시는 다시 유료 판정하지 않습니다. 기존 분위기는 30초 유지·8초 후보 유지·3페이지 확인 후 바꿉니다. 평상시/슬픔이 문장마다 번갈아 나오면 곡을 유지합니다.
- 이미지 도착에 따른 다시 그리기, 뒤로 읽기, 확정 전 스트리밍은 새로운 전환 근거로 세지 않습니다.
- 무음은 기본 곡으로 대체하지 않습니다. 작품 음원의 Web Audio 경로는 약 1.8초에 걸쳐 사라지고, 기기 합성 음악도 페이드아웃합니다. HTML 오디오 대체 경로는 정지합니다. 환경음·효과음·AI 음성은 각각의 기존 설정을 따릅니다.
- 음악을 해독하는 동안 무음으로 바뀌거나 화면을 다시 눌러도 이전 요청이 늦게 음악을 재생하지 않습니다. 새 작품/저장 불러오기는 음악 판단을 초기화합니다.

## 내장 이미지 없는 등록 인물

공개된 등록 인물은 내장 이미지가 없어도 이미 기본 입상 생성 대상이었습니다. 이번에는 이 경로를 명확히 검증하고, 참조가 없을 때의 프롬프트를 분리했습니다.

- 장면에 실제로 등장한 것으로 검증된 인물만 인물용으로 선택한 OpenAI 또는 Nano Banana 2에 요청합니다.
- 내장 그림이 없으면 공개 프로필·공개 외형 설명으로 첫 얼굴과 기본 복장을 그립니다. 다른 인물의 그림을 단독 기준으로 빌려 오지 않습니다.
- 생성된 입상을 저장하여 같은 인물이 다시 나오면 재사용합니다. 이후 표정 요청은 생성한 본인 입상을 참조합니다. 기존 유료 입상의 키를 바꾸거나 일괄 재생성하지 않습니다.
- 기억·사진·인용으로만 언급된 인물은 생성하지 않습니다. 비공개 신원/외형은 기존 Cortex 공개 정책을 유지합니다.
- 패키지에서 기준 그림을 지정했는데 그 파일을 불러오지 못한 경우는 ‘내장 그림 없음’과 다릅니다. 임의의 다른 얼굴을 유료 생성하지 않고 기존 오류·재시도 경로를 유지합니다.

## 검증 범위

음악 변경 간격·일시적인 분위기 교대·무음 지속·늦은 디코딩 취소·탭 재개·효과음 분리와 실제 Cortex 공개 투영 → 인물 배치 검증 → 두 제공사의 이미지 요청 → 캐시 복원 → 표정 재사용을 자동 검사합니다. 외부 모델 응답은 고정 응답으로 대체하여 검증 중 유료 API를 호출하지 않습니다. 실제 모델의 연출 판단이나 새로 그린 얼굴의 품질은 이 검사만으로 보장하지 않습니다. 전체 테스트, TypeScript 검사, 배포 빌드 결과를 배포 완료 시 보고합니다.

원본 `vendor/Cortex_v1.42.0.html`은 변경하지 않습니다. 작품 덧칠 관리·세이브·기존 미디어 캐시는 유지합니다.
