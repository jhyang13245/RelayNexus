# v13.2 — 얼굴 재작화와 필요한 순간의 이미지 교체

- 고정 타원으로 눈·입 부분을 잘라 중립 얼굴에 섞던 합성을 제거했다. 생성된 인물 이미지 자체를 원래 비율로 표시하며 입상 여백만 정리한다. 기존 `faceBlend` 설정은 사용하지 않는다.
- 표정 요청은 중립 입상을 동일 인물의 기준으로 삼아 얼굴의 눈·코·입·볼·턱·명암을 함께 다시 그리도록 변경했다. 몸·의상·구도는 유지하도록 요청한다. 실제 동일 인물 유지와 그림 품질은 선택한 이미지 모델의 결과에 달려 있다.
- 연출 모델은 평범한 대화·화자 변경·말투 차이에는 표정을 유지하고 뚜렷한 감정 전환에만 교체하도록 요청한다. 표정 근거는 해당 페이지까지 공개된 본문에 존재해야 한다. 이후 페이지의 감정 근거는 거절하며, 새 근거가 없으면 같은 문단의 확정 표정을 유지한다.
- 기존 인물 배치·카메라 캐시는 그대로 쓴다. 감정 근거 없이 저장된 이전 버전의 대사별 표정 추측은 보수적인 서술 표정 규칙으로 대체한다.
- 배경 키는 기존과 같이 작품·장소·시간대·날씨에만 따른다. 대사·화자·턴·분 단위 시각이 달라져도 같은 배경을 재사용한다.
- 새 표정을 준비하는 동안 이미 표시된 동일 인물 이미지를 유지한다. 첫 등장 인물은 이전처럼 이미지가 보일 때 대사를 시작한다.
- 배경·중립 인물 캐시는 유지한다. 새 방식으로 처음 필요한 표정만 한 번 생성하고 저장한다(이미지 비용 발생). 기존 표정 이미지는 오프라인·실패 시 대체 이미지로 보존하며 얼굴 합성을 적용하지 않는다.

검증 범위: 캐시 재사용·표정 갱신·시점별 근거 검사·브라우저 표시·기존 회귀 테스트. 실제 유료 모델의 재작화 품질과 감정 판단 정확도는 별도 실사용 확인이 필요하다.
