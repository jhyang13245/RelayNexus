# v13.11.8 인물 오연결 방지와 본문 대기 표시

## 인물 신원 연결

누락을 무조건 채우기보다 잘못된 입상을 띄우지 않는 것을 우선합니다. 작품 이름이나 인물 ID를 공통 코드에 추가하지 않고 다음 근거만 읽습니다.

1. 기존 `presentation.eventPublicAliases`의 사건별 명시적 연결.
2. 사건 노드의 구조화된 참여자: `participants: [{ characterId: "등록 ID", publicName: "금발 여학생" }]`. 정확하고 유일한 등록 이름을 `characterName`으로 제공할 수도 있습니다.
3. 엄격한 작가 표기: `participants: "김다윤(공개 호칭: 금발 여학생)"`.
4. 이미 공개된 서술의 확정적 신원 문장: `금발 여학생은 김다윤이었다.` 또는 `김다윤이라는 이름의 금발 여학생이 …`. 작가의 명시적 연결이 있는 인물은 그 연결을 우선합니다.

외형·성별·직업의 유사성, 유일한 참여자라는 이유, 대사 속 자기소개·추측·회상으로 연결하지 않습니다. 자동 연결은 해당 사건에만 적용하며, 다른 사건과 과거 재생으로 전파하지 않습니다. 같은 호칭이 겹치는 후보, 중복 등록 이름, 명시적 공개 제한은 보류합니다. 현재 문단 뒤쪽에서 밝혀질 신원으로 앞쪽의 익명 인물을 미리 연결하지 않습니다.

신원과 현장 존재를 별도로 확인합니다. 기존 연출 호출에 `identityStatus`와 `presence`를 요구하며, 모호하거나 비현장으로 분류한 인물은 제외합니다. 전화·사진·기억·미래 등장 등 명백한 간접 근거는 런타임에서도 거부합니다. 모델이 근거에서 ‘다른’이나 ‘전화 너머’ 같은 수식어를 잘라 냈더라도 원문 문맥을 함께 확인합니다. 인물이 확인되지 않았을 때 기존 입상을 대신 빌려 띄우거나 새 입상을 요청하지 않습니다.

이 검사는 자유로운 한국어의 모든 의미를 결정적으로 판별하는 보장은 아닙니다. 자동 연결은 좁은 확정 서술 형식만 지원하며, 복잡하거나 애매한 문맥은 인물이 일시적으로 보이지 않을 수 있습니다. 해당 경우에는 작품 패키지에 사건별 공개 호칭을 선언하는 것이 가장 확실합니다.

## 본문 중간 대기 표시

- 마지막 글자가 표시된 뒤 700ms 이상 실제 표시가 진행되지 않으면 글자 옆의 점 세 개를 켭니다. 300ms 갱신 주기 때문에 실제 표시 시점은 약 0.7~1초입니다.
- 문장 끝뿐 아니라 몇 글자만 받은 스트림 간격, 아직 표시할 글자가 남은 상태의 지연도 감지합니다. 요청 상태가 잠시 꺼졌어도 공개 스트림이 계속되는 동안 표시합니다.
- 글자가 다시 표시되면 즉시 점을 지웁니다. 보통의 문장부호 휴지, 완료된 문장, 다음 페이지가 준비된 경우, 메뉴·기록·설정·강조 화면의 의도적 정지에는 표시하지 않습니다.
- 이미 한 글자라도 읽기 시작한 페이지는 늦은 인물 준비 상태 때문에 본문을 지우고 다시 대기하지 않습니다. 턴 시작의 최대 5초 대기는 유지합니다.
- 기존 CSS 점 애니메이션을 재사용합니다. 본문 감시 때문에 매번 무대를 다시 그리거나 이미지 캐시를 조회하지 않습니다. 화면 움직임 최소화에서는 정적인 점으로 표시됩니다.

## 비용·저장

신원 연결 파서와 점 표시에는 AI 호출이 없습니다. 기존 인물 배치 정책 V7은 V8로 갱신되어 필요한 문단의 연출 판정이 다시 수행될 수 있습니다. 이미 생성한 입상·표정의 캐시 키를 유지하며 전체 이미지 재생성을 요구하지 않습니다. Cortex 원본, 작품 정사, 저장 슬롯, 키 저장 구조는 변경하지 않습니다.

## 검증

- 회귀 테스트 357개 통과: 동일/겹치는 호칭, 이름 부분 문자열, 회상·사진·전화·다른 사람, 뒤늦은 입장과 신원 공개, 비공개 제한, 캐시 입상으로 잘못 대체하지 않기, 스트리밍 중간 정지·재개·메뉴 일시정지 포함.
- Fate/Seoul의 실제 저장본으로 기존에 누락되던 익명 아처 후보·기준 이미지·물리적 등장 근거가 계속 연결되는지 로컬에서 확인했습니다. 저장본은 배포와 공개 소스에 포함하지 않습니다.
- TypeScript 검사와 배포 빌드를 확인합니다. 동일한 본문 표시 모듈과 실제 CSS를 쓰는 로컬 재현 화면에서 글자 옆 점 표시와 재개 시 제거를 브라우저로 확인했습니다.
- 실제 유료 모델을 새로 호출하거나 전체 게임을 플레이한 검증은 아닙니다. 모델의 모든 자유 서술·응답 조합에서 오연결이 없어짐을 보장하지 않습니다.
