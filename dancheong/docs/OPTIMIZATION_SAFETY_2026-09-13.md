# 단청 안전 최적화 적용 기록

## 범위와 보존 원칙

2026-09-13 전면 검수에서 확인한 항목 중, 기존 기능과 저장 형식을 유지하며 검증 가능한 변경을 적용했다. 전면 검수 후보가 모두 제거되었다는 뜻은 아니다. 본문 승인·판정·스포일러 정책, Lotus/Cortex 호환 경로, 계정 소유권·리비전 충돌 검증, 멀티플레이 규칙, UI 디자인은 변경하지 않았다.

## 적용

- 정보창: 확정 비트의 인물 검색 결과를 비트 객체별 WeakMap에 재사용한다. 본문·대사 주석·공개 인물 정보가 바뀌면 무효화한다. 복원·되돌리기에서도 현재 비트 목록을 기준으로 인물 목록을 다시 합성한다. 변경 없는 100비트에 정보창 갱신 5회 시 인물 본문 검색 0회이며, 편집·공개 별명 변경은 재검색한다. API 비용·이미지 목록 등 나머지 정보창 계산을 전부 없앤 것은 아니다.
- Instant HUD: 값이 같은 동안 기존 DOM을 보존한다. 비트 수·관계·프로필이 변경되면 갱신하며 정사 모드로 바뀌면 전용 HUD를 제거한다. 숨겨진 문서의 주기적 정보창 갱신만 중지하고 복귀 시 갱신한다.
- 멀티플레이 작품 선택: 인증된 `/api/library?summary=1`에서 작품·세션만 가져온다. 비용·신뢰도 상세 조회를 생략하며 기존 기본 API 응답은 유지한다.
- 싱글 기기 사용권: 5초 갱신 주기는 유지하면서 처리 중인 갱신의 중복 실행을 막고 15초 제한을 둔다. 인계·재획득·이후 재시도 경로를 보존한다.
- 너름 목록: 재조회 시 이전 요청을 취소하고 오래된 응답이 새 결과를 덮지 못하게 한다. 화면 종료 시 취소하며 20초 지연에는 재시도 안내를 표시한다. `AbortSignal.any`를 요구하지 않는다.
- 패키지 원본 메모리: 저장에 성공한 ZIP의 가속 캐시는 LRU 32MiB로 제한한다. 큰 ZIP은 IndexedDB에서 복원한다. 아직 저장 중이거나 실패한 원본은 별도로 보존한다. 따라서 미저장 원본까지 포함한 전체 메모리 상한을 32MiB로 보장하는 것은 아니다. 데이터베이스 구조와 원본 데이터는 변경하지 않는다.
- 클라우드 저장: 동일 요청에서 이미 검증·해시한 불변 JSON의 결과만 재사용하여 두 번째 JSON 검사·인코딩·SHA-256 계산을 생략한다. 임의 객체·변경된 본문·위조 해시는 재검증하며 읽기 무결성 검사는 유지한다. 포인터·저장 형식·트랜잭션·이전 객체 정리 순서는 그대로다.
- 미사용 코드: 호출 참조가 없는 지역 함수 `buildLegacyStaticPrompt`와 설명 주석 288줄, 미사용 모델 상수와 오류 메시지 변수를 제거했다. 원본은 Git 이력으로 복원 가능하다. 실제 이미지 fallback은 남겼다. 삭제된 원본 크기를 곧바로 다운로드 감소량으로 주장하지 않는다.
- 오래된 Muse 첫 문단 2배속 테스트는 현재 사용자가 선택한 읽기 좋은 공통 속도에 맞췄다. 실제 스트리밍 속도를 변경하지 않았다.

## 검증

- 단위·지음 전체: 770 통과, 1 선택 검사 건너뜀.
- Cortex 전체 헤드리스: 104 통과, 3 개인 백업 선택 검사 건너뜀. 이후 Instant HUD DOM 보존 검사를 해당 테스트에 추가해 재검증했다.
- 서버 HTML·지음 렌더: 61 통과.
- 추가 안전 테스트: 캐시 퇴출·33MiB 원본 복원·저장 실패 복구·해시 재사용/위조 거부·목록 인증/기존 응답·갱신 요청 중첩/인계·오래된 목록 응답 무시를 실행했다.
- 운영 빌드 성공. 변경한 운영 파일에 타입 진단 없음. 별도 운영 소스 검사에는 다른 파일의 기존 타입 진단 46건이 남는다. 타입 검사를 끄거나 오류를 숨기지 않았다.
- API 응답과 네트워크 경합은 모의 테스트다. 실제 모델 품질, 실제 iOS/Android, 운영 PC↔휴대폰 교차 사용의 완료 보증은 아니다. 디자인 변경은 없으며 새 브라우저 시각 검수는 수행하지 않았다.

## 이번에 유지한 검수 후보

홈 대형 컴포넌트 분할, 전체 CSS 중복 규칙 제거, 장식 PNG 재인코딩, 싱글 이미지 분리 저장 전환, 지음 검증 타이밍 변경, 과거 공개 HTML 이동은 미적용이다. 이들은 실제 화면 비교·대형 패키지 계측·구버전 백업/직접 링크/교차 기기 계약 검증이 선행되어야 한다. 특히 싱글 미디어 분리 저장은 데이터 전환 작업으로 따로 검증해야 하며 이번 중복 해시 제거와 혼동하지 않는다.
