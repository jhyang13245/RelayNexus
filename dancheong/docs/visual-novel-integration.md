# 단청 비주얼노벨 통합 · 1.24.0

독립판 13.19.0 (`8e4705f1c6d8e63845547cef0444c9ee073087ca`)을 본사이트에 복사했다. `vendor/visual-novel/manifest.json`은 원본 파일의 해시를 기록한다. 별도 사이트를 불러오는 iframe이나 외부 플레이 링크를 사용하지 않는다.

## 실행과 저장

- 단청 서재에서 소설/비주얼노벨을 선택한다. 두 화면은 같은 Cortex iframe, 엔진 객체, 작품 패키지, 턴과 계정 저장을 사용한다. 전환은 엔진을 다시 실행하지 않는다.
- 읽기 위치는 턴 ID와 본문 오프셋, 입력 초안은 공통 엔진 입력란을 통해 넘긴다. 비주얼노벨을 벗어나면 자동 진행·재생·새 미디어 요청을 멈춘다. 이미 결제된 요청의 결과는 캐시에 남긴다.
- 독립사이트의 기록과 API 키는 가져오지 않는다. 계정별 본사이트 세션 저장을 기준으로 시작한다.
- 현재 진행은 기존 단청 클라우드 자동 저장을 사용한다. 비주얼노벨 10개 슬롯과 퀵 슬롯, 파일 백업, 생성 미디어 포함 클라우드 백업도 제공한다. 이 슬롯은 본사이트 계정+세션에 속한다. 다른 작품의 슬롯을 현재 세션에 덮어쓸 수 없다.
- 진행을 바꾸는 슬롯 불러오기는 기존 클라우드 사전 확인과 쓰기 잠금을 통과한다. 화면 상태는 `scenario.runtime.vnPresentation`, 장면 자료는 기존 `turn.vnScene`에 보관한다. API 키는 저장본에 포함하지 않는다.
- 본문 API·표시 속도·품질은 단청 공통 설정에서 관리한다. 추가 이미지·음성 공급자 키는 본사이트의 계정별 암호화 기기 보관함에 저장한다.

## 원본에서 유지하는 기능

인물 연결과 신원 공개 제한, 5초 대기와 스트리밍, 입상·표정·복장 재사용, 신장과 구도 정렬, 배경 및 사건 이미지, 마스크 전환·컷인·강조·카메라, NVL/ADV, 음악·AI 음성·Typecast 출처, 자동/완전 자동, 기록, 진행 정보, 비용·예산, 저장 공간 관리, WebP·메모리 제한, 오류 복구와 모바일 CSS는 독립판 모듈을 사용한다. 원본 타이틀 화면의 인물/갤러리/성능 점검은 플레이 메뉴에 배치했다. 작품 선택·덧칠 설치·새 세션은 단청 기존 서재에서 관리한다.

## 검증 방법

`node scripts/vendor-cortex.mjs`, `tsc --noEmit`, 기존 Cortex/계정 저장 검사 및 `tests/cortex/vn-port.test.mjs`로 빌드와 계약을 검사한다. `node scripts/vn-preview.mjs`는 localhost:5401에서 합성 본문으로 같은 엔진·턴·입력 보존 및 화면 전환을 검증한다. 실제 사용자 기록을 쓰거나 유료 API를 호출하지 않는다. 이 검증 서버와 자료는 공개 정적 파일에 들어가지 않는다.

## 이번 검증 결과와 한계

- 타입 검사와 배포용 Worker 빌드, 92개 원본 파일 해시 및 의존성 검사 통과.
- 기존 단위 검사 859개 중 858개 통과, 선택적 외부 자료 1개 생략. 버전 문서 불일치는 수정 후 해당 50개 검사를 재실행해 통과했다.
- Cortex 검사 138개 중 선택적 비공개 자료 3개 생략. 병렬 빌드와 함께 실행할 때 시간 민감 검사 1개가 실패했으며, 해당 프로토콜 묶음 10개를 단독 재실행해 모두 통과했다.
- 실제 SQL 마이그레이션을 적용하는 클라우드 서비스 검사 5개 통과: 계정 분리, 출처 검사, 충돌·중복 저장 방지, 미디어 재사용, 불완전 업로드 보존.
- 브라우저에서 같은 엔진 객체·턴·입력 유지, 양방향 전환, 10개 슬롯과 저장/불러오기, 모바일 세로·가로 화면을 확인했다. 합성 자료를 사용했으며 실기기의 모든 해상도나 장시간 플레이 검증은 아니다.
- 이번 이식에서 유료 이미지·음성·집필 API를 실제 호출하지 않았다. 공급자별 생성 품질과 운영 환경의 모든 실패 조건을 재검증한 것은 아니다.
- 이 모드 선택은 기존 독립판과 같은 개인 플레이에 적용한다. 멀티플레이는 기존 전용 플레이어와 차례·공유 저장 계약을 유지한다.
