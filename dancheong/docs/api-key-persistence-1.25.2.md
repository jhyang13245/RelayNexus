# v1.25.2 · 기기 API 키 유지

## 수정

- 공통 OpenAI / OpenCode Go 키를 첫 화면 로드와 제공자 전환 시 바로 복원한다. 업데이트 후마다 유료 연결 검사를 실행하지 않는다.
- 자동 연결 검사 실패 시 키를 지우던 경로를 제거했다. 명시적으로 연결·저장한 키는 연결 확인이 실패해도 암호화 저장한다.
- IndexedDB를 일시적으로 읽지 못해도 기존 암호문을 삭제하지 않는다. 명시적인 연결 해제·기억 해제는 계속 지원한다.
- 여러 탭이 처음 키를 동시에 저장해도 하나의 암호화 키를 사용하도록 IndexedDB 트랜잭션에서 확인·생성을 직렬화했다. 다른 제공자의 저장 중 암호화 키를 삭제하지 않는다.
- VN 키는 기존 계정별 DB 이름과 암호문 형식을 그대로 사용한다. 한 제공자의 복호화 실패가 다른 제공자 키의 복원을 막지 않는다.
- VN 설정은 실제로 바꾼 키만 저장한다. 읽기 실패로 비어 보이는 필드나 다른 탭의 오래된 값이 정상 저장된 키를 덮어쓰지 않는다.
- 별도로 저장한 VN OpenAI 키가 공통 설정 수신 때 덮어써지는 문제를 수정했다. 별도 키가 없으면 공통 OpenAI 키를 실시간으로 참조한다.
- 키 저장 성공 후 브라우저에 영구 저장을 요청한다. 지원하지 않거나 거부되어도 정상 저장 결과를 취소하지 않는다.

## 검증

- 가짜 키로 동시 최초 저장, 기존 VN 형식 호환, 제공자별 삭제, 일시 저장소 오류, 부분 복호화 실패, 다른 탭의 키 보존을 검사한다.
- 지연된 제공자 복원이 최신 선택을 덮지 않는 것과 새로고침 시 연결 검사가 호출되지 않는 것을 검사한다.
- Chrome 로컬 검증 화면에서 공통 키 2개와 VN 키 4개를 동시에 저장한 뒤 실제 새로고침하여 모두 복원되는 것을 확인했다.
- 사용자 실제 키를 읽거나 유료 제공자 API를 호출하지 않았다. 물리 iPhone에서의 저장 공간 회수 동작은 검증하지 않았다.

## 유지 범위

같은 사이트·브라우저의 기기 저장을 유지한다. 저장 형식·DB 이름에 앱 릴리스 번호를 붙이지 않는다. 키는 작품 저장·클라우드 저장·멀티플레이 공유 데이터에 포함하지 않는다. 사이트 데이터의 명시적 삭제, 브라우저의 저장 공간 회수, 이미 삭제된 이전 키까지 복구할 수는 없다. 기존 Cortex/VN 원본은 변경하지 않고 메인 통합 어댑터에서 적용한다.
