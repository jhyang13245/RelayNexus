# Approved prose is canonical

- Published paragraphs and committed turn text are the canonical narrative, even
  when they contain an authoring mistake. Do not reclassify, censor, replace or
  delete their content in the reader, copy action, cast history, memory input,
  dialogue recovery input or scene-prose input to image generation.
- Disclosure and prose audits run before publication. Recommendation-looking
  prose must be handled there, not retrospectively removed from accepted text.
- Reserved wire envelopes and speaker annotations are transport data, not prose;
  decoding them before publication and safely rendering text remain necessary.
- Package-only private profiles, unrevealed identities and restricted media remain
  separate from public prose. A public name does not release every secret about
  that person. Image selection still requires an identified public speaker, not
  an appearance-keyword similarity or a nearby name.
- First-appearance public surfaces follow approved dialogue as well as narration.
  Unambiguous proper-name shorthand can bind an existing character; descriptive
  prefixes must never become identity aliases.
- Do not rewrite old saved turns to correct an authoring mistake automatically.
  An explicit user-requested edit, rewind or fork is a separate operation.
