# v1.25.9 · 산문작가의 화자 주석을 VN에서도 사용

## 변경

- 등록 인물의 대사는 산문작가가 같은 집필 호출에서 `⟦S:등록명|공개 호칭|PHYSICAL⟧` 주석을 붙인다. 전화·문자 등 현장 밖 발화는 `REMOTE`. 일반 문장은 그대로이며 주석은 스트림 디코더가 본문에서 제거한다.
- 등록명을 정확하고 유일하게 매칭한 내부 ID와 독자에게 표시할 호칭을 따로 저장한다. 미등록/중복 등록명은 호칭만 표시하며 인물을 추측하지 않는다. 기존 N·S·Q 주석도 읽는다.
- 소설 카드와 VN은 동일한 대사 위치·인용 원문에 묶인 주석을 사용한다. VN은 이 주석으로 확인된 현장 화자를 바로 준비한다. 기존 연출 판정은 별도로 계속되며 그 판정이 작가의 화자를 다른 인물로 바꾸지 않는다.
- 익명 호칭은 이미지가 준비되거나 첫 등장 판정이 끝났다는 이유로 실명으로 바뀌지 않는다. 작가 문맥에 마지막 공개 호칭을 주고 소개·호명·작중 발견 이후에 이름을 쓰도록 명시한다. 이는 집필 지침이며 모델의 모든 서술 오류를 완전히 차단하는 자연어 검증기는 아니다.
- 기존의 명시적 비밀·정체 공개 조건과 공개 전 전용 이미지 제한은 그대로 적용한다. 인물 연결 자체가 비밀 공개 권한은 아니다.
- 멀티 실시간 표시에는 등록명/원본 ID/프로필 대신 불투명 화자 참조와 공개 호칭만 전달한다. 받는 쪽은 자기 작품의 인물 목록에서 유일하게 확인하고 동일한 공개 제한을 적용한다.
- 이미지 키나 저장소를 초기화하지 않는다. 유료 입상 재사용, 설정과 저장 기록을 유지한다. 등록명 연결이 없는 과거 본문은 소급해서 추측하거나 다시 집필하지 않는다. 새 집필부터 새 주석이 적용된다.

## 검증

- 가상 작품으로 첫 익명 대사, 동일한 호칭/동일한 대사를 가진 두 인물, 대사 도중 연결, 늦거나 실패한 연출 API, 전화 발화, 비밀 인물, 잘못된/중복 주석, 소개 후 이름 전환, 저장 복원, 멀티 표시 참조를 검사한다.
- 기존 소설 화자 카드, 공개 이미지 제한, 연출 판정, 멀티 동기화·공유 생성 권한, 엔진 계약 회귀 검사를 실행한다.
- 실제 사용자 세션의 유료 집필·이미지 API 호출은 실행하지 않는다. 실제 모델이 새 집필 지침을 따르는 정도와 공개사이트 장시간 플레이는 별도 실사용 확인이 필요하다.
