# Cortex 1.7.0 — Continuity Graph

배포 범위는 독립 `dancheong-cortex-v1.7.0.html`입니다. Relay Nexus의 단청 기존 집필 엔진은 변경하지 않았습니다.

## 핵심 변경

- 전 턴 본문과 정사를 먼저 원자 확정한 뒤, 독서 시간에 `NEXT_TURN_CONTINUITY_CAPSULE_V3`를 백그라운드 생성합니다.
- 캡슐은 정사, 인물, 관계, 장기 아크, 물리 연속성, 모티프 원장을 분리해 보존합니다.
- 다음 입력에는 전체 원장을 재검색하지 않고 관련 기억을 최대 3개만 결정론적으로 선별해 작가 문맥에 추가합니다.
- 캡슐의 프로필, 정사 리비전, 사건 커서, 상태 해시가 현재 상태와 다르면 사용하지 않습니다.
- 미래 사건의 보호 설정은 내용 대신 불투명 참조와 누설 금지 제약만 저장합니다.
- V3가 아직 준비되지 않았거나 실패하면 기존 결정론적 안전 캡슐을 사용하며 다음 턴 시작을 기다리지 않습니다.

## API 실행 정책

- 독립 Cortex HTML의 모의·로컬 플레이 선택지와 실행 분기를 제거했습니다.
- 기기 브라우저에 저장된 API Key가 없으면 전송을 시작하지 않고 입력을 보존한 채 연결 설정을 엽니다.
- 본문 생성과 문학 캡슐 편집은 실제 Luna API 경로만 사용합니다.
- API Key 원문은 작품, 세션, 내보내기 로그에 포함하지 않습니다.

## 검증

- 전체 단위 테스트 512개 통과
- 렌더링 및 Cortex 표적 회귀 테스트 46개 통과
- 기존 첨부 로그 20턴 결정론적 재생 통과
- 실제 API 호출은 비용 방지를 위해 수행하지 않았습니다.
