# 단청 v1.26.1 · v1.26.0 소스 검토

## 검토 대상과 반영

사용자가 제공한 `Dancheong_v1.26.0_Source.zip`을 기존 v1.25.11 작업공간과 비교했습니다. 새 무대 연출·음악·녹음 효과음을 유지하고 다음 문제를 수정했습니다. 기존 키·플레이 기록·그림을 삭제하거나 데이터베이스 스키마를 변경하지 않습니다.

- 이미 페이지가 바뀐 뒤 완료된 빠른 컷 분석이 새 페이지에 속도선을 띄우던 문제.
- 페이지 이동·연출 끄기·동작 줄이기 이후에도 남던 반전·슬로모션과 배경 깊이 처리. 대화창/기록/메뉴를 열거나 탭을 숨기면 연출을 중지합니다.
- 문장 끝 구두점이 포함된 근거가 다음 문장의 액션까지 참조하던 문제. 부정문·대사 속 행동에 액션 연출을 붙이지 않습니다. 이는 보수적인 문장 검증이며 자연어의 모든 비유/부정을 이해하는 판별기는 아닙니다.
- 음악 전환 제한 시간이 지나도 재렌더가 없어 이전 음악에 머물 수 있던 문제. 단일 타이머로 갱신하며 초기화할 때 해제합니다. 무음은 즉시 적용하고 무음 장면에서는 인물 테마/음악 스팅어를 재생하지 않습니다.
- 다른 장소의 CG가 대기 회상으로 나오던 문제. 작품/장소/시간대 범위 안에서만 재사용합니다.
- 참여 입상이 일부만 준비됐을 때 CG 검사를 완료한 것으로 기록하던 문제. 준비된 인물/이미지 조합으로 검사 이력을 구분합니다.
- 세로로 매우 긴 원본의 픽셀 분석 높이가 무제한 늘어나던 문제. 가로·세로 모두 분석 상한 안에 유지합니다.
- 음량 정규화에서 건너뛴 샘플의 순간 피크와 trim 배수가 최대 음량 제한을 넘던 문제. 모든 채널의 피크를 확인하고 배수 적용 후 상한을 적용합니다.
- 잘못된 로컬 테마 이력(null 등)과 예상 밖 팔레트 값이 플레이를 중단시키던 문제.
- 가져온 소스 ZIP의 이전 매니페스트를 새 소스 해시에 포함해 파일 수/해시가 맞지 않던 문제. 매니페스트를 제외한 실제 파일로 해시를 계산한 뒤 새 매니페스트 하나를 작성합니다.

## 실행한 검증

- 새 회귀 검사 10개: 제공 원본에서는 10개 실패, 수정본에서는 10개 통과.
- 새 회귀 검사 + 기존 stagecraft 검사: 32개 통과.
- 전체 일반 테스트: 882개 중 881개 통과, 기존 skip 1개.
- 전체 Cortex 테스트: 276개 중 273개 통과, 기존 skip 3개.
- TypeScript `--noEmit`: 통과.
- Muse에는 별도 복사본의 아트 설정/색보정 경계 검사만 맡겼습니다. 결과 코드를 직접 읽고 로컬에서 실행해 24개 통과를 확인했습니다. 핵심 수정은 주 개발자가 수행했습니다. 보조 환경은 실행 명령이 차단되어 직접 실행하지 못했으며, 그 결과를 통과로 간주하지 않았습니다.
- 로컬 Chrome: 실제 통합 VN 진입과 연출 설정, 별도 fixture에서 실제 CSS·typesetter·stagecraft를 사용한 1440×900, 844×390, 390×844 렌더링을 검사했습니다. 합성 배경으로 색 강조와 중앙 문장, CG/연출 끄기 동작을 확인합니다. 재현 도구: `node scripts/vn-stagecraft-qa.mjs`(5452), 통합 도구: `node scripts/vn-preview.mjs`(5401). 두 도구는 로컬 전용입니다.
- 배포 게이트: `scripts/build-nexus.mjs`, 빌드 산출물 검사, 렌더링 HTML 검사, 소스 ZIP 해시·파일 수 검사를 거쳐 Sites에 전달합니다.
