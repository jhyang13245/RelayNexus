# 단청 Nexus 1.11.0 — Cortex 1.42.0 이식

Cortex를 기본 플레이 엔진으로 배치한다. 기존 Nexus 엔진은 설정의 Lotus 선택으로 유지한다. 두 엔진의 본문·상태를 서로 변환하지 않는다.

## 보존 경계

`vendor/cortex/Cortex_v1.42.0.html`은 제공된 Cortex 릴리스 원본이다.
SHA-256: `6dfbd01ae4f7774ac06cb3c6960b3e419526b28ba2f673ab5d87dfb99386da84`

빌드는 원본에 외부 호스트 스크립트와 스타일시트만 연결하여 `public/cortex.html`을 생성한다. 원본의 모든 인라인 스크립트와 DOM을 그대로 보존한다. Nexus는 같은 출처의 iframe에서 이 실행판을 연다. 집필, 문단 공개·수리, 판정, 비트 확정, 장기기억, 사건 전환, 분기, 엔딩, 이미지, 로그, 백업, 복원, 되감기는 모두 원본 Cortex가 담당한다. Nexus의 옛 simulate·상태 병합·시간 장소 검증 경로는 Cortex 본문을 처리하지 않는다.

시간·장소 HUD는 원본 Cortex가 최종 작가 트랙을 표시하는 화면을 그대로 사용한다. 별도 재해석은 없다. 멀티루트는 원본의 명시적 enabled 패키지에만 적용되고 일반 패키지에 강제되지 않는다.

## Nexus 연결부

- 서재: Cortex의 기기 내 세션 목록을 표시한다. Lotus 클라우드 세션 수치로 Cortex 진행을 표시하지 않는다.
- 작품 ZIP: 원본 Cortex의 ZIP 검사·적용 화면에 파일을 전달한다. 원본 이미지 자산 등록 경로도 유지한다. 적용 버튼을 눌러야 작품이 바뀐다.
- API 키: 같은 출처·해당 iframe인지 확인한 메시지로 전달하며 URL이나 서재 목록에 저장하지 않는다. Cortex 자체 설정도 그대로 사용할 수 있다.
- 저장: localStorage, sessionStorage, IndexedDB의 이름을 세션별로 격리한다. 비트 처리 중 엔진 전환·서재 이동을 막아 실행판이 중간에 제거되는 것을 피한다.
- UI: Nexus의 단청 녹색·따뜻한 배경·서재 디자인을 사용한다. Cortex의 기존 컨트롤은 삭제하지 않는다.
- 상태 알림: 호스트는 변경된 진행 여부와 공개 서재 정보만 받는다. 본문 생성 중 매 토큰마다 서재를 저장하지 않는다.

## 지원 범위

Cortex의 기기 저장·전체 백업·복원은 유지된다. 다른 기기에서는 전체 백업으로 옮긴다. 기존 Lotus의 클라우드 진행 동기화, 멀티플레이, 추천답변은 Cortex에 연결하지 않았다. 이 기능을 추가하려면 Cortex 실행 경로를 바꾸지 않는 별도 설계가 필요하다. Lotus 기록은 설정에서 엔진을 바꾸어 이용한다.

## 재현

Node 22.13 이상에서 `npm ci`, `npm test`를 실행한다. 빌드는 Windows/Linux 공통 Node 스크립트를 사용하며 HOME을 바꾸지 않는다. 소스 ZIP에는 vendor/cortex/parts의 원본 조각을 포함한다. `npm run build`가 이를 합쳐 원본 HTML과 `public/cortex.html`을 재생성하고 SHA-256을 검사한다. 오래된 build/cortex 내보내기 사본은 배포 소스 ZIP에 중복 포함하지 않으며 실제 build/sites-vite-plugin.ts는 포함한다.

검증: 기존 Nexus 단위검사 515개, 기존 실행판·서버 렌더 검사 58개, 이식 실행판 검사(원본 동등성, 실제 비트 확정·복원·격리, 메시지 출처, 분기·엔딩)가 통과했다. API는 모의 응답으로만 검증했다. 실제 유료 호출의 의미판정 품질이나 모바일 실기기 사용성까지 보장하는 결과는 아니다.

기존 소스의 전체 TypeScript 검사에는 Lotus API 및 보관된 옛 build 소스의 오류가 남아 있다. 제품 빌드는 통과하며, 이를 이식으로 새로 생긴 오류가 해결된 것처럼 보고하지 않는다.

## 배포

Nexus의 기존 사이트와 DB/BUCKET 바인딩을 보존한다. Cortex 독립 사이트와는 별개다. 원본 Cortex 업데이트 시 vendor를 명시적으로 갱신하고 원본 해시 및 이식 검사를 다시 수행한다.

배포 전송 호환성을 위해 원본 파일은 vendor/cortex/parts의 순서 있는 조각으로 보관한다. 빌드는 이를 합쳐 원본 SHA-256을 검사한 뒤 같은 HTML을 생성한다. 소스 ZIP에도 조각이 포함되며 원본 HTML과 이식 HTML은 빌드로 복원된다. 엔진 실행 내용은 변하지 않는다.

## 1.11.1 Nexus 화면 복원
원래 Nexus의 globals.css와 독서 화면 구성을 재사용한다. 표시 어댑터가 Cortex의 기존 DOM 요소를 같은 객체 그대로 옮기며, 엔진 스크립트와 본문은 변경하지 않는다. 오른쪽은 상태·사건·기록·진단 탭과 단청 카드 디자인을 적용한다. 기존 설정·백업·복원·되감기 버튼의 이벤트 핸들러를 유지한다. 모바일에서는 같은 패널을 서랍으로 연다.

## 1.11.2 Lotus 디자인 전용 적용
상태·사건·인물·이미지·기록·비용 6개 탭, 활성/봉인 상세 카드, 본문·입력창·상단 아이콘·모바일 패널을 Nexus 원본 스타일로 표시한다. Lotus 실행·판정·분기·비용 계산 로직을 가져오지 않는다. 공개 사건 DOM, 공개 인물 캡슐, 공개 이미지, Cortex 기억·API 응답 기록을 읽기 전용으로 표시한다. 원본 요소와 ID는 엔진 연결을 위해 유지하며 설정·복구 버튼의 핸들러는 그대로 보존한다. 비용 금액은 Cortex에 집계가 없으므로 미집계로 표시한다. 실제 청구액으로 오인할 0달러나 Lotus 추정식을 추가하지 않는다.

## 1.11.6 Lotus 부팅 화면

- Cortex 원본 문서가 파싱되는 동안에는 원본 UI를 숨기고 Lotus 부팅 화면만 표시한다.
- Lotus 화면 재배치가 끝난 뒤 첫 화면을 공개해 구형 Cortex 헤더·입력창이 잠깐 보이지 않게 했다.

## 1.11.5 Lotus 우선 화면 계약

- Nexus의 Lotus 화면을 최종 표현 계층으로 두고, 격리된 Cortex 런타임은 그 화면에 본문·상태·사건·기억·비용 데이터를 공급한다.
- 모바일 패널의 위치 규칙이 공통 스타일에 덮여 흐림막만 남던 회귀를 수정했다.
- 원본 Cortex 문서·스크립트·이벤트 처리기와 저장/API 경로는 변환하거나 복제하지 않는다.

## 1.11.4 Lotus 정보 패널 시각 정련

- 상태·사건·인물·이미지·기록·비용 탭을 Lotus의 종이 질감, 단청 색 포인트, 카드 깊이와 인장 표현으로 통일했다.
- 모바일 정보 시트의 헤더·탭·닫기 버튼과 간격을 다듬고 작은 본문 글자의 가독성을 높였다.
- 이 변경은 Cortex 공개 상태를 읽어 표시하는 CSS 계층에만 적용하며 엔진 로직, 판정, 저장 데이터와 API 흐름은 변경하지 않는다.

## 1.11.3 스트리밍 표시와 독서 영역
임베디드 화면은 고정하고 본문만 스크롤한다. 독립형의 window.scrollTo는 본문 영역으로 연결한다. Nexus story-content의 min-height:100%가 만들던 빈 공간을 제거한다. Lotus의 WorldWritingProgress 마크업과 물결 애니메이션을 재사용하며, Cortex의 STREAMING/displayTyping/ADJUDICATION_PENDING을 읽어 표시한다. 생성·감사·문단 공개·타이핑 버퍼는 Cortex 원본을 유지한다. 위로 스크롤해 읽는 동안 자동 추적을 멈춘다. 지연 API 모의 브라우저 검증에서 화면 유지와 진행 표시를 확인했으나 iOS Safari 실기기에서 제보된 전체 백화 자체는 재현하지 못했다.
