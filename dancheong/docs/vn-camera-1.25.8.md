# v1.25.8 · 작품 공통 입상 배율 보정

## 원인과 변경

- 앞머리 사이로 좁게 드러난 이마를 얼굴의 시작으로 잡으면 눈높이와 얼굴 너비 추정이 달라진다. 홍재·히시리의 기존 그림에서 이 현상을 재현했다.
- 공통 픽셀 보정 모듈은 연결된 머리 윤곽 안에서 충분히 넓고 밀집된 얼굴 영역을 찾는다. 좁은 이마 틈이나 떨어진 따뜻한 색 머리카락만으로 확대하지 않는다. 원본 아래쪽이 짧게 잘려 있어도 얼굴 확대 기준을 유지한다.
- 이 보정이 충분히 확인되면 얼굴 검출기의 준비 여부가 달라져도 같은 카메라 값을 쓴다. 확인하기 어려운 그림과 짧은 머리·노출된 이마는 기존 보정 경로를 유지한다.
- 작품·인물 이름에 따른 분기가 없다. 메인 스레드와 래스터 워커가 같은 함수를 사용하므로 모든 작품의 새 입상과 재사용 입상에 적용된다.
- 작품에 명시된 키, 기존 성인 기본값(남성 178cm·여성 162cm), 미지정값 168cm, 공통 가상 바닥 배치는 그대로 유지한다. 1인/다인 배치가 얼굴 확대율을 바꾸지 않는다.
- 로컬 카메라 메타데이터 버전만 갱신한다. 저장된 유료 그림, API 키, 세션 기록과 이미지 생성 키는 변경하지 않는다. 이 수정은 유료 호출을 추가하지 않는다.
- 독립 사이트 원본은 변경하지 않고 `scripts/port-visual-novel.mjs`와 `public/cortex-vn-camera.mjs`로 통합본에 적용한다.

## 검증

- 합성 픽셀 회귀 테스트: 앞머리 틈 유무, 아래쪽 크롭, 원본 해상도 2배, 얼굴 검출기 유무, 불확실한 피부 영역, 기존 이마 보정, 작품 신장/바닥 투영, 구형 카메라 캐시 교체.
- 저장된 홍재 2장·히시리 3장과 나디아·오요한 그림의 픽셀을 로컬에서 점검했다. 해당 그림과 플레이 백업은 공개 소스/배포물에 넣지 않는다.
- 같은 히시리 3장에 대한 카메라 높이 범위가 745–849에서 900–947로 줄었다. 숫자가 커질수록 표시 확대가 줄어든다. 이는 해당 표본의 측정 결과이며 모든 그림에 대한 품질 보장은 아니다.
- 1440×900, 844×390, 390×844 로컬 브라우저에서 실제 입상 프레이밍/CSS와 기존 그림으로 확인했다. 가로 화면에서 히시리 단독과 2인 배치의 이미지 높이는 모두 316.55 CSS px였다.
- TypeScript 검사 통과. 전체 Cortex 193건 중 189건 통과·3건 건너뜀·1건 타이밍 의존 테스트 실패 후 해당 파일을 단독 재실행하여 10건 모두 통과했다. 실패 지점은 기존 125ms 타자 진행량 검사이며 본 변경과 무관한 타이머 경합이었다.

## 한계

- 얼굴 픽셀 측정은 추정이다. 극단적인 측면, 특이한 피부색·가림, 그림 자체의 신체 비례 오류까지 완전히 교정하지는 않는다. 신뢰가 부족하면 기존 경로로 처리한다.
- 현재 Chrome의 실제 플레이 세션이 열려 있지 않아 저장 백업의 그림으로 검증했다. 실제 iPhone 및 실제 다중 계정의 유료 이미지 생성은 실행하지 않았다.
