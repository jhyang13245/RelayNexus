# Relay Nexus v1.10.3 릴리스 노트

배포일: 2026-08-26

## 세션방 읽기 경험

- 확대하지 않은 세션 본문은 세로 방향으로만 스크롤되도록 가로축 이동을 잠갔습니다.
- `pan-y pinch-zoom` 터치 정책으로 위아래 스크롤과 손가락 확대 동작을 함께 유지합니다.
- 긴 문장이나 콘텐츠가 본문 폭을 밀어내지 않도록 스크롤러와 본문 하위 요소의 폭 경계를 보강했습니다.

## 본문 글자 크기

- 설정 → 화면 설정에 `소·중·대` 본문 글자 크기 선택을 추가했습니다.
- 기존 크기를 `소` 기본값으로 유지합니다.
- 본문/대사 크기: 소 15.5/15px, 중 17.5/17px, 대 19.5/19px.
- 선택값은 테마와 본문 폭 설정처럼 현재 기기의 브라우저에 저장됩니다.

이번 리비전은 서사 엔진과 API 동작을 변경하지 않습니다.
