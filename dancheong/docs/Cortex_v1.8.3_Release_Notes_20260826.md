# Cortex 1.8.3 — ScenarioPack 1.5 의미 호환 어댑터

## 핵심 변경

- 사건 ID·순서만 비교하던 1.8.2 검증을 폐기하고 사건 제목, 설명, 결과, 종결 신호, 시간창, 참가자, 조건, 대체 비트, 장면 마커, 루트·루프 메타데이터를 함께 대조한다.
- `completionSignals`의 `|` 구분을 독립 종결 신호로 보존한다. 크로노스 코어의 실행 사건은 각각 종결 신호 2개를 유지한다.
- `opening.json`의 `preHistory`, `currentSituation`, `immediateProblem`, `knownRisks`, `openingEvent`, `firstGoal`, `openingLine`을 첫 사건 작가 계약에 전달한다. `hiddenRisks`는 GM 장부에만 둔다.
- 관계 정의, 공개 관계 기억, 관계 메모리 런타임, 자율행동 배우, 자율행동 런타임, 공개 사실 장부를 패키지 런타임 모듈로 연결한다.
- 사용자가 장시간 행동을 지정하면 짧은 `ACTION_SLICE`로 잘라 버리지 않고 지정 시각까지 진행한다. 현재 사건은 패키지의 `REMOTE` 또는 `DELAYED` 대체 비트를 통해 플레이어 선택을 보존하면서 흡수한다.
- 사건 진행·종결은 입력 키워드가 아니라 확정 본문에 종결 신호가 실제로 성립했는지로 판정한다.
- 이동 목적지가 없는 턴은 본문에 장소 이름이 언급됐다는 이유만으로 위치를 바꾸지 않는다.
- 1.8.2 이하 의미 어댑터 캐시는 1.8.3 의미 계약으로 재컴파일되지 않으면 `완전 호환`으로 표시하지 않는다.
