# Cortex 1.8.5 — Universal Narrative Kernel

## 배경

1.8.4는 크로노스 코어의 멀티루트 의미 계약을 보존했지만, 단일 사건 연쇄를 사용하는 Fate/Seoul 같은 Package 1.5 작품은 빈 route graph 때문에 실행 사건을 구성하지 못했다. 1.8.5는 작품명별 예외를 없애고 모든 작품을 하나의 공통 서사 커널로 집필한다.

## 변경 사항

- Package 1.5 입력을 `MULTI_ROUTE`와 `LINEAR_SEQUENCE` 토폴로지로 구분한다.
- 토폴로지는 사건 선택에만 관여하며 집필·정사·시간·공개·완료 판정은 `CORTEX_UNIVERSAL_NARRATIVE_KERNEL_V1`을 공통 사용한다.
- 루트 문서가 비어 있는 단일 연쇄 Package 1.5는 원본 사건의 sequence 순서대로 전체 사건을 구성한다.
- 명시 완료 신호가 없는 레거시 사건은 `onSuccess`, `effects`, `description`에서 검증 가능한 완료 신호를 생성한다.
- 원본 사건의 모든 알려진 필드를 매핑 정책 장부로 관리하며 등록되지 않은 신규 필드가 나타나면 완전 호환 적용을 차단한다.
- 미래 사건명, 비선택 루트 사건명과 GM 보호 용어 원문을 작가 프롬프트에서 제거한다.
- 미완료 사건 의무, 지연된 사용자 행동, 최후 수단 서사 부채를 공통 carryover 원장에 기록한다.
- 700~1000자·3~5장면은 품질 경고로 남기고 미완성 출력·행동 누락·시간 전환 누락·비공개 유출만 하드 차단한다.
- 195MB Fate/Seoul 패키지는 JSON과 인물별 대표 이미지만 선택 해제해 메모리 사용을 제한한다.
- 새 저장소를 사용해 이전 리비전의 정규화 캐시를 자동 승계하지 않는다. 기기 API 키는 별도 보관소에서 유지된다.

## 검증

- 크로노스 코어: 전체 사건 51개, 세계선 3개, 세계선별 20개 사건
- Fate/Seoul: 단일 연쇄 사건 47개, 빈 멀티루트 문서 무시, 대표 이미지 선택 로딩
- 두 패키지 모두 공통 서사 계약·사건 의미 해시·투영 커버리지 검증
- 세 크로노스 세계선의 비선택 사건 및 모든 미래 사건 제목 작가 문맥 차단
- 저장 실패 20회 연속 결함 주입 시 활성 서사 되감기 없음
