# v1.25.1 · VN 진입, 입상 배율, 멀티 비용 담당자

## 변경

- VN 화면은 단일 ESM 번들로 미리 내려받는다. 기존 개별 모듈 파일과 워커는 유지한다. 작품 공개 호칭 데이터도 번들에 포함해 진입 시 별도 요청을 없앴다.
- 과거 비용 기록은 첫 화면 표시 이후에 배치로 가져오며 기존 기록을 다시 쓰지 않는다. 새 유료 요청의 예산 검사는 이 작업이 끝난 뒤 수행한다. 계정 저장 복원과 정본 권한 검사는 유지한다.
- 피부 영역으로 얼굴을 측정하는 대체 경로에서 이마 노출을 구분한다. 이마가 넓게 드러난 그림의 과도한 축소를 최대 24% 배율 보정으로 완화한다. 눈 랜드마크 경로, 머리 위 여백, 작품 신장값 및 공통 바닥 기준은 유지한다. 기존 카메라 측정값만 다시 계산하고 그림을 유료 재생성하지 않는다.
- VN 멀티 인물·연출/이미지/음성은 원래 턴의 집필 담당자만 생성한다. 서버가 진행 임대 또는 확정된 비용 기록으로 담당자를 확인한다. 늦은 요청과 완료도 다른 사람에게 비용을 넘기지 않는다. 키 부재와 오류는 타인의 키로 자동 대체하지 않는다.
- 같은 대사는 청자마다 선택한 음성 모델이 달라도 원래 담당자가 생성한 음성을 공유한다. Typecast 출처를 위해 실제 제공사와 성우 공개 이름을 함께 보존한다.

## 검증

- TypeScript 검사 및 VN 진입/비용/카메라/멀티 회귀 테스트.
- SQLite/R2 대역으로 인물·이미지·음성 모두의 턴 담당자 제한, 담당자 키 누락, 확정 이후 늦은 요청, 다음 플레이어 전환, 중복 과금 방지 및 권한 차단 검증.
- 로컬 브라우저의 두 합성 참가자에서 실제 번들 진입, 본문과 제어 UI 확인.
- 기존 두 입상의 실제 픽셀과 렌더러 프레이밍/CSS로 수정 전후 시각 비교. 머리 위 여백과 163/178cm 배치 확인. 검증에 사용한 다운로드 이미지는 공개 소스에 포함하지 않는다.

## 한계

- 실기기 iPhone 및 실제 다중 계정 유료 제공사 호출은 수행하지 않았다. 통신·클라우드 복원·외부 모델 자체의 지연은 남는다.
- 얼굴 측정은 추정이다. 눈 위치가 확인되지 않는 그림에는 제한된 픽셀 보정을 적용하며 모든 생성 그림의 해부학적 일치를 보장하지 않는다.
- 원래 담당자의 탭이 닫혔거나 음성이 꺼져 있으면 새 자산/음성 공유를 기다릴 수 있다. 다른 참가자의 비용으로 자동 생성하지 않는다. 본문 읽기는 독립적으로 이어진다.
- Muse는 비민감 코드 사본의 독립 체크리스트만 작성했다. 주 개발자가 코드, 상태/권한 및 시각 결과를 직접 검토했다.
