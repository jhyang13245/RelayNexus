# 월희식 무대 (가로 휴대폰) — 1.26.4

사용자가 제공한 월희 리메이크 화면 6장(가로 휴대폰, 16:9 게임 화면)을 측정해 기준으로 삼았습니다.

## 참고 화면에서 측정한 값 (화면 높이 기준)
| 항목 | 월희 리메이크 |
|---|---|
| 정수리 | 위에서 7–12% |
| 눈높이 | 25–32% (화면 위 3분의 1 선) |
| 머리 크기(정수리–턱) | 25–33% |
| 하단 크롭 | 허리·골반 |
| 단독 위치 | 가로 0.47–0.52 (중앙) |
| 3인 | 약 0.2 / 0.43 / 0.8, 가장자리 인물은 잘림 |
| 본문 | 인물 위에 겹침, 진한 외곽선, 이전 줄은 회색 |
| 클로즈업 | 얼굴이 화면의 약 45%, 레터박스 가장자리가 부드러움 |
| 카메라 | 인물 크기는 장면 내내 일정, 키 차이는 유지 |

## 원인
1.26.3까지는 카메라가 `max(178cm, 공개 인물 중 최대 키)`를 기준으로 화면을 잡았습니다. 이 후보에는 화면에 나오지 않는 시점 주인공도 들어갑니다. 그래서 보통 인물(160cm 안팎)은 늘 기준보다 작게 그려지고 화면 아래로 내려갔습니다. 얼굴 크기는 1.26.3에서 거의 맞췄지만 위치가 낮았습니다(정수리 20%, 눈높이 39–44%).

## 변경 (입상 카메라 `월희식`, 기본값, 가로 휴대폰)
- 크기 기준: 시점 주인공을 뺀 공개 인물 키의 중앙값(150–178cm 범위). 모든 인물의 `--hs`는 여전히 `키 / 기준`이라 인물 간 비율은 정확히 유지됩니다.
- 카메라: 높이 118%, 하단 -22.5%. 기준 키 인물의 정수리가 8%, 눈높이가 약 27%에 옵니다.
- 기울기: 무대에 기준보다 큰 인물이 있으면 가장 큰 인물의 정수리가 2% 안에 들어오도록 모두를 같이 내립니다. 크기는 바뀌지 않습니다(카메라 틸트).
- 배치: 혼자 0.54, 둘 0.33/0.69, 셋 0.2/0.5/0.8.
- 본문: NVL 폭 66%, 글자 외곽선, 이전 줄 불투명 회색, 배경만 고르게 어둡게(입상은 원래 밝기).
- 클로즈업: 초점 인물의 얼굴을 중심으로 1.4배. 와이드는 위쪽을 기준으로 0.88배.
- 시네마 바: 안쪽 가장자리를 부드럽게.
- `설정 → 연출 → 무대 연출 확장 → 입상 카메라`: `월희식 · 중앙 구도 (권장)` / `크게 · 오른쪽 (본문 피함)`(1.26.3) / `기존 크기`. 앞의 두 방식 외에는 1.26.2와 같습니다.
- 세로 휴대폰은 바꾸지 않았습니다(1.26.5부터 PC 포함 모든 가로 화면에 적용).

## 측정 (889×410, Chromium, 실제 VN CSS·신장 계산, 실제 입상 비율의 합성 이미지)
공개 인물 예: 주인공 175(제외), 162, 156, 160, 170, 180 → 기준 162cm.

| 1.26.3 · 단독 162cm | 21.5% | 38.5% | 25.5% | 0.79 |
| 월희식 · 단독 162cm | 7.9% | 26.8% | 28.3% | 0.54 |

## 한계
- 월희 리메이크는 앞에 선 인물을 더 크게 그리는 원근 배치도 씁니다. 여기서는 기존 `멀리 선 인물(0.94배)` 외의 원근은 넣지 않았습니다.
- 본문이 인물 얼굴 위에 겹칠 수 있습니다(참고 화면과 같은 방식). 피하고 싶으면 `크게 · 오른쪽`을 고르세요.
- 키 차이가 큰 두 인물(예: 162cm와 180cm)이 함께 서면 작은 인물이 화면에서 낮게 보입니다. 비율을 정확히 유지하기 때문입니다.
- 실제 기기와 실제 생성 입상으로는 확인하지 못했습니다. 입상 비율은 실제 화면(서연)에서 잰 값(눈 19%, 턱 27%)으로 맞췄습니다.

## 1.26.5 · PC 화면 적용
- 월희식 카메라·기울기·배치·외곽선·클로즈업·시네마 바를 가로 화면 전체(`orientation: landscape`)에 적용했습니다. 모든 값이 무대 크기에 대한 비율이라 PC와 휴대폰이 같은 구도를 씁니다. 본문 폭 66%는 휴대폰 전용이고, PC는 원래의 76% 본문 폭을 그대로 씁니다.
- 작중 시간 표시가 화면 위 가운데(인물 머리 위치)에 있던 것을, 월희식에서는 메뉴 버튼 옆의 작은 투명 글자로 옮겼습니다.
- `크게 · 오른쪽`(1.26.3)은 가로 휴대폰 전용으로 남겼습니다. `기존 크기`는 모든 화면에서 이전과 같습니다.

| 화면 | 단독 162cm (정수리 / 눈 / 머리 / 가로) | 클로즈업 | 3인 가로 위치 |
|---|---|---|---|
| 1280×720 | 7.7% / 26.6% / 28.4% / 0.54 | 4.8% / 31.0% / 39.4% | 0.20 / 0.50 / 0.80 |
| 1440×900 | 7.6% / 26.6% / 28.4% / 0.54 | 4.8% / 31.0% / 39.4% | 0.20 / 0.50 / 0.80 |
| 1920×1080 | 7.2% / 26.3% / 28.6% / 0.54 | 4.9% / 31.0% / 39.2% | 0.20 / 0.50 / 0.80 |
| 889×410 (휴대폰) | 7.8% / 26.7% / 28.4% / 0.54 | 4.8% / 31.1% / 39.5% | 0.20 / 0.50 / 0.80 |

같은 PC 화면의 이전 카메라(기존 크기): 정수리 24.1%, 눈 38.0%, 머리 20.8%, 가로 0.68.
