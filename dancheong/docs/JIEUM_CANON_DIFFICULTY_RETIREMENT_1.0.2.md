# 지음 1.0.2 — 지능형 정사 난이도 선택 제거

단청 1.14.6에 포함한다. 지능형 정사 모드에서는 EASY/NORMAL/HARD 선택과 표시를 제거한다. 이 모드의 진행은 작가가 작성한 사건·발생조건·불변식과 Cortex 계약으로 결정되므로 별도의 포괄 난이도를 작성 의무로 제시하지 않는다.

기존 Studio 파일과 패키지의 `difficulty` 및 `rules/difficulty.json`은 왕복 호환을 위해 보존한다. 가져온 값을 자동 변경하거나 과거 패키지를 마이그레이션하지 않는다. Instant Story 모드의 난이도 선택은 유지한다.

지능형 정사에서는 프로젝트 상세 화면, 메뉴 설명, 현재 프로젝트 요약, AI 설계 요약에서 난이도를 숨기고 HARD 약점 경고도 만들지 않는다. 생성기 요청문에서도 고정 HARD 입력을 제거한다. 기존 패키지 직렬화와 실행 계약은 변경하지 않는다.
