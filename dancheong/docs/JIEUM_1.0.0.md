# 단청 지음 1.0.0 · Nexus 1.14.0

- Studio 제안서 개정 1.2를 기준으로 네이티브 `/jieum` 편집기를 통합했다. 외부 Studio를 iframe으로 띄우거나 기존 공개 Studio를 변경하지 않는다.
- Studio 2.3.2 기준 커밋: `418dcbc6f8a4575a223ade4bc2c8782ac709b9a5`.
- `RelayNovelStudio_v2.3.2_Source.zip` SHA-256: `fc45f599cb3dd64dca07a2e26327129797da65818d2514e95dca982214328a2f`.
- Cortex 기준: 1.42.0 + 단청 확장 1.0.0, Nexus 1.13.1에서 배포한 조립본을 변경 없이 유지한다. SHA-256: `156e7f1bb42f3bdb83ea6f4cea6b716f9e9c9cd4ceb79bc8e504ebc94cce44d9`.
- 원본 `app`의 도메인 모듈, 편집 섹션과 데모를 `features/jieum`으로 편입했다. 원본 CSS는 `studio-baseline.css`에 보존한다. `scripts/scope-jieum.mjs`가 선택자를 격리하고 작은 글씨를 보정한 `jieum-scoped.css`를 만든다.
- 제외: Studio 자체 hosting/auth 셸, layout, 독립 manifest/service worker, 자체 IndexedDB 시작 코드. Nexus의 로그인·설정·상단 메뉴를 공유한다. 새 계정/클라우드 동기화 기능을 추가하지 않는다.
- Studio 원본 도메인 모듈 사본 `tests/jieum/fixtures/studio-2.3.2`는 역방향 가져오기 검증용이다. 로컬 원본 저장소에 의존하지 않고 테스트를 재현할 수 있다.

## 디자인

단청 본 서비스의 상단바는 그대로 공유한다. 지음 내부는 한지 바탕, 녹색 색인, 연두색 선택 표시, 청색·하늘색 보조 영역으로 구분했다. 기존 승인된 단청 문양을 저채도 장식으로 재사용한다. 편집 화면만 지연 로딩하며 CSS는 `.jieum-editor`/`.jieum-route` 내부로 한정한다. 독자 화면이나 Cortex iframe에 전역 스타일을 주입하지 않는다.

사용자 요청에 따라 Muse 보조 검토를 별도 비민감 작업 사본에서 수행했다. 범위는 기존 팔레트·간격 비교였고 원본 파일 수정 권한은 주지 않았다. 최종 디자인, 코드 통합과 렌더링 판단은 메인 개발자가 직접 수행했다. 초소형 본문 글씨 제안은 채택하지 않았다.

## 유지하는 기능

정사 단일/멀티 루트, 분기·엔딩 수렴, 발생조건과 사건 설계, Instant 시작 설정·예시·키워드·수치·엔딩 주기, HARD/SOFT 불변식, 보호어, 관계 HUD, 이미지 Asset-Once 원본/화면용 내보내기, V1/V2 스냅샷, 두 기성학원 데모, Lotus 호환 및 Cortex 변환을 유지한다. 실제 AI의 작품별 품질을 100% 보장한다는 의미는 아니다.

새 산출물의 manifest와 스냅샷 루트에 다음 선택 메타데이터만 추가한다. `studioVersion`은 기존 가져오기 분기를 보존하기 위해 **2.3.2**를 유지한다. 스냅샷 경로·format·필수 feature 계약은 바꾸지 않는다.

```json
{"authoringProduct":"dancheong-jieum","jieumVersion":"1.0.0","studioCompatibilityVersion":"2.3.2"}
```

입력 패키지의 편집 원본 바이트 길이/SHA-256을 먼저 검증한다. 새 내보내기에서는 위 메타데이터가 반영된 실제 직렬화 바이트로 길이와 해시를 다시 계산한다. 런타임에 바로 가져오기/재생을 자동 실행하지 않고 기존 CortexPack ZIP 가져오기 경로를 사용한다.

## 저장과 전달 계약

- IndexedDB `DancheongJieum`, 버전 1, `drafts`/`handoffs` 저장소. 기존 Cortex·Nexus·Studio DB를 변경하거나 삭제하지 않는다.
- 초안 키 `current`: `{revision, project, updatedAt}`. 이미지 원본 Blob을 그대로 저장하고 재개 시 임시 object URL을 다시 만든다.
- 저장은 readwrite 트랜잭션 완료 후에만 성공으로 표시한다. 읽은 revision을 비교하는 CAS로 여러 탭의 조용한 덮어쓰기를 거부한다. 충돌 탭은 현재 작업을 파일로 내보낸 후 새로고침해야 한다.
- 다른 페이지로 이동하기 전 대기 중 저장을 마친다. 저장에 실패하면 이동하지 않고 내보내기를 안내한다. 미저장 상태의 외부 이동에는 브라우저 경고를 유지한다.
- 홈 `/api/studio/draft` 결과는 같은 origin의 IndexedDB에 넣고 `/jieum?transfer=<UUID>`로 전달한다. URL에는 줄거리·인증 정보가 들어가지 않는다.
- 전달 크기 최대 2 MiB, 수명 1시간, 미적용 큐 최대 8개. origin·타깃 계약을 검증하고 인증 키 필드를 거부한다. 오래된 압축 해시 호환 경로도 해제 크기를 제한한다.
- 검토 화면에서 보류·기존 작업 내보내기·재검토·적용을 선택한다. 초안 저장과 전달 ID 소비는 **한 트랜잭션**에서 완료한다. 실패나 충돌이면 이전 초안과 전달 기록을 모두 유지한다.
- 전체 프로젝트 JSON/ZIP 가져오기는 청사진 변환기를 사용하지 않는다. 가져오기 확인 대화상자 후 원본 검증·복원·저장에 모두 성공해야 편집 초안을 교체한다. AI 설계 섹션도 같은 안전한 가져오기 경로를 사용한다.
- 타 origin의 기존 Studio 초안을 자동 수집하지 않는다. 기존 Studio에서 원본 보존 ZIP 또는 작업 JSON을 내려받아 지음의 불러오기로 옮긴다. 브라우저 저장소를 지우기 전에는 ZIP 백업이 필요하다.

## 검증

- Studio 기존 계약/통합 82개를 편입했다. 현재 조립 Cortex에 정사/분기/Instant 패키지를 넣는 mock 런타임 검사 포함.
- 추가 저장·전달/CAS/실패 원자성 5개, Studio 2.3.2 ↔ 지음 의미·이미지 바이트 보존 2개.
- Nexus 기존 단위 테스트 571개, native route/메타데이터/PWA/lazy assets 3개. 기존 렌더링·Cortex 호스트·리플레이 검사도 수행한다.
- 실제 브라우저에서 데스크톱/모바일·라이트/다크 렌더링, 8 MiB 원본 이미지 ZIP 가져오기, 새로고침 후 이미지 표시, 잘못된 JSON 거부와 기존 초안 보존을 확인했다. 홈과 동일한 전달 저장 함수를 사용해 보류·재검토·적용 및 성공 후 전달 URL 정리도 검증했다. 입력 직후 홈으로 이동하고 다시 들어와도 마지막 수정 제목이 보존됐다.
- 전체 TypeScript 검사에는 기존 프로젝트 오류가 남아 있으며 새 지음 모듈과 편입 테스트에서는 오류가 없다. 실제 iPhone Safari, 대용량 기기별 저장 한도 및 유료 실모델 생성 품질은 별도 검증 대상이다. 단위/모의 테스트 통과를 실기기 또는 실모델 검증으로 표현하지 않는다.

배포 결과와 공개 소스 ZIP 해시는 릴리즈 기록에 별도로 저장한다. 이 문서는 배포 성공을 선행 주장하지 않는다.
