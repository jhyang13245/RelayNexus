# v1.25.4 — VN multiplayer media and automatic reading

## Media

- The authenticated VN gateway accepts the exact signed-in account's raw ID (multiplayer) and owner key (solo). Missing, stale and other-account fences still fail. Pre-provider access rejections explicitly report `X-VN-Provider-State: not-started`.
- A shared producer releases only proven unpaid reservations. Unknown network/provider outcomes remain fenced against duplicate billing, including retries followed by an unpaid rejection.
- A one-time claim migration recovers old, completed failures from the raw-account transport before the deployment cutoff. v1.25.5 extends recovery to image/voice requests: all built-in VN media routes ran the same account gate before any provider call. It excludes running/ready records, another payer, later uncertain outcomes and new-protocol requests.
- Solo and multiplayer now use the same account key vault. Former multiplayer credentials fill only absent provider records; existing keys and explicit deletion records win, including concurrent saves. Session/media databases are unchanged.
- The originating turn's player still owns every cast/image/voice request. Listeners reuse the shared result and do not substitute their keys.

## Reading and controls

- Multiplayer pages advance automatically at the normal reading pace after reveal and any enabled voice playback. Manual next/previous, skip, history jumps and full-auto choices are disabled; no player action is automatically submitted.
- Only the current player sees input and suggestions. Other players wait on the story screen. New public paragraphs resume reading automatically.
- A joining reader starts the latest turn instead of a personal historical bookmark. Menus, hidden tabs and voice buffering can still pause local playback; this release does not promise frame-exact synchronization across devices.
- The bottom-left turn notice tracks the image status notice's actual height, with separate portrait/landscape spacing.

## Validation

Targeted account-fence, key-vault, shared-media, payer ownership, migration, reader controls and original-source preservation tests; TypeScript check; production artifact validation. Local browser checks use synthetic data, no real credentials or provider calls. Real provider latency and another player's device remain external conditions.
