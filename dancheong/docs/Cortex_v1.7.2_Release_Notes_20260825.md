# Cortex 1.7.2 — 공통 서사 무결성 리비전

배포일: 2026-08-25  
적용 범위: 독립 Cortex HTML (`/cortex.html`)  
Nexus/단청 기본 엔진: 변경 없음

## 원인

Cortex 1.7.1 크로노스 코어 로그에서 완성된 본문과 서버 상태가 서로 어긋났다. 본문은 07:48에 학교에 도착했지만 서버 시각과 장소는 06:30대·현재 장면에 머물렀고, 현장에 없는 인물이 발화했으며, 사용자가 지정한 두 바퀴가 한 바퀴 반으로 축소됐다. 첫 쪽지를 실제로 발견하고 읽은 본문도 종결 조건 미충족으로 오판되어 임시 비트가 열렸고, 다음 정상 본문은 잘못된 시간·장소 판정 때문에 저장되지 않았다. 인벤토리에는 책상이 들어가는 오염이 있었으며, 다음 턴 캡슐은 V1에 머물거나 내부 제어문과 잘린 문장을 포함했다.

## 공통 개선

- 본문에 명시된 유효한 시각과 이동 결과를 서버 월드 시각·장소에 단조 증가 방식으로 반영한다.
- 장소가 바뀌면 현장 등장 인물을 다시 계산하고, 현장 밖 인물의 무근거 발화를 강한 품질 오류로 차단한다.
- 사용자가 지정한 행동 수량을 보존하고 모델이 축소한 수량은 본문 블록에서 결정적으로 교정한다.
- 발견·확보·이동·결정·파괴·상태 변화의 의미 역할과 대상 근거를 결합해 종결 조건을 판정한다.
- 이미 개연성 있게 완성된 본문은 반복 종결 검사 실패만으로 폐기하지 않는다.
- 책상·바닥·문·교실 같은 비휴대 장소/가구를 인벤토리에서 제외하고 직접 잡은 휴대 물체만 기록한다.
- 다음 턴 Literary/Continuity Capsule V3를 추가 API 호출 없이 즉시 결정적으로 생성한다.
- 캡슐과 공개 작가 문맥에서 서버 제어문을 제거하고 문장 경계가 완성된 본문 꼬리만 전달한다.

이 규칙들은 크로노스 코어 고유 인명이나 사건 ID에 의존하지 않으며 학교·연구실·택배함 등 서로 다른 장면에 동일하게 적용된다.

## 검증

- Cortex 렌더/엔진 테스트: 48/48 통과
- Nexus 공통 단위 테스트: 512/512 통과
- 기존 20턴 Cortex 회귀 재생: 모든 무결성 단언 통과
- 1.7.1 로그 실패 패턴 재생: 시각, 장소, 종결 의미, 수량, 인벤토리, 현장 화자, 캡슐 V3 규칙 통과
- 대규모 100/200회 시뮬레이션은 사용자 요청에 따라 수행하지 않음
