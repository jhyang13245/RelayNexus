# 지음 1.0.1 — 적은 입력으로 시작하는 창작

단청 1.14.4에 포함한다. 저작 호환 버전은 Studio 2.3.2를 유지한다.

## 변경

- 세계관의 역사·정치·경제·기술·사회문화·군사·종교이념·교통통신·화폐물가·초자연 서술을 자유 작성란 하나로 통합한다. 각 분야는 필수 양식 대신 안내 문구로 제시한다.
- 이전 항목의 원문은 소제목과 함께 통합 표시한다. 읽기만 해서는 데이터를 바꾸지 않으며, 통합 글을 수정할 때 서술 내용을 overview에 저장하고 해당 분류 필드를 비운다. 핵심 정사·불가능 조건·AI 보완 제약·미래 확장 필드는 별도로 보존한다.
- 작품 정보, 인물, Instant 진행 지침, 첫 장면에 간결한 기본 편집을 제공한다. 전체 필드는 상세 설정에서 접근할 수 있다. 인물의 공개 소개에 비밀이나 외형 필드를 자동 합치지 않는다.
- 기본 메뉴와 추가 설계 도구를 나눈다. 예시 장면·키워드 노트·NPC·이미지·상태창을 기본 작성 진행률의 의무로 세지 않는다. 진행률은 내보내기 인증이 아니며 기존 필수 검증을 유지한다.
- 모바일의 상세 설정·인물 추가 버튼이 공통 soft-button 숨김 규칙에 가려지지 않게 한다.

## 검증

기존 지음 계약 검사 89개, 새 세계관 통합·원본 보존·패키지 왕복·선택 항목 진행률 검사 3개를 통과했다. 변경 파일과 의존성 범위의 TypeScript 검사를 통과했다. 전체 저장소 타입 검사는 기존 API 및 중복 작업 디렉터리 오류가 있어 통과로 표기하지 않는다.

로컬 실제 브라우저에서 세계관 입력 후 인물 탭 왕복, 데스크톱 및 390px 모바일 표시, 모바일 상세 설정 진입을 확인했다. 실제 유료 모델의 집필 품질과 실물 iPhone/Safari는 검사하지 않았다. 합쳐진 자유 서술이 실제 생성 품질을 높이는지는 별도 평가 대상이다.
