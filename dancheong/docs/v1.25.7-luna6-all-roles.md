# 1.25.7 — GPT 6 Luna for all active Luna roles

## Scope

- OpenAI and OpenCode Go now use `gpt-6-luna` for writing, continuity/preflight checks, event adjudication, memory, recovery/recommendations, VN cast direction and studio drafts. Instant and restored legacy simulation requests also normalize the old model ID.
- The shared normalizer upgrades only `gpt-5.6-luna` and its dated snapshots. Other text, image and voice model families retain their selection.
- The integration adapter updates runtime calls without modifying the vendored Cortex/VN originals. Historical standalone snapshots and cost records retain their original model information.
- Response schemas, output limits, reasoning settings, streaming and validation remain the same. The two providers retain their existing endpoints and authorization headers.

## Existing API keys and saved games

There is no credential migration, storage reset or new device/account namespace. Existing encrypted OpenAI, OpenCode Go, Gemini and Typecast credentials continue to load through the existing vault. The model upgrade never clears keys after a failed request. Saved game histories and multiplayer originating-player payment ownership are preserved. The user only needs to refresh to load the release, not re-enter saved keys.

## Published prices checked for this release

Standard short-context text pricing, USD per one million tokens:

| Model | Input | Cached input | Cache write | Output |
| --- | ---: | ---: | ---: | ---: |
| GPT 5.6 Luna | 0.20 | 0.02 | 0.25 | 1.20 |
| GPT 6 Luna | 0.10 | 0.01 | 0.125 | 0.50 |

Input is 50% lower and output approximately 58% lower at these rates. Contexts over 272K input tokens use a different tier; existing cost calculations retain both tiers and both generations. OpenCode Go lists these model rates but its subscription allowance/overage rules still apply, so this is not a claim that subscription charges change by the same percentages. Actual token use may differ between models.

Sources: [OpenAI GPT 6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), [OpenAI GPT 5.6 Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna), [OpenCode Go](https://opencode.ai/docs/go/).

## Verification and limits

Regression coverage checks exact credential/header preservation through both VN proxies, old settings and request normalization, encrypted keys after reload, concurrent key saves, provider isolation, real adapted engine requests using mocked providers, recovery of missing recommendations, cost accounting, streaming and multiplayer ownership fences. TypeScript and production artifact checks are release gates.

No live paid provider request or actual user key inspection is performed for this migration. Tests verify request routing and behavior with fixture credentials; live account entitlement and model output quality are not proven by these checks.
