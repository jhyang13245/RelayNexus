# Cortex 1.8.1 — iOS 패키지 적용·모달 레이아웃 수정

배포일: 2026-08-26

## 수정 내용

- 검증이 끝난 패키지는 기기 영구 저장 완료를 기다리지 않고 즉시 활성화합니다.
- 적용 직후 가져오기 창을 닫고 선택한 세계선으로 전환합니다.
- IndexedDB 또는 LocalStorage 저장이 지연·실패해도 현재 세션 적용은 유지합니다.
- 적용 중 버튼 상태와 성공·실패 안내를 명시적으로 표시합니다.
- 모바일 모달을 헤더·스크롤 본문·고정 푸터의 세로 Flex 구조로 변경했습니다.
- iPhone 안전영역을 포함해 하단 `취소`·`적용` 버튼 전체가 화면 안에 표시됩니다.
- Cortex 1.8.0 저장본을 1.8.1로 마이그레이션합니다.

## 검증

- 패키지 검증 후 적용 버튼 활성화 확인
- 영구 저장을 지원하지 않는 환경에서도 패키지가 즉시 활성화되고 모달이 먼저 닫히는지 확인
- 적용 완료 후 버튼 상태 복구 확인
- 전체 단위 테스트 515개 통과
- 독립 Cortex HTML 테스트 57개 통과
- 기존 20턴 로그 회귀 재생 통과
