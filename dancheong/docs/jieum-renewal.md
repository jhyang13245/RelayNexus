# 지음 정사 저작 개편

사용자 승인: 구현, 검수, 공개 배포. Instant 편집과 기존 작품 원문/이미지는 보존한다.

## 범위
- 홈: 작품 정보와 JSON/ZIP 가져오기. 교체 전 저장/건너뛰기/취소, 저장 취소 시 교체 금지.
- 세계관/비공개 세계관, 선택 규칙/참고자료. GM 통합.
- 캐릭터: 기존 이미지 헤더, 자유 설정/외형/비공개. 불변식 유지.
- 도입부 및 서술 설정: 본문/상황/세 파동, 시점/문체와 정적 예문.
- 사건: 필수/타인시점/발생조건, 내용/종결조건/선택 제약/대체종결, 분기 토글.
- 단일루트 또는 순차 루트 해금. 루트당 엔딩 하나, 시작 전 작가 코멘트. 루트 경계를 저장.
- 스탯·자원 별도 간단 탭, 공개 선택. 사건별 고정 증감과 반복 자원 변화는 구분.
- 사건시계/시간루프/AI설계/자율세계 독립 UI 삭제, 정사 키워드 없음.
- 복선: 내용/심을사건/회수사건. 세력: 이름/설정/비공개. 이미지 트리거 간소화.
- 회색 예시는 focus 시 숨김. 검증 문제에서 해당 편집으로 이동.

## 검증 목표
저장/정규화/원본보존, 루트 경계와 해금/시작/재로드, 점수 중복 및 미평가,
자원 범위/증감/재시도/되돌리기, 새 패키지 가져오기, 기존 Instant 회귀,
공개/비공개 분리, 빌드와 화면 검수. 모델 품질과 실제 지연은 측정 여부를 명시.

## Nexus 1.19.0 / 지음 1.2.0 검수 결과
- 메인 프롬프트 생성은 모드별 간결한 스키마를 사용한다. 엔진 기본값은 코드에서 구성하고 연결 검증 후 전달한다. 모델 호출 실패·미완성 응답은 기존 초안을 교체하지 않는다.
- 정사 컴파일, 엔딩 도달과 다음 루트 시작, 저장 후 재접속, 공개 판정 호출 내 자원 증가/감소, 범위 초과 보류, 중복 방지와 되돌리기를 모의 응답으로 검증했다.
- 단위/통합 검사 725개: 724 통과, 기존 1개 건너뜀. Cortex 호스트 검사 53개: 51 통과, 기존 2개 건너뜀.
- Chrome에서 320/390/768/1024/1440px 주요 입력 화면을 렌더링해 가로 넘침과 버튼 잘림을 검사했다. 메인 생성→지음 전달, 재로드 입력 보존, 루트 추가, 가져오기 취소, 저장창 취소를 검증했다.
- 글자 삭제 버튼에 아이콘 고정 폭을 사용하지 않는다. 카드 제목과 조작 버튼은 공간에 맞춰 줄을 나누며 모바일 버튼의 터치 높이를 유지한다.
- 렌더링 검사 61개 통과. 실제 브라우저에서 새 패키지를 불러와 작성한 도입부, 작가 코멘트, 공개 자원, 비공개 스탯 제외 및 인물/현재 장면 갱신을 확인했다.
- 생산 빌드와 배포 산출물 검증 통과. 저장소 전체 tsc는 기존 작업 사본/레거시 타입 오류로 통과하지 못한다. 이번에 추가한 정사 편집·생성 파일에서는 보고된 타입 오류를 수정했다.
- 실제 유료 모델 호출의 산문 품질, 비공개 정보의 자연어 누설 가능성, 실사용 지연은 이번 자동 검증의 보장 범위가 아니다. 자원 판정은 기존 판정 요청에 포함하며, 자원만을 위한 추가 호출을 만들지 않는다.
- 예전 복합 루트·숫자가 아닌 상태값은 원본 JSON에 보존하고 새 편집 구조에 자동 변환되지 않는 부분을 해당 사건 화면에 알린다.

## Nexus 1.19.2 / 지음 1.2.2 이미지 영역 선택
- 캐릭터 내장 이미지와 장면 이미지 모두 업로드 직후 1088×608 고정 영역을 선택한다.
- 세로 사진은 처음에 세로 전체와 좌우 여백을, 긴 가로 사진은 가로 전체와 위아래 여백을 보여준다.
- 사진 비율에 따라 프레임을 완전히 채울 수 있는 확대 범위를 자동 계산한다. 확대된 이미지가 프레임보다 커진 축은 마우스·터치 드래그와 방향키로 이동할 수 있다.
- 여러 캐릭터 이미지는 차례로 조정하며, 저장되는 WebP 파일 자체가 1088×608이다. 확대하지 않고 저장하면 화면에 보인 여백도 그대로 포함된다.
- Chrome 데스크톱·390px 모바일에서 세로·가로 초기 맞춤, 확대·드래그, 캐릭터·장면 저장 결과를 실제 캔버스 픽셀과 출력 크기로 확인했다.

## Nexus 1.19.2 Cortex 내장 화자 이미지
- 산문 작가가 확정한 화자 주석과 공개 가능한 캐릭터 ID·이름이 모두 일치할 때만 비주인공 내장 사진을 해당 비트의 첫 대사 앞에 한 번 표시한다.
- 주인공 내장 사진은 프롤로그 시작에 한 번 크게 표시하고, 대사의 작은 화자 아바타는 유지한다.
- 사진 디코딩을 미리 시작하고 재사용한다. 본문 생성과 감사는 계속 진행하며, 화면 표시는 최대 6초 뒤 사진 없이 이어진다.
- 사진이 없거나 화자가 모호한 경우 다른 인물을 추정 연결하지 않으며 자동 유료 이미지 생성도 호출하지 않는다.
