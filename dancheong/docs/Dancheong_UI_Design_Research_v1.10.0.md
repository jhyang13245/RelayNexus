# Relay Nexus 1.10.0 — 단청 UI 디자인 연구

## 목표

단청의 시각 요소를 화면 전체에 반복하는 대신, 한국 건축 단청의 기능과 위계를 플레이 인터페이스에 번역한다. 본문 읽기와 선택은 조용하고 빠르게 유지하고, 구조·현재 상태·핵심 행동에만 색을 집중한다.

## UI 번역 원칙

1. **독서면은 가칠·긋기처럼 절제한다.** 한지색에 가까운 저채도 배경과 먹색 본문을 사용해 장시간 읽을 때의 피로를 줄인다.
2. **색은 건축 부재처럼 위계적으로 둔다.** 상단 바는 보, 장면 메타는 띠, 현재 선택과 주요 버튼은 집중 단청으로 취급한다.
3. **오방색은 의미 표식으로만 쓴다.** 녹청은 진행과 현재 상태, 적색은 경계와 강조, 황색은 구획, 청색은 보조 정보를 담당한다.
4. **문양을 장식 이미지로 복제하지 않는다.** 구름·연꽃·당초의 반복과 흐름은 얇은 띠, 곡선 연결감, 규칙적인 간격으로 추상화한다.
5. **플레이 흐름이 장식보다 우선한다.** 본문, 현재 장면, 입력창은 항상 보이고 복구·동기화·기억·내보내기·계정·설정은 하나의 필요 시 펼치는 도구 메뉴에 둔다.

## 1.10.0 적용 결과

- 세션 화면을 본문과 286px 상태 패널의 2열 구조로 단순화했다.
- 상단에는 세션, 되돌리기, 도구만 남기고 부가 기능은 `SESSION TOOLS`에 접었다.
- 본문 폭, 행간, 장면 제목 위계를 조정해 독서 리듬을 강화했다.
- 사용자 선택은 녹청색 왼쪽 선 하나로 명확히 구분했다.
- 턴별 보조 동작은 평상시 시각 강도를 낮추고 호버·포커스 때 선명하게 했다.
- 모바일에서는 부가 도구가 고정 패널로 열려 기존의 숨김 기능도 접근할 수 있게 했다.
- Cortex 1.6.4의 엔진 동작과 선택 구조는 변경하지 않았다.

## 디자인 판단

단청의 정체성은 색과 문양을 많이 배치하는 데 있지 않다. 보호·구획·상징·위계를 수행하도록 필요한 부재에 정확히 적용하는 것이 핵심이다. Relay Nexus 1.10.0은 이 원리를 따라 ‘조용한 중앙, 집중된 가장자리’를 채택한다. 그 결과 단청의 인상은 유지하면서도 플레이어의 시선은 본문과 다음 행동에 머문다.
