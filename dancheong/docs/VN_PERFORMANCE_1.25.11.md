## 적용 범위

- 기존 인물 판정 요청에 장면 연출 정보를 함께 받는다. 별도의 연출 판정 호출은 추가하지 않는다. 실제 공개 본문에 없는 행동·미래·회상·부정된 행동은 근거로 쓰지 않는다.
- 효과음, 충격, 컷인과 강조 카드를 해당 문구가 표시되는 시점에 실행한다. 싱글의 `voice-end` 연출은 음성 종료를 기다리고, 멀티는 공유 글자 시계를 따른다. 뒤늦게 받은 연출을 지난 문장에 재생하지 않는다. 건너뛰기에는 효과음을 몰아서 재생하지 않는다.
- 추가 구도 설정을 켠 경우 서기·경계·앉기·몸 기울이기와 좌우 시선을 같은 인물의 기존 입상을 참조하여 그린다. 비트당 최대 1개, 같은 인물·복장·표정·자세·방향의 결과를 재사용한다. 모델·키와 멀티 비용 부담은 기존 인물 이미지 경로를 사용한다.
- `설정 → 추가 구도·자세 생성`의 기존 선택값을 유지한다. 기본 꺼짐이며 생성에는 추가 이미지 비용이 발생한다. 기존 사용자에게 자동으로 켜지지 않는다.
- 같은 장소의 역방향 구도는 일반 대화에서 유지한다. 두 인물 구도와 넓은 구도를 구분하고, 명시적으로 멀리 선 인물에만 약한 원근 차이를 준다. 신장과 전신 보정은 기존 실제 모듈을 그대로 사용한다. 이미지 반전이나 몸 부위별 늘이기는 하지 않는다.
- 시간대·날씨에 맞는 공통 입상 색보정과 역광 처리, 종이·천·발걸음·문·금속·충격의 절차적 효과음 및 음성 재생 중 효과음 감쇠를 적용한다.
- 현재 대사의 의도와 인접 문맥을 기존 TTS 요청에 전달한다. 대사 자체를 추가하거나 바꾸지 않는다. 이름 소개 전 공개 호칭을 유지하도록 집필 지침도 보강했다.
- 이미 보이는 입상의 표정·자세는 문장 중간에 갑자기 교체하지 않고 다음 문장에 반영한다. 처음 준비된 인물은 빈 자리 때문에 차단되지 않는다.
- 기존 저장·API 키·유료 생성물을 삭제하거나 마이그레이션하지 않는다. 과거 판정은 재사용하며 새 연출 항목이 없다는 이유로 유료 재판정을 하지 않는다.
