# Multiplayer 1.20.3

- 준비 완료·취소 입력은 즉시 화면에 반영하고 서버 저장 중임을 별도로 표시한다. 실패하면 직전 상태로 되돌린다.
- 서버 확정 뒤 참가자 카드와 내 준비 영역에 `준비 완료` 또는 `준비 전`을 계속 표시한다.
- 준비 변경은 이야기 생성용 Cortex 잠금을 사용하지 않으며, 회원 상태 갱신과 이벤트 기록을 한 번의 배치로 처리한다.
- 방·참가자 조회와 내 참가방 목록 조회를 배치해 네트워크 왕복 및 N+1 조회를 제거한다.
- URL로 방에 진입할 때 서재와 API 키 검사를 기다리지 않고 방부터 불러온다. API 키 검사는 독립적으로 완료된다.
- 백그라운드 탭에서는 방 갱신 요청을 멈추고, 돌아오면 즉시 다시 확인한다.
- 대기실처럼 카운트다운이 없는 화면에서는 0.5초 전역 재렌더를 실행하지 않는다.
