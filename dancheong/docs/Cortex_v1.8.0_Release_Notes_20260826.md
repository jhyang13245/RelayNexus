# Cortex 1.8.0 — ScenarioPack 1.5 완전 호환 계층

배포일: 2026-08-26

## 핵심 변경

- ScenarioPack 1.5의 `multi_route_v1`, `time_loop_v1`, `reveal_policy_v1`, `ending_meta_progress_v1` 계약을 독립 Cortex HTML에서 직접 해석합니다.
- 사건 원본 전체를 GM 전용 장부에 보존하고, 선택한 루트의 공통 장·전용 장·조건 분기를 실제 실행 연쇄로 컴파일합니다.
- 현재 사건의 비트·필수 기능·시간창·참여 인물은 집필 엔진에 전달하되, 미래 사건의 제목·정답·진명은 공개 조건 전까지 전달하지 않습니다.
- 패키지가 허용한 경우 가져오기 화면에서 잠긴 루트를 테스트 오버라이드로 선택할 수 있습니다.
- 사건 패널에 `선택 세계선 사건 수 / 원본 전체 사건 수`와 현재 루트를 표시해, 미래 내용을 누설하지 않고도 정상 로드 여부를 확인할 수 있습니다.
- 계약형 v1.5가 아닌 기존 ScenarioPack·InstantStoryPack ZIP은 기존 레거시 어댑터로 계속 불러옵니다.

## 크로노스 코어 실물 ZIP 검증

- 원본 사건: 51개 보존
- 루트: 3개 인식
- 기본 루트: `baek_seohyun`
- 선택 실행 연쇄: 20개
- 첫 사건: `CC_CH01_NOTE_ONE` / 정체불명의 쪽지
- 첫 사건 비트 3개 및 필수 기능 1개 보존
- 초기 사건 날짜: D+0, D+1, D+2, D+3 순으로 정상 계산
- 정규화·등록 이후에도 51개 GM 장부와 20개 실행 연쇄 유지
- 공개 작가 문맥에서 두 번째 미래 사건 제목이 누설되지 않음을 확인

## 호환성과 저장

- Cortex 1.7.9 세션 저장을 1.8.0으로 마이그레이션합니다.
- API 키는 계속 기기 브라우저 전용 저장소에만 보관합니다.
- 본 리비전은 독립 Cortex HTML에만 적용됩니다.
