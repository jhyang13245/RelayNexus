# Cortex 1.8.2 — ScenarioPack 실행 일치·영속 상태 복구

## 핵심 수정

- ScenarioPack 1.5 검증 결과와 실제 활성 런타임의 스키마, 실행 ID, 선택 루트, 사건 연쇄를 적용 직전에 다시 대조합니다.
- 다중 루트 패키지가 `legacy_…` 변환본으로 실행되거나 서로 다른 루트의 사건이 섞이면 플레이 시작을 차단합니다.
- 이전 리비전의 잘못된 다중 루트 레거시 캐시는 자동 등록하지 않으며, 원본 ZIP 재선택을 요구합니다.
- 패키지의 구조화된 시간 창과 도입 시각을 읽어 세계 시각과 사건 시각을 함께 구성합니다.
- 로그에 비공개 사건 내용을 노출하지 않는 실행 증명서(루트·사건 수·연쇄 해시)를 남깁니다.

## 저장 안정성

- 대형 시나리오·턴·정사 상태를 IndexedDB 전용 저장소로 이전했습니다.
- `localStorage`에는 작은 설정 포인터만 남기며, 이전 대형 저장본 때문에 용량이 찬 경우 즉시 정리합니다.
- 기기 영구 저장이 불가능해도 현재 탭의 확정 턴은 보존하며 저장 용량 오류로 본문과 사건 상태를 롤백하지 않습니다.
- 활성 패키지와 각 작품의 독립 상태를 하나의 직렬 저장 큐로 순서대로 기록합니다.

## 시간·의도 교정

- 입력 시간 단위에 `분`과 `초`를 추가했습니다.
- 짧고 사건과 무관한 행동은 사건 종료 시각까지 강제로 늘리지 않습니다.
- 사건 비트와 의미적으로 연결된 행동만 비트 마일스톤을 진행하며, 나머지는 입력 행동의 실제 시간만 진행합니다.
- `물구나무서기`의 일부 문자열을 `무서움`으로 오인하던 감정 판정을 제거했습니다.

## 검증

- 중첩 폴더형 ScenarioPack 1.5, 2개 루트 분리, 구조화된 시간 창, 실행 증명서 검증을 추가했습니다.
- 구형 다중 루트 레거시 캐시 차단을 검증했습니다.
- `기지개를 5분동안 핀다`가 정확히 5분만 진행하고 사건 비트를 유지하는지 검증했습니다.
- 브라우저 저장 용량 오류가 발생해도 확정 경로가 예외로 중단되지 않는지 검증했습니다.
