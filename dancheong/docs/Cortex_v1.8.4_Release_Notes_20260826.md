# Cortex 1.8.4 — ScenarioPack 1.5 Runtime V4

## 배경

1.8.3 진단 로그에서 ZIP과 선택 루트는 정상 적용됐지만 정규화 이후 첫 사건의 완료 신호가 하나 사라졌고, 공개 인물명·장소·시간·변형 정사 판정도 실제 본문과 어긋났다. 1.8.4는 패키지 원본 장부를 실행 런타임의 불변 계약으로 사용한다.

## 변경 사항

- 정규화·활성화·복원 뒤 51개 원본 사건의 제목, 설명, 완료 신호, 시간창, 대체 비트, 루트 메타데이터를 다시 대조한다.
- 실제 활성 런타임의 의미 해시가 원본과 다르면 패키지 적용을 중단한다.
- 현재 사건의 설명·효과·후속 인과·완료 신호를 매 턴 작가 계약에 전달한다.
- 미래 사건 본문은 계속 비공개로 유지하면서 백서현·김다윤·윤설아 등 공개 인물명은 과잉 마스킹하지 않는다.
- `학교에 등교한다`, 교실·사물함 이동, 학교 이탈을 명시적 장소 이동으로 판정한다.
- 명시 시간이 없는 일반 행동은 사건 종료 시각까지 늘리지 않고 현실적인 행동 시간만 소비한다.
- 다음 날 사건 시작으로 건너갈 때 본문에 날짜 전환 장면이 없으면 최종 품질 검증에서 차단한다.
- 700~1000자·3~5개 장면 정책을 최종 확정 게이트에 연결한다.
- 조사 행동의 표현 변형을 인정하고, 배설물 표현을 부상 정사로 오인하지 않으며 실제 손·손목·팔 부상은 보존한다.
- 1.8.3 실행 상태는 자동 승계하지 않고 원본 패키지에서 Runtime V4로 다시 컴파일한다. 기기 API 키는 별도 보관소에서 유지된다.

## 검증

- 공식 크로노스 코어 ScenarioPack v1.5: 사건 51개, 세계선 3개, 세계선별 20개 사건 검증
- 세 세계선 의미 해시 및 정규화 후 의미 해시 통과
- 실행 사건 20개 전부 완료 신호 2개 유지
- 공개 인물 9명 이름 보존 및 미래 사건 제목 차단
- Cortex 독립 HTML 테스트 58개 통과
- 프로젝트 단위 테스트 515개 통과
- Cortex 20턴 재생 검증 통과
- 프로덕션 빌드 통과
