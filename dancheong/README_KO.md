## 로컬 실행


Windows 실행 주소는 <http://127.0.0.1:4173>입니다. 로컬 서버 설정이 필요하면 `.env.example`을 `.env.local`로 복사하며, 실제 API 키가 든 파일은 커밋하거나 공유하지 마세요.

## 저장 구조

- D1: 계정 작품·세션·감사 기록·비용 메타데이터
- R2: 패키지 ZIP·세션 스냅숏·작품 표지 등 바이너리 원본
- IndexedDB: 빠른 재접속을 위한 기기별 Cortex 패키지·미디어
- 로컬 저장소: 기기별 Cortex 목록과 화면 설정

소스 ZIP은 API 키, 환경 비밀값, 의존성, 빌드 결과물, 실행 캐시, 과거 소스 ZIP을 제외합니다. ZIP 안의 `SOURCE_EXPORT_MANIFEST.json`에서 정확한 버전, 파일 수, 생성 시각, 소스 해시를 확인할 수 있습니다.
