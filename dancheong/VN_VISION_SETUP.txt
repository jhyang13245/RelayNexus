비주얼노벨 입상 보정의 로컬 검출 파일

소스 ZIP에는 전체 자사 소스, 검출 라이브러리 로더, 라이선스와 바이너리
의존성의 고정 URL·크기·SHA-256 목록을 포함합니다. 배포 호스트의 파일당
25 MiB 제한 때문에 모델과 WASM 바이너리는 ZIP에서만 제외합니다.
운영 실행 파일에는 public/vn-vision/1.0.1 아래 바이너리가 반드시 필요합니다.

ZIP을 새 폴더에 푼 경우 최초 빌드 전에 실행:
  node scripts/install-vn-vision.mjs

네트워크 없이 설치된 파일을 검사:
  node scripts/install-vn-vision.mjs --check

스크립트는 고정된 정적 의존성 파일만 내려받고 SHA-256을 검사합니다.
캐릭터 이미지·프로필·API 키를 전송하지 않으며 이미지 생성이나 유료 API를
호출하지 않습니다. 검출은 플레이어 기기의 별도 Worker에서 실행됩니다.
빌드나 앱 실행이 의존성 파일을 외부 CDN에서 자동으로 가져오지 않습니다.
노드 의존성 설치는 별도이며 기존 프로젝트 실행 지침을 따릅니다.
