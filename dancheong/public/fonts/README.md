# Dancheong fonts

Nanum Myeongjo (400, 700, 800) and Nanum Myeongjo YetHangul are supplied by NAVER:
https://hangeul.naver.com/font/nanum

Sources:
- https://hangeul.naver.com/hangeul_static/webfont/zips/nanum-myeongjo.zip
- https://hangeul.naver.com/hangeul_static/webfont/zips/NanumMyeongjoYetHangul.zip

Fonts are served locally as WOFF2. The YetHangul file contains only the glyphs
used in the Studio headline. Normal Myeongjo files retain the full character set.
See OFL-NanumMyeongjo.txt for redistribution terms.
