# 이강백전 → 지음(지능형 정사) 사건 초안 작성 규격

## 목적
무협 연재소설 「이강백전」을 단청 "지음"의 **지능형 정사(intelligent canon)** 작품으로 옮긴다.
독자(플레이어)는 주인공 **이강백**을 직접 연기하고, AI 작가가 매 턴 산문을 쓴다.
작품은 서장부터 36화 끝(66일차, 경사 편 1막 끝)까지의 **정사 사건 목록**을 순서대로 통과한다.
각 사건은 런타임에서 기본 3턴(최소 2, 연장 최대 2)으로 진행된다. 즉 사건 하나 ≈ 소설 원고 2~3절 분량.

## 분할 원칙
- 한 화를 보통 **2개 사건**으로 나눈다(절 2~4개씩 묶음). 짧거나 한 장면뿐이면 1개, 큰 장면이 셋 이상 몰린 화는 3개까지.
- 사건 하나는 "하나의 장면 목표"여야 한다: 같은 시간·장소 흐름 안에서, 시작 상황 → 핵심 전환 → 결과가 있는 단위.
- 서장(늙은 짐꾼 시점, 갑진년)은 작품의 **시작 본문(프롤로그)**으로 따로 쓰이므로 사건으로 만들지 않는다. 01화 사건은 "1" 절(낙양 청운표국 뒷마당, 인시)부터 시작한다.

## 각 사건 JSON 필드 (모두 한국어)
```json
{
  "episode": 1,                 // 화 번호
  "part": 1,                    // 그 화 안에서의 순서 1,2,3
  "sections": "1~3절",           // 원고의 어느 절을 덮는지
  "title": "편자 못과 검붉은 봉랍", // 사건 이름. 짧게(6~16자). 화 제목을 그대로 쓰지 말고 장면을 가리키는 이름
  "storyDay": 1,                // 표행 N일차(정수). 모르면 가장 가까운 추정 + uncertain에 적기
  "timePlace": "표행 1일차 인시, 낙양 청운표국 뒷마당",
  "otherViewpoint": "",         // 강백 아닌 인물의 시점 장면이 이 사건의 중심이면 "인물명 시점. 의도" (예: 소운의 회상). 아니면 빈 문자열
  "description": "...",         // 사건 내용 5~9문장. 아래 '사건 내용 쓰는 법'
  "facts": [                    // 3~8개
    {"kind": "FIXED_FACT", "text": "..."},       // 바뀌면 안 되는 고유 사실(이름·숫자·물건·상처 부위·장소·시각)
    {"kind": "REQUIRED_RESULT", "text": "..."},  // 이 사건에서 실제로 이뤄져야 할 결과
    {"kind": "OFFSCREEN_RESULT", "text": "..."}  // 강백이 보지 못하는 곳에서 일어나도록 허용한 일
  ],
  "closure": ["...", "..."],    // 종결조건 2~4개. 아래 '종결조건 쓰는 법'
  "constraints": "...",         // 이 사건에서 하면 안 되는 것(스포일러·이른 공개·능력 한계·말투 규칙 위반 등) 2~5문장
  "unmet": "...",               // 플레이어가 다른 길로 갔을 때 허용할 대체 종결 1~3문장(정사의 도착점은 유지)
  "keyLines": ["..."],          // 원고에서 그대로 살려야 할 핵심 대사·문장(최대 4, 강백 본인의 대사는 넣지 않는다)
  "foreshadow": [               // 이 사건에서 심거나 회수하는 복선(없으면 [])
    {"role": "plant", "title": "같은 손 — 반듯한 글씨와 좋은 먹", "note": "4화 협박장에서 처음"}
  ],
  "newAbilities": ["..."],      // 강백이 이 사건에서 새로 얻는 능력/깨달음(없으면 [])
  "uncertain": ""               // 원고와 정본 문서가 어긋나거나 확신이 없는 점(없으면 빈 문자열)
}
```

## 사건 내용(description) 쓰는 법
- AI 작가에게 주는 **장면 설계**다. 현재형·지시형으로 쓴다: "강백은 …한다. 마광은 …를 묻는다."
- 시작 상황(누가 어디서 무엇을 하고 있는가) → 일어나는 일의 순서 → 이 장면이 남기는 것.
- 플레이어가 강백을 연기한다. **강백의 대사·감정·결정을 강제하는 문장은 피하고**, 강백이 마주할 상황과 다른 인물이 하는 일, 정사상 일어난 결과를 중심으로 쓴다. 강백의 정사 행동은 "정사에서 강백은 …했다"처럼 기준으로만 적는다.
- 원고의 구체물(냄새·물건·숫자·상처·지명)을 살린다. 해석·설명은 줄인다.
- 다음 사건의 내용을 미리 쓰지 않는다.

## 종결조건(closure) 쓰는 법
- 공개 본문에서 **독자가 확인할 수 있는 결과**로 쓴다. 예: "독자가 다섯 번째 수레의 약재 상자 하나만 봉랍이 검붉고 바퀴 축이 내려앉아 있다는 것을 본다." / "곽위가 노칠의 시신을 두고 '다르잖소'라고 말한다."
- 하나의 경로만 허용하는 행동 지시가 아니라 **도착점**을 쓴다(경로는 플레이어 자유).
- 2~4개. 사건의 핵심만.

## 반드시 지킬 정사 규칙 (요약 — 상세는 01_정사문서.md, 06_문체가이드.md)
1. **소설이 정사다.** 원고(편집실 리마스터)를 기준으로 쓴다. 정본 문서 우선순위: 08 결정사항 > 01 정사문서 > 05 아크 지도 > 07 회차목록 > 게임 기록. 원고와 01이 어긋나면 01을 따르고 uncertain에 적는다.
2. **불과 내공의 언어(1부):** 강백 시점 서술에서 강백 자신의 몸 안은 불·불씨·아궁이·재·풀무·계단·온기·길로만 쓴다. "기·내공·경맥" 금지. 다른 무림인의 대사는 무공 일반에 기·내공을 쓰되, 강백의 것은 "불"이라 부른다.
3. **경지·호신강기:** 절정 이상은 호신강기가 있어, 상대가 막을 스스로 걷었거나·여럿의 합이거나·막 안쪽으로 파고든 경우에만 아래 경지의 공격이 닿는다.
4. **성장 규칙:** 한 화에 새 능력은 둘까지, 새 능력에는 실패·대가가 하나 이상, 근거는 아비가 그려 둔 길(몸이 기억함)이나 짐꾼의 몸·기억. 놀람을 숫자 비교("몇 년 걸릴 걸")로 쓰지 않는다.
5. **누가 무엇을 아는가:** 그 시점에 인물이 알 수 있는 것만. 진목은 22화 전까지 백발 사내가 "그 밤의 사람"인지 의심만 한다. 진목은 13화 전까지 "양하"라는 식객으로 불리며 본명·청산검문을 밝히지 않는다. 강백은 7화까지 글자를 전혀 모른다(23화 자기 이름, 25화 一~十 …).
6. **호칭:** 06 문체가이드 6장 표를 따른다(강백→두충 "표사님"(11화까지)→"형님"(12화부터), 두충→강백 "강백아"(12화부터), 강백→한진 반말(6화 이후), 강백→진목 "사부"(13화부터), 소운→강백 "강백 씨"(22화부터) 등).
7. **첫 살인은 22화, 주먹(아홉 번째로 칼 안쪽→충권, 처음으로 거두지 못함).** 그 전 사건에서 강백은 사람을 죽이지 않는다(침입자·인부는 모두 생포).
8. 07 회차목록의 "고쳐야 할 화 메모"에 있는 확정 수정(일차 셈, 9화 참장 무아는 일곱 시진, 역분경 완성은 21화, 마광의 관 운구 등)을 반영한다.
9. 강백의 손과 심마의 손을 섞지 않는다(손끝으로 핏줄·팔꿈치로 관자놀이는 심마의 것).

## 출력
