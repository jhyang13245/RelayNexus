# 이강백전 (李江白傳) — 지음 작품 · 너름 출간본

연재소설 「이강백전」의 서장~36화(1부 경사 편 1막 끝, 표행 66일차)를 단청 **지음**의 **지능형 정사** 작품으로 만들고, **너름**으로 출간한 결과물이다. 단청 v1.34.19 소스의 지음 코드(모델·검증·내보내기)를 그대로 실행해 만들었다.

## 파일

| 파일 | 용도 |
|---|---|
| `이강백전_CortexPack.zip` | 너름에 올리는 출간 패키지(CortexPack, 표지 포함). SHA-256 `302f22ec0e596a019076b3193866642811ff08635474afe87656ec83cb44eb3b`, 1,475,871바이트 |
| `이강백전_작업.json` | 지음 작업 JSON. 지음 → 불러오기로 열면 그대로 이어서 편집할 수 있다 |
| `너름_출간정보.json` | 너름 출간 화면에 넣을 작품명·부제·영문 ID·설명·장르·태그 |
| `작가_검토_메모.md` | 원고와 정본 문서가 어긋난 자리, 원고 없이 문서로 만든 화의 빈칸 |
| `cover/` | 표지(1080×1440, PNG·WebP)와 표지 원본 HTML |
| `source/` | 작품을 다시 만드는 원본: 설정(`content/settings.mts`), 화별 사건 초안(`drafts/ep01~36.json`), 빌드·출간·검사 스크립트 |
| `verification/` | 검증 보고서와 화면 캡처 |

## 작품 구성

- **실행 방식:** 지능형 정사(Cortex) · 단일 루트 「1부 · 낙양에서 경사까지」.
- **사건:** 100개, 서장 뒤 1화부터 36화까지 원고 순서대로 배치했다.
  - 낙양~서안 편 59개, 경사행 9개, 경사 편 1막 32개.
  - 화마다 2~3개이고, 사건마다 내용·현재 사건의 고유 사실·종결조건 2~4개·장면 제약·대체 종결을 넣었다.
  - 마지막 사건 「36화 · 대문 앞, 지게 위의 길」이 엔딩이다.
  - 소운의 회상(18화)과 나루 싸움(19화)은 '주인공 이외 인물 시점' 사건이다.
- **도입부:** 시작 본문은 원작 서장을 그대로 썼다. 시작 상황은 표행 1일차 인시 낙양 청운표국 뒷마당이다. 작은·중간·큰 파동의 첫 행동 셋을 넣었다.
- **설정:**
  - 세계관: 관무불가침·관제·경사 기관·경지·호신강기·전음·화산·여정. 비공개 세계관에는 ★ 비밀을 넣고 36화까지 공개하지 않게 했다.
  - 반드시 지킬 규칙: 불과 내공의 언어, 성장 규칙, 첫 살인, 글자 진도, 이름이 공개되는 시점.
  - 인물 25명(주인공 이강백 포함)과 세력 10곳.
  - 캐릭터 불변식 13개: 강백·진목·소운·유헌·두충·곽위·석두·한진의 생존, 강백의 경지 상한 등.
  - 복선 14개: 심는 사건과 회수하는 사건이 모두 이 루트 안에 있다.
  - 보호어 6개: 1부에서 공개하지 않는 말.
- **문체:** 3인칭 제한 시점이다. 추가 서술 요청에 06 문체가이드의 목소리·형식·대사·피할 버릇을 옮겼다.
- **스탯:**
  - 해독환: 자원, 18화에 셋을 얻고 쓴 만큼 줄어든다.
  - 익힌 글자: 사건 점수로 23·25·27·32·35화에 오르고 36화까지 25자가 된다.
  - 둘 다 처음 바뀐 뒤 상태창에 공개된다.

## 너름 출간과 검증

이 작업 환경에서는 운영 사이트(`relay-novel-nexus.juno12345.chatgpt.site`)에 접속할 수 없었다(네트워크 정책이 차단). 접속하더라도 작가 계정 로그인이 필요하다. 그래서 같은 소스의 **단청 독립 서버**(`npm run build:standalone`, 너름 허브 포함)를 띄우고, 거기에 작가 계정을 만들어 실제 너름 업로드 절차로 출간했다. 절차는 업로드 세션 생성 → 표지 → 패키지 분할 업로드 → 완료다.

확인한 것:
- 지음 검증: 오류 0, 경고 0, Cortex 린터 오류 0.
- 내보낸 ZIP을 지음 가져오기로 다시 열었을 때 원본이 손실 없이 복원된다(fullFidelity, 사건 100개, 표지 포함).
- 실제 지음 화면에 작업 JSON을 불러오면 「사건 100개 · 엔딩 지정됨」, 「패키지를 만들 준비가 되었습니다」로 나온다.
- 너름 허브의 패키지 계약 검증을 통과해 공개되었다.
  - 공개 목록·작품 페이지(`/neoreum/works/lee-gangbaek-jeon`)·관리 페이지에 표시되고, 작품 페이지에 「Cortex에서 바로 실행 가능」이 뜬다.
  - 너름에서 내려받은 ZIP의 SHA-256이 원본과 같다. 표지(WebP)도 그대로 내려온다.
- 「내 서재에 추가」로 서재에 설치하고 새 이야기를 열었다.
  - Cortex가 패키지를 불러온다(「이강백전 패키지를 Cortex 공통 세션으로 불러왔습니다」).
  - 첫 사건 「1화 · 편자 못과 검붉은 봉랍」, 장소 「낙양 청운표국 뒷마당」, 원작 서장이 시작 장면으로 표시된다.

확인하지 못한 것:
- 실제 AI 집필 품질과 사건 진행은 확인하지 못했다. 이 서버에는 AI 키가 없어(「API KEY REQUIRED」) 첫 턴 이후 산문과 추천 행동이 나오지 않는다.
- 비주얼노벨 모드와 운영 사이트 업로드도 하지 않았다.

### 운영 사이트에 출간하기 (약 1분)

1. 단청 운영 사이트에 작가 계정으로 로그인 → **너름 → 새 작품 출간**.
2. 패키지에 `이강백전_CortexPack.zip`을 선택한다. ZIP에 든 표지가 자동으로 잡힌다.
3. `너름_출간정보.json`의 값을 그대로 넣는다.
   - 작품명 `이강백전`, 부제 `李江白傳 · 1부 낙양에서 경사까지`, 영문 ID `lee-gangbaek-jeon`.
   - 장르 `무협 · 성장 · 관부 미스터리`, 태그 `무협, 정통무협, 성장, 미스터리, 짐꾼, 지능형 정사`, 설명.
   - 공개 범위는 공개.
4. 「작품 검증 후 너름에 공개」.

지음에서 더 고치려면 `이강백전_작업.json`(또는 ZIP)을 지음 → 불러오기로 연다.

## 다시 만들기

```bash
# 단청 v1.34.19 소스 루트에서
npm ci
node --import tsx <repo>/works/lee-gangbaek-jeon/source/build-project.mts <repo>/works/lee-gangbaek-jeon/source ./out
# → out/이강백전_작업.json, out/이강백전_CortexPack.zip, out/validation-report.json
```

- 사건 초안은 `source/DRAFT_SPEC.md` 규격을 따른다.
- `fix-drafts.py`는 2~11화 일차를 상대 날짜로 바꾼다. 이미 적용된 상태로 들어 있다.
- `lint-drafts.py`는 이름·비밀이 공개 시점보다 먼저 나오는지 검사한다.
- `publish-neoreum.mjs`는 너름 업로드 절차를 그대로 따르는 출간 스크립트다.
- 표지 HTML은 `@fontsource/noto-serif-tc`·`@fontsource/noto-serif-kr` 글꼴을 `../fonts/`에 두고 Chromium으로 1080×1440 캡처해 만들었다.
