# 아홉 번째 등불 ~귀환 게이지가 차오를수록 불길한 이세계 용사 생활~

단청 **지음 · 지능형 정사 모드**용 이세계 라이트노벨 작품입니다.

> ⚠️ 이 문서는 작가용 설계서라 **결말까지 전부 스포일러**가 있습니다. 먼저 독자로 읽어 보고 싶다면 아래 「바로 읽기」만 보고 닫으세요.

| 파일 | 용도 |
| --- | --- |
| `ninth-lamp_jieum.json` | 지음 작업 JSON. 지음에서 불러와 편집합니다. |

## 사용법

**지음에서 편집하기**
1. 단청 → 지음 홈 → **기존 작품 불러오기** → `ninth-lamp_jieum.json` 선택
2. 세계관·캐릭터·사건·복선·스탯 탭에서 원하는 대로 다듬기 (캐릭터 이미지는 비어 있으니 직접 올리면 됩니다)
3. **검증·내보내기 → 패키지 ZIP 저장**

**바로 읽기**
- 단청 서재 → **ScenarioPack ZIP 불러오기** → `ninth-lamp_CortexPack.zip`

## 한 줄 소개

> 엄마 대신 실종된 이모에게 쓴 편지를 태우던 밤, 스무 살 편의점 알바생 윤도하는 이세계의 아홉 번째 용사로 소환된다. 상태창, 귀여운 견습 사제, 무뚝뚝한 기사단장, 그리고 "안개의 왕을 쓰러뜨리면 집에 보내 주겠다"는 약속. 그런데 괴물을 벨 때마다 차오르는 **귀환 게이지**가 어쩐지 불길하다.

## 요청 사항별 설계

| 요청 | 설계 |
| --- | --- |
| **누구나 입문하기 쉬움** | 첫 장면은 익숙한 이세계 소환 클리셰(상태창, 용사, 마왕 격의 '안개의 왕')로 시작합니다. 1인칭 라이트노벨 문체로 주인공의 속마음 딴죽이 이야기를 이끌고, 시작 추천답변 3개가 있으며 목표("게이지를 채워 집에 간다")가 처음부터 분명합니다. |
| **흥미·몰입** | 게이지라는 숫자를 독자가 직접 보며 '좋은 것'으로 여기다가, 그 정체를 깨닫게 됩니다. 수치(HUD)가 곧 미스터리 장치입니다. 매 사건 제목이 챕터 제목으로 보이고, 사건마다 새 단서가 하나씩 열립니다. |
| **어두운 면** | 용사는 등불의 연료이고, 괴물(잔향)은 먼저 타 버린 용사들의 기억입니다. 빛은 가난한 동네(등외구)에 덜 닿습니다. 다정한 대신관은 악의 없이 "30만 명"을 택합니다. 안개의 왕은 주인공의 실종된 이모입니다. |
| **복선 회수** | 복선 20개를 '심을 사건 → 회수할 사건'으로 지음의 복선 탭에 연결했습니다. 숫자(1004·8282), 물건(꿀사탕·머리핀·편지·삐삐), 노래(자장가), 말버릇('괜찮아')이 서로 엮여 회수됩니다. 아래 「복선 지도」 참고. |
| **선택이 의미 있음** | 잔향을 **베면** 게이지가 오르고(= 더 잘 타는 연료가 되고), **대답하거나 애도하면** 진실의 조각을 얻습니다. 친절이 진실을, 폭력이 파멸을 키우는 구조입니다. |

## 세계

- **루멘하르트 왕국**: 검은 안개 바다에 둘러싸인 마지막 땅. 탑 위의 **대성등** 빛이 닿는 곳에서만 30만 명이 산다.
- **성등 신전**: 대성등과 소환·귀환 의식을 관장한다. 스물여덟 해마다 이세계(한국)에서 용사를 부른다.
- **축복의 창(상태창)**: 레벨·기술·**귀환 게이지**. 진짜 이름은 **연소 준비도**.
- **잔향**: 안개 속 괴물. 이 세계 사람에게는 짐승 울음이지만 주인공에게만 한국어("엄마…", "집에 갈래…")로 들린다.
- **진실**: 대성등은 영혼을 태워 빛난다. 귀환문은 탑 꼭대기 화로로 이어진다. 지금까지 집에 돌아간 용사는 없다.

## 수치 (스탯·자원)

| 수치 | 방식 | 역할 |
| --- | --- | --- |
| **귀환 게이지** % | 사건별 점수 · 공개 | 잔향을 벨 때 +15 / +20 / +30. 60% 이상이면 결말에서 주인공 손이 실제로 타기 시작한다. |
| **진실의 조각** (0~8) | 사건별 점수 · 첫 변화 후 공개 | 단서를 확인할 때 +1. 5 이상이면 결말에서 시민들 앞에서 진실을 증명한다. |
| **세라의 신뢰** (0~10) | 사건별 점수 · 공개 | 「세라의 수첩」 분기 기준(4 이상). 정직하고 다정하면 오르고, 세라를 속이면 내려간다. |
| **스마트폰 배터리** % | 자원 · 공개 | 시작 23%. 손전등·사진 2%, 재생 3%, 통화 5%. 메이블의 결정 충전기로만 회복한다. 두 번째 이야기의 분기와 연결된다. |
| **모인 기억** (0~9) | 사건별 점수 · 첫 변화 후 공개 | 두 번째 이야기에서 사람들이 기억을 바치기로 약속할 때 오른다. 새 등불의 밝기를 정한다. |

### 결말 변주 (비공개 세계관에 기록)

결말의 큰 줄기는 고정입니다. 의식이 멈추고, 이모가 남은 자신을 등불에 바치고, 다온의 메시지가 도착합니다. 다음 항목은 수치와 선택에 따라 달라집니다.

- 진실의 조각 **5 이상**: 시민들 앞에서 진실을 증명하고, 오르텐이 스스로 지팡이를 내려놓는다. **4 이하**: 신전이 "용사의 광란"으로 덮으려 하고 소문이 엇갈린다.
- 귀환 게이지 **60 이상**: 문이 열리자 주인공의 손이 실제로 타기 시작하고, 이모가 그 불을 대신 끌어간다. 오른손에 등불 흉터가 남는다.
- 10a를 지났다면 세라가 귀환가 대신 자장가로 의식을 멈춘다. 10b를 지났다면 노래하다 목이 메어 울며 달려온다.
- 이모에게 꿀사탕·머리핀·편지 중 무엇을 건넸는지에 따라 마지막 대화가 달라진다.

## 스포일러 관리

- 단청 독자 화면에서는 **사건 제목이 챕터 제목**으로 보이고, **종결조건**은 '이야기 정보' 패널에 보입니다. 그래서 둘 다 미리 비밀이 새지 않게 썼습니다. 비밀은 비공개 세계관과 인물의 비공개 설정에만 있습니다.
- 비공개 세계관의 「공개 조건 — 정사 진행표」가 사건마다 어디까지 드러낼지 정합니다.
- 전역 보호어: `한소이` (「안개의 심장」 사건의 공개어). 안개의 왕은 인물 이름 자체를 '안개의 왕'으로 두어 인물 목록에서 정체가 새지 않게 했습니다.
- 캐릭터 불변식: 주인공 생존(HARD), 세라 생존(HARD), 다온은 이 세계로 오지 않음(HARD), 스마트폰은 파괴되지 않음, 바르트 생존(첫 번째 이야기), 의식 전 오르텐의 지위.

## 검증

`source/`의 스크립트로 단청 v1.28.0 소스의 지음 모듈과 Cortex 런타임을 그대로 써서 확인했습니다.

- **지음 검증**: 정사 설계 문제 0건, 검증 오류 0건. 경고 27건은 모두 지음 정사 작품 공통 항목입니다(기준 이미지 없음, 사건 '발생 조건 비어 있음').
- **가져오기·내보내기**: 지음 파일 가져오기와 같은 경로로 다시 읽어 정규화했습니다. 패키지 ZIP을 지음으로 다시 불러와도 정사 설계와 복선이 그대로 복원됩니다.
- **모의 플레이**: 실제 Cortex 1.42.0 + 지음 확장을 헤드리스로 띄워, 고정 문장을 내는 모의 모델로 두 번 끝까지 진행했습니다.
  - 선택 조건 충족: 1→9 → **10a** → 11 엔딩 → 두 번째 이야기 해금 → … → **7a** → 8 → 9 엔딩. 수치는 게이지 65, 진실 8, 신뢰 6, 모인 기억 9로 설계와 같습니다.
  - 선택 조건 미충족: 1→9 → **10b** → 11 엔딩 → … → **7b** → 8 → 9 엔딩.
- **한계**
  - 실제 AI의 문장 품질, 비밀 누설 여부, 판정 정확도는 검증하지 않았습니다. 모의 모델은 연결 구조만 확인합니다.
  - Node의 가짜 IndexedDB는 실제 브라우저보다 훨씬 느려서, 두 번째 이야기에서 Cortex의 4초 저장 제한에 걸렸습니다. 그래서 검증용 사본에서만 그 제한을 늘렸습니다(`assemble-cortex.mjs --test-timeout`). 배포용 런타임은 바꾸지 않았습니다. 두 번째 이야기의 저장 상태는 이전 루트 기록이 함께 보관되어 모의 진행 기준 약 4MB였습니다. 실제 기기에서 확인해 볼 만합니다.

## 다시 빌드하기

```bash
# 단청 소스(v1.28.0)를 압축 해제한 위치를 DC로 둔다. jszip·fflate·esbuild(검증에는 jsdom·fake-indexeddb)가 필요하다.
esbuild source/build.ts --bundle --platform=node --format=esm --loader:.json=json \
  --alias:@jieum=$DC/features/jieum --outfile=build.mjs
node build.mjs ninth-lamp_jieum.json ninth-lamp_CortexPack.zip

node source/assemble-cortex.mjs $DC/vendor/cortex cortex-test.html --test-timeout
esbuild source/verify.ts --bundle --platform=node --format=esm --loader:.json=json \
  --alias:@jieum=$DC/features/jieum --alias:@harness=$DC/tests/cortex/harness.mjs \
  --external:jsdom --external:fake-indexeddb --outfile=verify.mjs
node --max-old-space-size=8192 verify.mjs ninth-lamp_jieum.json cortex-test.html
```

작품 내용을 고칠 때는 지음에서 직접 편집하는 것이 가장 간단합니다. `source/draft.mjs`는 처음 설계한 원본입니다.
